# 世界观与核心玩法方向

记录日期：2026-09-21  
状态：早期创意基线，供后续设计、场景扩展与剧情制作参考。

本文记录已讨论确定的方向，不代表相关功能已经实现，也不是当前版本的开发任务清单。尚未确定的细节单独列出，后续按实际需要补充。

后续系统需求见[开发备忘录](开发备忘录.md)，包括升级、物品掉落、背包和人物换装系统。

## 一句话概念

**开着自己的改装房车探索遗迹，强化自身、装备、房车。**

玩家驾驶房车穿行于由不同文明遗迹拼合而成的星球，寻找安全区、建立营地、深入遗迹，最终击败“遗迹之王”，将被掠夺的遗迹归还原本的星球文明。

## 世界观与最终目标

宇宙中存在一个邪恶的“遗迹之王”。它掠夺其他文明的遗迹，将其据为己有；有时甚至为了得到遗迹而毁灭整个文明。

所有被收集的遗迹都被捏合到遗迹之王的母星上，形成一颗汇聚不同文明遗存的“遗迹星球”。因此，不同建筑、地貌和文明风格可以出现在同一颗星球上，它们原本来自不同的世界。

玩家的最终目标是击败这颗星球上的遗迹之王，并将这些遗迹归还给它们原本所属的星球文明。

世界观的表达追求：**简单易懂，同时带有宏大的感觉。** 玩家能迅速理解敌人做了什么、自己为什么出发；宇宙与文明的规模感通过探索、画面和剧情逐渐展开。

## 核心探索流程

**大地图驾驶 → 找到安全区 → 展开房车营地 → 深入遗迹 → 击败遗迹最终 Boss → 获得“证物” → 前往下一处遗迹。**

1. 驾驶自己的房车探索大地图，寻找下一处落脚点。
2. 找到安全区，支起房车营地，以此作为深入遗迹的出发点。
3. 离开营地，进入遗迹探索与战斗。
4. 击败该遗迹的最终 Boss，取得前往下一处遗迹的“证物”。
5. 继续旅程，逐步推进至与遗迹之王的最终对决。

“证物”目前确定的作用是串联遗迹之间的推进。它的具体形态、剧情含义，以及如何帮助玩家前往下一处遗迹，尚未确定。

## 大地图与现有场景

以讨论中提到的现有四个场景为基础，今后逐步扩展成为大地图，承载房车驾驶、安全区、营地和遗迹探索。

遗迹星球的设定为不同风格场景的共存提供了统一解释。场景之间可以呈现明显的文明差异，同时都属于这颗由掠夺所得拼合而成的星球。

具体的地图连接方式、规模、加载方案，以及四个场景各自承担的角色，留待后续设计。

## 房车与成长方向

房车兼具两个角色：

- **移动家园**：承载安顿、驻扎和返回营地的体验。
- **冒险伙伴**：陪伴玩家在大地图中行进，其改装与成长也是游戏吸引力的一部分。

整体成长围绕三条线展开：**自身、装备、房车**。

两种房车体验都要兼顾，但现阶段暂不展开复杂系统。驾驶挑战、车辆战斗、维护、营地设施，以及三条成长线的具体机制均尚未确定。

## 剧情与风格化表达

剧情阶段之间使用**风格化动画串场**，串联冒险进程、文明遗迹与最终目标。

整体表达保持清楚直接，让玩家通过旅程感受到世界的规模。小房车与临时营地带来贴近个人的体验，不同文明的庞大遗迹则承载宏大的空间与故事背景。

动画的具体形式、时长、触发位置和制作方式尚未确定。

## 可选灵感：尚未定案

以下内容来自讨论中的延伸建议，仅供以后取用，不作为已确定设定：

- 将“证物”设计为记录遗迹故乡信息的文明印记，使其同时关联主线推进与最终归还。
- 让不同遗迹的 Boss 拥有不同身份，例如监守者、被控制的守护者，或误将玩家视为入侵者的本土守卫。
- 在取得证物时播放短动画，展现文明曾经的生活与遗迹被掠夺的过程。
- 为不同文明使用不同的动画画面语言，例如壁画、剪影或机械蓝图。
- 通过改装获得新的通行或探索能力，让成长带来可抵达区域的变化。
- 用“开着自己的家，帮助失去故乡的文明回家”作为情感表达方向。

## 后续需要回答的问题

- 玩家是谁，为什么来到遗迹星球？
- “证物”具体是什么，如何引向下一处遗迹？
- 安全区与营地的规则是什么？
- 三条成长线分别提供哪些能力？
- 遗迹最终如何归还？对于已被毁灭的文明，归还意味着什么？
- 如何从逐个遗迹的探索推进到遗迹之王的最终对决？

这些问题不妨碍当前核心方向成立，后续在需要制作相应内容时再明确。
