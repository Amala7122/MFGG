# 分辨率与 UI 改造路线

更新时间：2026-09-23

当前状态：第一、二、四阶段已实施；第三阶段（本地分屏）按当前决定暂缓；第五阶段待场景和分屏策略确定后统一验收。

## 目标

- 1080p 成为最低正式验收分辨率，1440p 与 4K 保持清晰。
- 3D 渲染分辨率、窗口分辨率和 UI 缩放互不绑死。
- 单人、联机与本地分屏使用同一套显示设置语义。
- RTX 2080、RTX 3060、RTX 4060 级显卡在目标画质下保持 60 FPS。

## 第一阶段：窗口与可用设置（已完成）

- 显式保留 1152×648 UI 逻辑画布，默认物理窗口提升到 1920×1080。
- 支持窗口模式与无边框全屏。
- 支持 1280×720、1600×900、1920×1080、2560×1440、3840×2160 窗口分辨率。
- 支持 85%、100%、115%、130% UI 缩放。
- 显示设置即时生效并独立保存到 `user://display.cfg`。
- 截图与性能自动化不读取个人显示存档，保证结果可重复。

## 第二阶段：分离 3D 渲染比例与 UI 分辨率（已完成）

- UI 由 2D 画布以窗口原生像素绘制；它的整体尺寸另由 UI 缩放控制。
- 3D 独立提供 100%、85%、70% 档位，默认 100%，更改即时生效并写入 `user://display.cfg`。
- 只有 3D 场景允许使用缩放器；文字、准星、小地图和菜单禁止随 3D 降分辨率。
- 低于 100% 时采用 Godot 的 FSR 1.0 空间放大；100% 为原生渲染。实际同机位对比显示，85% FSR 比 85% 双线性更能保住遗迹、山体的硬边，但原生仍最干净，70% 有可见的细节损失。因此降档是性能余量不足时的选项，不是默认画质。
- 自动测试 `tests/test_display_scaling.gd` 检查三个档位不会改变 UI 画布尺寸或 UI 缩放。

## 第三阶段：重构本地分屏（暂缓）

用户决定本轮不处理分屏。现有分屏渲染路径不纳入第二、四阶段的完成判定；后续进入本阶段时单独改造和验收。

- 取消每块固定 1152×648 的渲染纹理。
- 每块 3D 视口根据实际物理占屏尺寸与 3D 渲染比例计算像素数。
- HUD 从 3D SubViewport 纹理中拆出，以窗口原生分辨率分别裁切到各玩家区域。
- 重新决定横向、纵向分屏及宽高比策略，避免 16:9 屏幕上的大面积黑边。

## 第四阶段：1080p UI 精修（已完成本轮范围）

- 去掉武器面板 72%、生命与小队面板 88%、技能栏 85% 的历史二次缩放；面板按 1080p 下的实际占位绘制。
- 统一正文、HUD 的字体和可变字重 600。菜单设置页改为五项，并压缩说明区，保证 130% UI 缩放在 1080p 内仍可完整操作。
- 细边线按 1152×648 逻辑画布到 1080p 的映射，采用至少 1.5 逻辑像素（默认 UI 缩放下约 2.5 物理像素）；菜单按钮边框为 2 逻辑像素。切角继续由共享样式控制，不再对整块 HUD 施加额外缩放。
- 字体使用 Google Fonts 发布的 Noto Sans SC 可变字体；授权文件随字体放在 `theme/fonts/OFL-NotoSansSC.txt`，游戏及截图均使用项目内置字体，不依赖系统回退字体。
- 已检查 1920×1080（16:9）、1920×1200（16:10）、2560×1080（21:9）的设置页和游戏 HUD，以及各尺寸下 130% 的设置页；另以 3840×2160 虚拟窗口检查 100% 和 130% 的设置页，未发现重叠、裁切。这些均是程序截图，**不等同于真实高 DPI 或 4K 显示器实测**；后续仍需在实体屏幕上复核。

## 本轮复查图与运行方法

- 场景画质同机位：`visual_captures/phase24_native_gate.png`、`phase24_fsr85_gate.png`、`phase24_bilinear85_gate.png`、`phase24_fsr70_gate.png`。
- 设置页：`visual_captures/ui/display_settings_1920_1080.png`、`display_settings_130pct_1920_1080.png`，另有 1920×1200、2560×1080、3840×2160 对应文件。
- HUD：`visual_captures/phase24_hud_1080_court.png`、`phase24_hud_16_10_court.png`、`phase24_hud_21_9_court.png`。
- 游戏主菜单 → 显示设置，可分别切换窗口模式、窗口分辨率、3D 渲染比例、UI 缩放；3D 降档仅影响场景，不应模糊 HUD。

## 第五阶段：性能与验收

- 固定测试 1920×1080、2560×1440、双人分屏三组基线。
- 记录平均 FPS、1% 低帧、绘制调用、图元数和显存占用。
- 最低验收：目标显卡 1080p 单人 60 FPS；分屏单列预算并明确所用画质档位。
- 每轮场景升级都使用相同机位、敌人数与采样时长，禁止拿不同分辨率成绩横向比较。
