# 分辨率与 UI 改造路线

更新时间：2026-09-20

## 目标

- 1080p 成为最低正式验收分辨率，1440p 与 4K 保持清晰。
- 3D 渲染分辨率、窗口分辨率和 UI 缩放互不绑死。
- 单人、联机与本地分屏使用同一套显示设置语义。
- RTX 2080、RTX 3060、RTX 4060 级显卡在目标画质下保持 60 FPS。

## 第一阶段：窗口与可用设置（本轮）

- 显式保留 1152×648 UI 逻辑画布，默认物理窗口提升到 1920×1080。
- 支持窗口模式与无边框全屏。
- 支持 1280×720、1600×900、1920×1080、2560×1440、3840×2160 窗口分辨率。
- 支持 85%、100%、115%、130% UI 缩放。
- 显示设置即时生效并独立保存到 `user://display.cfg`。
- 截图与性能自动化不读取个人显示存档，保证结果可重复。

## 第二阶段：分离 3D 渲染比例与 UI 分辨率

- UI 永远以窗口原生像素绘制。
- 3D 增加独立渲染比例，建议档位为 70%、85%、100%。
- 只有 3D 场景允许使用缩放器；文字、准星、小地图和菜单禁止随 3D 降分辨率。
- 对比原生、FSR 与双线性缩放，选择不会破坏低多边形硬边轮廓的方案。

## 第三阶段：重构本地分屏

- 取消每块固定 1152×648 的渲染纹理。
- 每块 3D 视口根据实际物理占屏尺寸与 3D 渲染比例计算像素数。
- HUD 从 3D SubViewport 纹理中拆出，以窗口原生分辨率分别裁切到各玩家区域。
- 重新决定横向、纵向分屏及宽高比策略，避免 16:9 屏幕上的大面积黑边。

## 第四阶段：1080p UI 精修

- 去掉武器面板 72%、生命与小队面板 88% 等历史二次缩放。
- 按 1080p 重新确定字体、行距、边框与切角尺寸；细线最低使用 2 个物理像素。
- 引入明确授权、覆盖中英文的游戏字体，替代 `ThemeDB.fallback_font`。
- 建立 16:9、16:10、21:9 和高 DPI 截图对照，检查重叠、留白与信息层级。

## 第五阶段：性能与验收

- 固定测试 1920×1080、2560×1440、双人分屏三组基线。
- 记录平均 FPS、1% 低帧、绘制调用、图元数和显存占用。
- 最低验收：目标显卡 1080p 单人 60 FPS；分屏单列预算并明确所用画质档位。
- 每轮场景升级都使用相同机位、敌人数与采样时长，禁止拿不同分辨率成绩横向比较。
