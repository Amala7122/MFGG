# ruin-star 移植补齐：地面反馈与动态投放

2026-10-08，对照本地 `godot-ruin-star` 与 `godot-ruin_star_new`，补齐用户指出的地面反馈和敌人投放差异。

## 地面反馈

- 手雷的地面焦痕调用在合并时遗漏，现已恢复，并加入爆炸扬尘。
- 原版脚步函数已复制，但复用了带闪光与点光的命中火花，并以角色中心减固定高度求落点。现在使用不发光的独立扬尘，按左右脚步态触发，查询实际碰撞地面。冲刺更明显，落地按冲击强度扬尘；静止、翻滚、特写和暂停不产生行走脚步。
- 原版死亡特效文件本身已完整复制，但地面环被额外旋转成竖直方向，且高度仅来自高度场。现在环沿真实地表展开，倒地、碎片和次级殉爆适配实际平台和坡面；焦痕挂在场景上，散体退场后继续保留。
- 首领原先只把外壳网格移交给死亡演出，核心仍随实体销毁。恢复模型容器，一起执行倒地、碳化和拆解；网格收集兼容根节点本身就是网格的情况。
- 共鸣爆发也改为从实际支撑面发出，避免平台下出现光柱、地表环和焦痕。
- 泥偶、晶兽、沉积泰坦保留自己的物理散架并加入地面反馈；晶刺蜂尸体实际砸地后才扬尘。
- 扬尘并发最多 48 个，淡出后自动释放；弹痕/焦痕共用原有 96 个上限，场景退出同步清掉登记。无真实地面时，不生成新的扬尘爆发或焦痕。

## 动态小队投放

合并时丢失了原版的 `_build_squads`、动态中心、成员散布与安全选点路径，变成固定锚点轮转。

现在保留原版 2～4 人编组、组内 0.25 秒和组间 0.85 秒的节奏。小队中心在即将投放时围绕玩家选择，后续成员在 1.4～3.2 米内散布；每个实际位置重新校验。默认离所有玩家至少 14 米，离最近玩家至多 32 米，优先选择镜头外或遮挡后的点。

安全校验包括地图边界/保留区、真实地面与坡度、该兵种放大后的身体空间、已有敌人占用和导航连通性。没有导航的实验关只接受有连续支撑的直线路径。固定锚点仅是通过相同校验的兜底；找不到安全位置时保留预算和小队成员，0.35 秒后重试。首领也使用动态选点，失败后重试且不累加虚假波次。大型普通敌人的出生高度按放大后胶囊计算。

正式出场顺序仍沿用项目当前配置。测试在隔离进程中临时打开全部五张已有地图定义。

## 可调参数

全部位于 `data/game_config.json`。

| 目的 | 路径 | 默认值 |
|---|---|---|
| 行走/冲刺扬尘强度 | `ground_feedback.walk_dust_strength` / `.sprint_dust_strength` | 0.35 / 0.55 |
| 落地扬尘基础/冲击增量 | `ground_feedback.landing_dust_base` / `.landing_dust_impact_scale` | 0.55 / 1.5 |
| 扬尘并发数量 | `ground_feedback.max_dust_effects` | 48，硬上限 48，0 可关闭 |
| 组内/组间投放间隔 | `spawn.squad_member_interval` / `.spawn_interval` | 0.25 / 0.85 秒 |
| 投放最小/最大玩家距离 | `enemy_roster.anchor_min_player_distance` / `.anchor_max_player_distance` | 14 / 32 米 |
