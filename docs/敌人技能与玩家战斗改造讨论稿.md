# 敌人技能与玩家战斗改造讨论稿

记录日期：2026-09-26

## 1. 用户提出的方向

- 每种怪都应有能体现特色的特殊技能，部分技能可以带地面效果。
- 巨型破坏者可以冲锋，冲锋前在地面显示红色轨迹预警。
- 取消手雷，替换为近战技能；近战能够击退小型怪。
- 将某些现有怪调整为狙击手，攻击前有红线预警。
- 主角的狙击改成镭射激光，增强视觉效果。
- 保留并优先考虑原方案中的步态参数化，让敌人通过明显不同的行动方式增加辨识度。
- 先讨论并形成文档，再开始实现；敌人尚未完全定型，优先考虑见效快的做法。

上述是本稿的设计方向。具体技能、按键、参数、打断关系和制作顺序仍可修改。

## 2. 本轮设计目标

每种敌人都要让玩家形成一条清楚的记忆：它准备做什么、该怎么躲、躲完能怎么反击。

一项招牌技能由四部分组成：

1. **触发条件**：在合适距离、视线和冷却条件下使用，而不是一直放技能。
2. **预备与预警**：身体动作、地面图形或瞄准线共同告诉玩家危险来自哪里。
3. **实际攻击**：伤害区域与预警一致；命中发生在出手阶段。
4. **收招与反击机会**：成功躲避后，敌人要留出玩家能利用的窗口。

技能决定应对方式；步态、声音、受击和死亡反馈负责强化这种身份。继续使用旧 juice 方案中的预设思路，但不以加大晃动、延长闪白或提高血量来代替技能设计。

步态参数化是本轮第一优先级之一。敌人尚未攻击时，玩家就应能通过姿态、步幅、起步、转身和停步读出它的行动特点。它与招牌技能一起建立身份，不等所有技能做完再补。

## 3. 先做的一组战斗关系

建议首轮围绕下列关系验证，不要求同时完成全部 15 种敌人：

| 敌人压力 | 玩家选择 | 应有的收益 |
|---|---|---|
| 小怪快速贴近、准备扑击 | 朝前方使用近战扫击 | 推开小怪，打断扑击，重新获得射击空间 |
| 巨型破坏者红色轨迹冲锋 | 横移或翻滚离开轨迹 | 巨怪冲空后停顿，允许攻击侧面或背面 |
| 狙击手红线锁定 | 找掩体，或在锁线后横移 | 敌人射空并进入装填窗口 |
| 迫击炮落点预警 | 离开圆形区域 | 接近炮手或继续输出其他目标 |
| 多个敌人排列成一直线 | 主角镭射射击 | 清楚看到光束穿透与逐个命中，获得站位收益 |

这样，近战、翻滚、掩体和激光都有明确用途。

### 3.1 步态与行动方式：持续可见的身份

用户明确认可原方案的步态参数化方向。第一轮同时建立三个重量档和一个远程移动姿态，后续再扩展到具体物种。

| 行动类型 | 姿态与步态 | 起步、转身和停步 | 与技能的衔接 |
|---|---|---|---|
| 轻快追猎型 | 身体压低，短快步，肢体摆动干脆，躯干起伏克制 | 快起步、快改向，扑击前有明显收身 | 短快步接近后，收身动作清楚地进入扑击准备 |
| 普通战士型 | 直立、中等步幅，肩胯有适量协调运动 | 常规加速，转身自然，攻击前踏稳 | 作为基准，抬武器和挥击时序最容易读懂 |
| 重装推进型 | 重心低、步幅宽，步频低，肩胯缓慢移重，脚步落地清楚 | 起步慢，转弯有身体滞后，刹停要收脚 | 巨怪冲锋前由沉重行走切换为压身蓄力，冲锋后重刹 |
| 远程持枪型 | 侧移时使用侧向步态，上身与武器稳定，不边移动边大幅摇枪 | 短段移动后站定，站稳再瞄准；换位时恢复横移 | 狙击手红线出现时停止走步，身体进入稳定瞄准姿态 |

第一轮应能在统一颜色、隐藏名字的条件下，看出轻怪在追、重怪在推进、射手在换位。现有 15 个条目可先使用这些行动类型，再用少量参数覆盖形成差异。

步态预设至少包括步频、步幅、膝部弯曲、躯干前倾、肩胯摆动、摆臂幅度和姿态恢复速度。行动参数包括加速、刹停、转向及站定策略；它们要与视觉姿态配合，避免动作看似很重，实际却瞬间启动和调头。

设计与实现约定：

- **实际移动驱动步态**：速度、体型和步幅共同影响步频。停住、被挡住或进入蓄力时要收脚，不能仍在原地跑步。
- **按运动方向摆腿**：前进、后退和横移不能都播放同一套正向奔跑；远程敌人朝玩家瞄准时尤其要区分。
- **身体稳定性也是差异**：轻怪用干脆的腿部运动表达敏捷，重怪用缓慢移重表达重量，不靠整身高频上下抖动。
- **行走与出招形成连续动作**：追猎者收身、重怪踏稳、狙击手架枪，都是步态结束并进入技能的信号。
- **允许替换模型**：配置描述轻快、沉重或稳枪的目标，具体骨架负责实现。未来兽形或机械模型不必硬套人形摆臂与摆腿。
- **保持参数入口精简**：先用少量共用预设加个体覆盖，不给每个图鉴条目复制完整的动画参数表。

步态单独验收：只看敌人接近、转身和停步，不展示技能、名字和颜色，也能分清轻快、普通、重装与远程换位。然后再验证这些行走特征能自然接到各自的招牌技能。

## 4. 巨型破坏者：红轨冲锋

### 4.1 技能表现与规则建议

**压低身体、刨地蓄力 → 红轨逐渐明确 → 方向锁定 → 直线冲锋 → 重刹或撞墙 → 恢复。**

- 只在中距离、前方有可行进路段时发动；贴脸时使用普通重击。
- 蓄力前段可以缓慢调整朝向，最后一段锁定轨迹；方向锁定用停止转动、箭头和明确音效表示。
- 地面预警显示冲锋的实际宽度和长度，并带方向箭头。只画细线无法说明巨怪整个身体的危险范围。
- 锁定后沿预告方向冲锋，不在高速移动中持续追踪玩家。
- 冲锋被实体障碍阻挡时终止，不能穿树、穿墙或直接跨过不可通行的落差。
- 每次冲锋对同一目标最多造成一次冲锋伤害，避免接触的每一帧都扣血。
- 冲空后有明确收招；撞墙可给予更明显的踉跄，作为利用场景的奖励。
- 首版不附加持续伤害地带。先把预警、冲锋和反击窗口做清楚，之后再讨论裂地余效。

### 4.2 原型试验起点

| 项目 | 建议起点 |
|---|---|
| 总蓄力 | 约 1.0 秒 |
| 最后锁向阶段 | 约 0.3 秒 |
| 冲锋距离 | 约 8–12 米，受场地限制 |
| 冲空收招 | 约 0.8–1.2 秒 |
| 再次冲锋间隔 | 约 5–7 秒，不包含未满足触发条件的等待 |

距离和速度要一起验证：必须留出看懂预警并离开轨迹的时间。坡面预警需要贴合地面，不能漂浮，也不能被大面积埋进地形。

### 4.3 待讨论：主角能否打断冲锋

建议普通近战能打断小怪的蓄力，不能正面击停已经冲出的巨型破坏者。巨怪主要通过躲轨迹、诱导撞墙和攻击收招来应对。

是否允许激光爆头打断巨怪蓄力，留待后续验证。这会明显改变激光的战略价值，不能只作为视觉改造顺带加入。

## 5. 主角近战：替换手雷

### 5.1 定位建议

建议先做**快速的前方扫击**：小范围、多目标、中等伤害、对小怪有明显击退。用途是打断贴身威胁、创造射击空间，也可用来补刀。

- 暂定沿用现有手雷的 E 键；实验场的 F 键是已有试验操作，最终按键仍待讨论。
- 前方扇形判定，方向跟随角色实际出手方向；攻击动画与命中帧对齐。
- 小型怪后退或短暂腾起，并取消可打断的扑击准备。
- 普通怪可以短暂受击，击退较弱。
- 重型怪表现为局部震动，不被整只抛飞；特殊技能是否中断遵守单独规则。
- 隔着墙或掩体的目标不能被扫到。
- 命中同一个目标只结算一次；一次命中多怪时合并镜头反馈，避免顿帧与震动重复叠加。
- 不默认附带无敌，也不默认所有小怪一击必杀。这两项需要结合伤害和冷却单独讨论。

### 5.2 原型试验起点

| 项目 | 建议起点 |
|---|---|
| 范围 | 前方约 120–150°，距离约 2.5 米 |
| 前摇 | 约 0.08–0.12 秒 |
| 收招 | 约 0.15–0.25 秒 |
| 冷却 | 约 1.2–1.8 秒 |
| 小怪击退 | 目标效果为退开约 3–4 米，遇墙缩短 |
| 同次目标数量 | 可先沿用实验场最多 3 只的试验规则，再比较全扇形命中的版本 |

击退距离以实际运动结果验收，不能仅用一个推力数值代替。普通挥击、命中和击杀要有不同反馈，落空不应播放强烈命中效果。

### 5.3 与 Q 键脉冲的区别

当前 Q 已是以玩家为中心的大范围推开技能。若新近战也做成大半径全周攻击，两者用途会重复。

首轮建议：E 为频繁使用、需要朝向的近战扫击；Q 暂时保留为长冷却、全周救急。后续讨论是否把 Q 改成护盾、位移或另一种能力，不在取消手雷时自动扩大改造范围。

手雷退出正式操作时，应同步处理技能栏、提示、冷却和相关数值。旧手雷资源可以先保留为历史资源，不必在验证近战的同一轮删除所有文件。

## 6. 敌方狙击手：红线锁定

建议首先把现有“点射游骑兵”作为候选改成狙击手；它本来就在较远距离活动。最终名称和造型待定，侦察射手可继续承担机动散射职责。

### 6.1 技能节奏建议

**选取射位 → 站定抬枪 → 红线跟随瞄准 → 红线锁定 → 单发射击 → 装填或换位。**

- 蓄力前段红线跟随目标，最后一段锁定世界方向，不能在开火瞬间重新瞄准玩家。
- 红线从实际枪口指向瞄准点，并被地形和掩体截断；不能画出穿墙命中的假信息。
- 开火前再次确认路径上的遮挡；遮挡成立时不能继续伤到墙后的玩家。
- 命中判定沿红线提示的攻击范围执行，锁定后横移应能有效躲避。
- 被近战击退时可取消蓄力，给接近狙击手明确收益。
- 初版只做单发，不同时叠加连续狙击、地面爆炸和额外弹幕。
- 单靠红色不够：红线跟随与锁定状态还要用亮度、脉冲、端点标记和音效区分。

原型建议总瞄准约 1.0–1.3 秒，最后约 0.3–0.4 秒锁线，射击后约 0.7 秒装填停顿。具体射速和伤害必须与可躲避性一起调试。

红线是开火前的威胁提示，实际射击另有短促光迹和枪声。是否使用瞬发射线，或极快但可见的弹体，仍为待讨论项。

## 7. 主角狙击：镭射激光

### 7.1 首轮建议：单发脉冲激光

保留当前瞄准与单发穿透的操作节奏，将枪口、射线轨迹、命中和声音统一为镭射表现。

- 光束使用青白色核心与外层光晕，和敌方红色预警区分。
- 开火时显示一条完整、短暂保留并快速收束的光束；枪口有短促能量爆发，命中点有对应能量反馈。
- 光束末端与实际射线阻挡点一致；穿过敌人时显示逐个命中的反馈，到墙体处终止。
- 初版伤害只结算一次。光束的视觉停留不能按每帧再次扣血。
- 当前狙击已有最多穿透 3 个目标的规则，可作为第一版基础；射程、伤害、爆头倍率和弹药节奏先沿用现有规则进行对照。
- 先加强光束、声音和枪身反馈，再判断是否需要额外蓄力或改变弹药名称。不能用过强的画面泛白遮住敌人的预警。

这一路径改动集中、视觉收益明显，也便于将“表现提升”和“武器变强”分别判断。

### 7.2 可选后续方向：持续激光

持续激光意味着按住发射、持续伤害、能量或过热、扫射宽度及穿透规则都要重新设计，可能承担与当前主武器不同的职责。

它不是本稿默认方案，也不是单发镭射的必然后续。若选择持续激光，应单独讨论操作、资源和强度，再写入定案。

## 8. 全部现有敌人的招牌技能候选

以下 15 项均为设计建议。每种敌人有独立可描述的招牌技能，制作时可以共享扑击、冲锋、扇形攻击、射线和地面区域等基础能力。模型和名称以后改变，也可以保留技能身份。

| 当前敌人 | 招牌技能候选 | 玩家看到的信号 | 应对与反击机会 |
|---|---|---|---|
| 侦察射手 | 侧闪反击：玩家接近时短侧移，再散射 | 侧移准备动作，射击前短暂停顿 | 追近，用近战取消射击准备 |
| 小型追猎者 | 短距扑击：接近后收身，再向前扑 | 蹲伏与短箭头提示 | 横移，或近战击退并打断 |
| 近战士兵 | 蓄力直刺：向前跨一步刺击 | 抬武器，窄短矩形预警 | 侧移，攻击收招 |
| 点射游骑兵 | 改为狙击手：红线锁定单发射击 | 枪口红线，锁线提示音 | 掩体、锁线后横移，或接近打断 |
| 迅捷刀手 | 二连横斩：两次有间隔的扇形攻击 | 第一次抬刀，第二次反向抬刀 | 避开第一刀后仍要读第二刀；结束后反击 |
| 重装战士 | 地裂重锤：短距离扇形地面冲击 | 举锤，前方扇形裂纹预警 | 离开扇形或绕背，砸空后攻击 |
| 旋流术士 | 地面旋涡：在目标附近放置持续危险区 | 圆形符文先成形，再激活 | 移出圈并接近施法者；减速效果另行讨论 |
| 弹墙炮手 | 封路射击：用几条平行危险带限制路线 | 分开的条形预警，保留明显安全间隙 | 找间隙，趁炮手架枪时换位 |
| 狂战士 | 狂怒连劈：蓄力后连续向前推进挥砍 | 吼叫、身体前倾、逐次扇形提示 | 拉开距离，连劈结束后近战或射击 |
| 大型盾卫 | 举盾推进后盾击 | 举盾姿态，盾击前大扇形预警 | 绕侧面或背面；盾击落空暴露身体 |
| 疾行刺客 | 侧绕突刺：先快速侧绕，再锁向突进 | 可见侧绕，随后短直线预警 | 识别最后突刺方向，横移或近战截停 |
| 重型迫击炮 | 连续落点炮击：顺序轰击多个位置 | 有顺序提示的地面圆圈 | 连续走位，避开已亮起的落点 |
| 巨型破坏者 | 红轨冲锋 | 宽红色轨迹、方向箭头、锁向动作 | 横移、翻滚、诱导撞墙，攻击收招 |
| 精英剑士 | 架势反击：短暂进入招架状态，受正面攻击后准备反击 | 明确架势，随后显示反击扇形 | 停火或绕侧；反击仍须给躲避窗口 |
| 猎杀幼体 | 跳扑落地：锁定小范围落点后跃起攻击 | 收身动作，小圆圈落点预警 | 离开落点，或在起跳前近战打断 |

第一轮优先验证小型追猎者、巨型破坏者、敌方狙击手。现有迫击炮作为地面圆圈预警的参照，普通士兵作为近战时序的参照。其余候选根据试验结果逐项完善，不一次把全部技能固定下来。

盾卫的正面减伤、精英剑士的招架，以及旋涡的减速等涉及额外判定或状态，宜放在第一组基础技能验证之后。攻击不能因“反击”名义省略前摇，也不以全向免疫或无法接近来表达精英身份。

## 9. 地面效果与预警的共用约定

### 9.1 图形含义

| 图形 | 主要含义 | 例子 |
|---|---|---|
| 宽条带与箭头 | 沿确定方向移动的危险 | 巨怪冲锋 |
| 窄射线与端点 | 瞄准、锁定并准备射击 | 狙击手 |
| 扇形 | 前方范围攻击 | 横斩、重锤、盾击 |
| 圆圈 | 固定落点或区域攻击 | 炮击、跳扑、旋涡 |

红色表示敌方威胁，图形说明攻击形状；明暗、填充和声音说明何时生效。主角近战可用暖白或橙色，主角激光用青白色。颜色不是唯一信息来源。

### 9.2 预警与持续区域分开

- **预警阶段**：即将发生危险，区域尚不造成该技能伤害。
- **攻击阶段**：与预告的区域和方向对应，产生一次或明确次数的伤害。
- **持续阶段**：仅在技能本身需要时存在，显示不同的激活纹理与剩余状态。
- **结束或取消**：立即撤去该技能的伤害判定，并清楚撤去预警或危险区。

首轮先实现预警与一次性攻击。持续区域先限于一种，例如术士旋涡，验证玩家能否辨认，再扩展灼烧、减速等效果。

复杂地形下，不能让平面图形穿越山坡、落差和掩体，暗示实际不存在的攻击范围。圆圈、条带与碰撞判定需要在正式场地验证，而不只在平地测试。

### 9.3 同时出招的压力

第一版需要限制高威胁技能同时发动的数量。可先以同屏最多 1–2 个冲锋或狙击锁定作为试验起点，再根据场地和敌人组合调整。

技能排队应发生在预警开始之前；不能让红线已经锁定却因排队迟迟不开火，也不能为了排队在最后一刻缩短预警。小怪普攻不必全部等待这一限制。

## 10. 与当前工程的衔接

以下为实现阶段的注意事项；原讨论时的现状作为设计依据，最新实现进度见分步实施计划：

- 现有普通敌人共用近战与远程行为脚本。应增加技能阶段和每实例配置，避免为每个图鉴条目复制整个敌人脚本。
- 现有 EnemyRig 已有步频、摆腿、膝部、前倾、起伏、摆臂和姿态平滑参数，适合接入步态预设。但目前跑步混合主要在超过基础速度后生效，前倾也绑定该混合，需检查参数能否在实际行走中生效；只往配置填数值不算完成。
- 现有近战伤害在攻击开始时就结算。引入预警后，必须把命中移动到出手阶段，并检查实际距离、朝向和遮挡。
- 刚修正的导航继续负责普通追击。冲锋、跳扑等特殊位移有独立规则，不能让追击寻路在每帧重新改写已锁定的技能方向。
- 现有迫击炮已有地面圆圈预警，适合复用部分表现；条带、扇形和射线仍需各自的图形与判定。
- 近战实验场已有扫击、命中帧、击飞和反馈。可复用验证过的动作与表现，但正式版需要按敌人重量和技能状态决定击退、击杀与打断，不能直接照搬实验场小兽一击必杀。
- 玩家狙击已有瞬发判定、爆头和最多 3 个目标穿透。单发激光可以先接在现有判定上，减少第一轮平衡变化。
- 当前 Q 技能是全周脉冲，新近战要与其定位区分。
- 当前波次以敌人退出场景树统计存活。延长死亡表现时，应让战斗对象及时退出，另播视觉残影，避免波次等待尸体消失。
- 特殊技能取消、敌人死亡、目标失效、暂停与重开都需要正确清理预警、命中和后续计时，避免出现没有施法者的残留攻击。

## 11. 建议的实现顺序与验收

完成讨论并形成定案后，再按以下顺序进入实现：

1. **步态辨识、攻击阶段与共用预警**：先建立轻快、普通、重装和远程横移的行动区别；统一准备、锁定、出手、恢复和取消，修正基础近战命中时机。
2. **主角近战与小型追猎者**：验证贴脸压力、击退和打断是否有用；退出手雷正式操作。
3. **巨型破坏者冲锋**：验证轨迹预警、锁向、障碍终止与冲空收招。
4. **敌方狙击手与主角单发激光**：验证红线威胁与青白光束能否清楚区分，躲线与穿透反馈是否成立。
5. **加入一类持续地面危险与更多怪物技能**：用前四步的实测结果继续扩展。

第一组验收重点：

- 不看名字、颜色和技能，仅凭行走、转身与停步能分辨行动类型。
- 不看敌人名字，能从动作和预警分辨扑击、冲锋、狙击与炮击。
- 玩家按预警采取正确行动，确实能躲开，而不是躲完仍被重新追踪命中。
- 近战击退后能获得可用的安全距离，小怪准备中的技能确实中断。
- 巨怪冲空或撞墙后有可利用的反击窗口。
- 激光视觉终点、穿透目标和伤害判定一致，不穿掩体，也不重复结算。
- 混合敌群中仍能读清预警；天气、草地、坡面和遮挡不会使关键提示失效。
- 死亡、取消和重开后无残留红线、危险区或延迟伤害，波次计数正常。

## 12. 下一轮讨论的重点

1. **近战形态**：前方扫击，还是周身旋斩？本文建议前方扫击，以区分 Q 脉冲。
2. **激光形态**：单发脉冲，还是持续光束？本文建议先做单发穿透激光。
3. **近战击杀规则**：小怪主要被击退，还是部分小怪直接被斩杀？需结合武器成长讨论。
4. **重怪打断规则**：巨怪只靠躲避与撞墙应对，还是可通过激光爆头打断蓄力？
5. **Q 技能去留**：暂留全周救急脉冲，还是与本轮一起换成其他能力？
6. **敌方狙击手身份**：先改点射游骑兵，还是从其他现有条目中选取？
