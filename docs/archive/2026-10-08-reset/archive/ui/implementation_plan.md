# 低多边形 UI 分阶段实施计划

## 总原则

- 优先改玩家在战斗中持续看到的界面，开始界面最后处理。
- 数字、标签、进度填充各占独立区域，禁止文字压在色条上。
- 统一使用直线、折线、切角、三角切面与大色块；不使用卷轴、雕花、布纹和玻璃拟态。
- 颜色按语义复用：生命红、护盾青、弹药金、危险红、交互青；森林绿和暖米色负责承托。
- 优先用 Godot 自绘多边形实现，保证缩放清晰并减少零散贴图依赖。

## 第一阶段：核心战斗 HUD（已完成）

- 共享主题色与低多边形面板原语。
- 生命 / 护盾三段式布局：图标、独立数字块、纯进度条。
- 技能卡片、武器面板、弹药格、武器剪影。
- 波次、计时、小地图、击杀信息重新统一。
- 正式界面默认隐藏 FPS。

### 第二轮品质升级（已完成）

- 常驻 HUD 整体缩减约 25%～30%，释放中心与四角战斗视野。
- 面板由单层描边升级为投影、暗金外框、青铜包边、内槽与低多边形分面。
- 进度条增加上下晶体切面；生命、护盾图标升级为多层徽章。
- 武器弹药由过密弹丸格改为紧凑比例条。
- 小地图、技能卡、波次条、武器面板和通知卡统一收窄。

### 第三轮语义材质拆分（已完成）

- 不再让全部组件复用同一块森林绿面板，拆分为红黑、青蓝、米金、浅米、军绿和钢灰六套材质家族。
- 生命采用红色装甲缝，护盾采用青色能量双轨，波次与击杀采用金色箭羽。
- 手雷与冲击技能分别使用金色、青色底板；狙击区与主武器区材质分离。
- 交互提示和即时通知改用浅米色卡片与深色正文，和常驻 HUD 明确分层。
- Boss 面板继承红黑危险材质，小地图继续保留森林绿导航材质。

## 第二阶段：战斗反馈（已完成）

- 动态准星和命中标记统一配色。
- 受击方向由圆弧改为多边形楔片。
- 低血量由柔和渐变晕影改为四角三角碎片。
- 首领条、伤害残影和波次格沿用统一原语。

## 第三阶段：即时信息（已完成基础版）

- 拾血、补弹、武器升级和模块拾取通知卡片。
- 击杀读数样式统一。

## 第四阶段：流程界面（下一阶段）

- 阶段完成、失败结算与奖励卡片。
- 暂停菜单、设置面板与确认弹窗。

## 第五阶段：开始界面（最后处理）

- 主菜单信息层级与背景构图。
- 关卡选择、开始游戏与退出入口。
- 首次进入、返回主菜单和继续游戏状态。
