## 文档使用原则

- 已实施的事实与候选方案分开写，避免“写进计划”被误认为“已经完成”。
- 当前优先级以“项目总进度与下一步”为主，不自动把旧讨论稿里的所有想法重新激活。
- 原型验证完成后，应补充正式接入状态，避免实验功能长期悬在半空。
