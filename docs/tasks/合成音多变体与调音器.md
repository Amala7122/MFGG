### 多变体怎么做的

同一个键用**同一组参数、不同随机种子**生成 N 个波形，用 `AudioStreamRandomizer` 装起来，
播放模式 `PLAYBACK_RANDOM_NO_REPEATS`（不连续重复）。关键约束：

- **参数一点没动**，只有噪声序列不同 → 音色不变。
- **变体 0 的种子偏移是 0**，所以它的波形与改动前**逐字节相同**；测试里用"两次重建结果相同"守住确定性。
- 变体数按键配置，只给高频重复的键配（连发、命中、脚步、弹壳、敌人射击）；爆炸这类低频键不配。
- 范围 1~8，1 = 关闭。构建 26 个键 + 10 个键带变体，实测 **63 ms**。

### 调音器怎么用

```text
Godot_v4.7.2-stable_win64.exe --path . --script res://tools/probes/audio_synth_tuner.gd
```

按键：

| 键 | 作用 |
|---|---|
| `1`~`6` | 选参数：时长 / 起始频率 / 结束频率 / 衰减指数 / 噪声占比 / 增益 |
| `←` `→` | 微调（按住 `H` 是粗调 ×10） |
| `Tab` | 7 发/秒（基础射速）↔ 10.5 发/秒（射速满级） |
| `V` | 变体数 1 → 2 → 3 → 4 → 6 循环 |
| `Space` | 暂停 / 继续连发 |
| `R` | 恢复 `data/game_config.json` 里的当前值 |
| `S` | 打印可直接粘贴进 `audio.bank` 的一行 |
| `Q` | 退出 |

调音器**不写项目文件**：调好按 `S`，把打印出的那一行写进
[game_config.json](../../data/game_config.json) 的 `audio.bank`，再跑游戏确认。
