### 怎么调

- **换音色**：改 `data/game_config.json` 的 `audio.file_bank`，值是路径字符串，或
  `{"path": "...", "loop": false, "volume_db": -3.0}` 对象。`volume_db` 逐键配平响度。
- **A/B 对比合成音色**：`audio.file_bank_enabled` 改 `false`；运行中改了配置可以调 `AudioUtil.reload()`
  立即重建音色库，不用重开游戏。
- **循环素材**：音效库里名字带 Loop 的文件导入后是 `LOOP_DISABLED`（I-032），
  必须在条目里写 `"loop": true` 才会在运行时打开循环。
- **三种兜底**：文件不存在 → 聚合一条警告并继续用合成音色；写法非法 / 不是音频流 → `push_error` 并回退；
  配置文件整体丢失 → 全部走合成音色。

## 下一步 / 已知限制

- **只保留 `shot` / `sniper` 两条文件音源**，其余 24 个键一律合成音色。**加新音效必须一次一条、单独试听**：
  首版一次接 17 条的直接后果就是用户「分不出谁是谁」。
- **4 个键仍是合成音色且音效库没有对应素材**：`heartbeat`、`footstep`、`casing_clink`、`bullet_whiz`。
  另外 `titan_charge` / `titan_takeoff` / `titan_land` / `titan_sweep` 四个键仍无调用点。
- **响度**：文件音源一般比合成音色响得多，`shot` / `sniper` 的 `volume_db` 目前仍是 0，需要复听时配平。
- **界面音没有层次**：13 处 UI 调用仍共用同一个 `ui` 键；要做点击/悬停/错误/滚动分层需要新增键和调用点，
  而 `game_flow.gd` 正被另一个会话改动，本轮没有碰它。
- **立体声素材用于 3D**：Godot 4 的 `AudioStreamPlayer3D` 支持立体声定位（`panning_strength`），
  文档没有"3D 必须单声道"的硬性要求；若要更聚焦的定位或想把导入体积再减半，
  可以对选中的文件开 `Force > Mono`（Godot 文档：多数音效可以转单声道）。
- **I-031 仍未处置**：整个音效库（导入后 45.2 MB）都会进发行包，而现在只用了 2 个文件。
  正确做法是把不用的文件移出项目，而不是加排除规则——排除会让已接入的文件也一起失效。
  这需要用户决定，本轮没有动任何音频文件。
