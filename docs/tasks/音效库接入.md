## 最新反馈

背景：上一轮按"样本有效长度 / 射击间隔"的测量离线渲染了 12 个枪声候选（裁剪、变调、合成多变体、混合），
让用户按 **7 发/秒** 试听。**结果全部被否。**

处理：

- `audio.file_bank` **清空** → `shot` / `sniper` 都回到 `audio.bank` 的合成音色
  （验证：`test_audio_file_bank.gd` 输出「file_bank 为空：26 个键全部走合成音色」，退出码 0）。
- 结论：**枪声不能用"我听不见、却按测量猜候选"的方式推进。** 听感判断必须由用户完成；
  我负责造工具和给入口，不再盲出候选。

### 怎么调

- **换音色**：改 `data/game_config.json` 的 `audio.file_bank`，值是路径字符串，或
  `{"path": "...", "loop": false, "volume_db": -3.0}` 对象。`volume_db` 逐键配平响度。
- **A/B 对比合成音色**：`audio.file_bank_enabled` 改 `false`；运行中改了配置可以调 `AudioUtil.reload()`
  立即重建音色库，不用重开游戏。
- **循环素材**：音效库里名字带 Loop 的文件导入后是 `LOOP_DISABLED`（I-032），
  必须在条目里写 `"loop": true` 才会在运行时打开循环。
- **三种兜底**：文件不存在 → 聚合一条警告并继续用合成音色；写法非法 / 不是音频流 → `push_error` 并回退；
  配置文件整体丢失 → 全部走合成音色。
