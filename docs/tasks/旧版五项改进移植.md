- 相比研究时，新版已经有通用手雷硬直、泰坦专属储备与三雷 / 晶体奖励相关实现；不动手雷接口、参数和 Boss 文件。

- 默认复现旧版轻扫 60、重击 180 / 3s，连段、0.4s 蓄力与 0.85s 自动释放；改用实际生效的单一秒时序，独立配置，不搬旧版同时生效与不生效的多套帧参数。
- 普通敌人近战通过现有伤害 / 统计 / 受击链路；穿甲只作用于护甲减伤，不套入泰坦泥盾。Boss 不获得旧占位 Boss 的必定弱点倍伤、破甲增伤或近战强制打断；现有奖励倍率继续由泰坦自己决定。
- 对形状查询按 actor 去重、处理零距离和大型碰撞边界，限制候选数量；不扩展百体核心或改寻路。
- 手雷和 Q 卡片原样保留，近战单独显示空格提示与状态。调参面板草稿即时生效、显式保存；日志 / 备份 / 临时文件使用项目外产物目录。
- 音效先复用现有合成音键，不覆盖或批量移入旧音频库，避免与新调音器重叠。

### 灰模试用反馈与处理分析（2026-10-18，未实施）

用户反馈“彩色光效，包括敌人子弹，浮游卫士，行走的灰尘效果”影响灰模；“土路没有网格确实很别扭”，提出必要时考虑实体道路。登记I-188 / I-189，沿用本任务。用户本轮要求先分析，不授权直接修正；截图为 `C:/Users/ZXG/AppData/Local/Temp/codex-clipboard-58588cde-6e67-41ce-b74a-e1c0b94d49ee.png`，已查看。可见青色卫士、黄色弹体与彩色地面光斑、无网格灰色路面；静态图不能单独验证行走扬尘的动态观感。

核对事实：

- `greybox_director.gd` 的PROTECTED_SCRIPTS把enemy_bullet / floating_wisp及多类战斗效果整棵子树列为保留；材质因此不接管，Light3D分支也保留受保护效果和玩家子节点的局部灯。保留“战斗信息”被实现成保留“全部原画表现”，是首版边界过宽，不是这些效果需要改变战斗机制。
- `scenes/enemy_bullet.tscn` 有发光弹芯、半透明Aura / Trail与2.4能量、2.2米范围的Glow；`enemy_bullet.gd::apply_color` 在setup / 池化复用时重写颜色。`floating_wisp.gd` 有青色光环 / 透镜 / 尾焰与DroneLight，普通 / 索敌 / 超频 / 开火时持续更新表现；其WispDart另有2.4米范围局部灯。不能只把灯能量或原材质颜色改一次，否则会被业务脚本再次写回。
- `ground_dust.gd` 是CPUParticles3D，黄褐色色带、透明Quad与软边纹理，本身不发光。当前灰模仅给MeshInstance3D / MultiMeshInstance3D替换材质，未接管此粒子；`player.gd::_on_footstep`确实调用同一扬尘实现。不能把它误判成需要“关灯”的效果，也不能套不透明网格材质破坏透明渐隐。
- `world_map_builder.gd::_valley_road` 已创建MeshInstance3D，顶点贴地，明确不创建独立碰撞；不是Decal。`greybox_palette.gd`刻意给道路StandardMaterial3D纯灰，并把它排除在网格参数列表外，所以道路无格线。现有`prototype_grid.gdshader`按世界坐标投影，可以直接在现有路面使用同尺度 / 同原点格线，不需要加几何厚度或碰撞。
- 道路有既有贴地高度；`attack_surface_mesh.gd`已记录黄色道路 / 石铺与预警的深度间隙约束。为网格重做道路高程 / 碰撞没有收益，反而会把移动、导航与预警贴地验证带进显示任务；不能直接断言新增实体一定修好读图或闪烁。
