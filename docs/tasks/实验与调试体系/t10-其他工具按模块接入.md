# T10：其他已有工具按模块接入

> 本文件是 [测试台体系摸底与规划](../实验与调试体系摸底.md) 的分片。
> 批次状态、依赖与验收门槛以主文件的批次表为准；本文件只保存该部分的调研／规划原文。


| 小批 | 范围 | 验收 |
|---|---|---|
| T10a 玩家模块 | F7 近战、F8 卫士／护盾面板归属到玩家相关模块，保留原快捷键作为兼容入口 | 暂停／返回不冲突；原有重播／时间定位与保存能力不退化 |
| T10b 声音模块 | 接入现有合成音调音器，界面能定位音色、循环试听与保存命名配方／明确选用 | 不再要求复制打印结果手改 audio.bank；保存、变体、射速与重读正确；音色好坏仍由用户听感判断 |
| T10c 导航／性能模块 | 已有导航观察与追击压力入口、参数面板和专用计量工具有统一目录和结果入口 | 继续用正式导航；性能采样独立运行，记录条件，工具 UI 开销不混入成绩；不改算法 |
| T10d 探针／自动测试目录 | 将摸底中的脚本入口与回归列为可发现工具，说明图形／音频需求、用途、参数和结果位置 | 支撑模块不伪装为可运行工具；退役项明确标记；复用 run_probe／run_acceptance 与错误门槛，不把任意脚本或整批测试自动常驻 |

声音、个人音量和公共性能／诊断模块同样接入全局调节目录，具体操作按真实运行能力开放；不能要求先切去某个台再调整。

T10d 是运行与结果目录，不能替代各模块的实际调参界面。第三方演示作为外部示例分类，不混入核心测试台或自动启用。已有合成音方案的用户判断保持，不借接入调音器替换音色。
