# T11：其余对象、动作和参数覆盖补齐

> 本文件是 [测试台体系摸底与规划](../实验与调试体系摸底.md) 的分片。
> 批次状态、依赖与验收门槛以主文件的批次表为准；本文件只保存该部分的调研／规划原文。


- **顺序**：先补当前已经有效且有用户调节需求的字段／对象，再覆盖其余已存在参数；战斗按技能模块逐个接入。视觉已有三纯外形与兜虫战斗样本保持，其他宿主模型编辑统一交T13；T11登记真实缺口与路由，不将只读观察写成可编辑。已经在前批完成的内容只复核，不重复开发。
- **覆盖对象**：以真实有效参数为准，逐项记录模块、界面、预览／重播、生效与保存；570 是前轮、732 是本次 schema 条目快照，均不当作实施时固定验收数字或同量全新控件。新 encounter、编组／波次／组策略、正式角色与其他配置中的有效可调项也需登记，不能只完成 7 份敌人表就宣称全工具完成。
- **缺口处理**：无实际读取／效果、未实现的建模／动作能力、保留未投产对象都明确分类。已支持参数不允许以“手改文件”作为交付流程；确实需要新开发的能力保留未开始范围，不造空控件、不静默复活废弃字段。
- **验收**：按对象／模块抽查界面定位、数值反馈、保存重开与跨台采用；覆盖守卫能列出缺口。发现问题即时登记；玩法变化或高成本新能力另定范围，不将整合无限扩展。
