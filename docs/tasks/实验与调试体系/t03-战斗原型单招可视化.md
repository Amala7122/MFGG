# T03：战斗原型测试台单招可视化

> 本文件是 [测试台体系摸底与规划](../实验与调试体系摸底.md) 的分片。
> 批次状态、依赖与验收门槛以主文件的批次表为准；本文件只保存该部分的调研／规划原文。


- **编辑归属与返回**：只开放个体战斗／技能／策略参数；外形和编组编辑通过对应台入口。参数页和观察预览复用T02共用返回组件与调用栈，往返保留同一草稿、输入与技能选择；已有单招观察／范围放宽等功能只复核实际缺口，不重复开发。体型联动与需重建状态不得在返回时退回旧值。
- **范围**：以一项当前已实现技能打通属性／形态／时序模块；支持站桩、固定目标／朝向／种子、固定时刻显示，调整长度／宽度／夹角等当前实际支持的字段。
- **交付**：固定画面即时更新预警与判定几何；单次播放、重播、进入真人交战。预览采样和正式技能共用几何／时序定义，按需抽出当前实现的最小共享部分。
- **执行边界**：按 T00 结论区分轻量采样与完整物理预览，后者优先独立进程复用正式实现／快照；不为即时编辑另造一份技能数值或宣称所有敌人可在同进程安全并存。
- **验收**：对比修改前后预警轮廓与危险／安全采样点，真实命中与显示一致；参数来源与保存值一致；试打沿用同一草稿。下一招应用与需重建参数有正确提示。
- **边界与入口**：由 `combat_lab.gd`、现有参数面板、试点技能／特效和真实攻击区域实现演进。此批不重写整个技能系统，不改原技能强度与行为，不承诺全物理战斗任意时间倒放。

## T03执行：三线重击试点（2026-10-21）

状态：**首版完成，相关自动／后台图形复验通过，等待用户体验，本批停止**。用户明确授权继续T03，目标是站桩定格时调整真实三道范围与时序，随后单次重播或转真人试打；固定目标／朝向／种子，复用同一对象草稿与返回。硬约束为不改正式默认、不复制技能数值、不同时运行两个物理世界、不把几何时间定位冒充完整肢体倒放。用户偏好仍为小字号、高密度、清晰入口。

已核对：当前七敌人单招重播／暂停／范围线已存在，但观察时没有形状编辑入口；三线重击实际在titan_rage_director构建三块矩形并锁定，观察适配另算合并轮廓，其中高度还与实际4.1米不同，需统一共享定义。I-331返回条与观察首行重叠会在本台布局接入时一并修正。

比较三种落地方式：保留现状、每次输入都重建完整样本，能复用真实技能但破坏固定时刻且反复生成；独立进程完整预览隔离更强，但需要T04通信／窗口与父现场恢复，本台当前没有并存正式现场，不先接跨进程平台；推荐在当前测试场暂停物理、用共享纯数据几何／时序定义即时采样，再复用现有真实单招重建试验，始终只运行一个战斗世界。先用真实命中危险／安全点与原有狂暴回归检验共享抽取，不改玩法。

**本批实现与体验入口**：战斗原型台F6 → 沉积泰坦“调参” → “观察本草稿” → 技能选“三线重击” → “定格编辑”。空间台继承该入口。项目默认未启用狂暴编排时需明确勾选“启用”，面板说明真实施放条件，不偷偷开玩法开关。长度／宽度／夹角、前摇／后摇可在固定几何时刻即时预览，伤害／结束冷却在同一视图调整、在真实重播／试打验证。单次收势后自动冻结；真人试打重建同一完整合法草稿，开启玩家与真实AI，便利条件沿配置区。准备期间立即返回可取消待完成交接；“收起编辑”保留草稿并说明当前样本待重播。

- `skill_shape_panel.gd`仅是现有enemy_tuning_panel的紧凑视图，复用其字段、原文、校验、共享会话及返回，没有建立第二份保存配置。非法输入持续显示字段／原文／范围／恢复建议，完整原因悬停可读，返回仍可继续修正。数字框同步原生值与精确文字；失焦格式化回调不作为新修改回写，晚到的格式化只修复非编辑框显示，不改用户输入／数值／焦点。七个字段在窗口／缩放下均有实际可见范围断言。
- `titan_triple_slam_definition.gd`抽取当前真实快照、三道几何和时序，titan_rage_director与观察适配共用；保留真实固定4.1米高度、锁向、同时命中、重叠去重及原伤害倍率。冻结只采样数据，不生成伤害区或推进世界；运行仍走原攻击入口。原七敌人观察及外形／技能职责保持。
