# T09：天空、云与天气模块

> 本文件是 [测试台体系摸底与规划](../实验与调试体系摸底.md) 的分片。
> 批次状态、依赖与验收门槛以主文件的批次表为准；本文件只保存该部分的调研／规划原文。


- **拆分**：T09a Sky3D／日月时钟与基础光照；T09b 云形、云量、移动与云影；T09c 雨雪风／雾与天气时序。共用包／草稿，按模块逐小批接入，逐项说明范围、单位、生效和重复观察方法。
- **全局可达**：Sky3D／时钟、云层、天气／风分别注册到同一公共目录，逐台F6可直接调整当前场景，支持无玩家与已暂停。识别自带环境或经明确操作临时挂载的兼容环境；不只在天气或Sky3D专用场景可用。
- **场景控制**：场景可继承／开启／关闭相关系统；关闭天气／Sky3D 后，室内光照、后处理和独立局部雾仍可工作，全局管理器不能重新强加模块。
- **验收**：现有天气场景作为观察布景，实际地图作为效果验证；同包／固定时间与种子跨场景可复现。没有现成室内入口时，只用最小测试夹具验证“无天空／无天气但保留环境”，不把新地下关卡建设纳入本任务。
- **边界与入口**：WeatherSystem／Timeline、Sky3D 适配、WeatherEnvironment、Graphics／WorldBackdrop 及旧两个天气入口。整合不默认修复既有天气观感或重做天气平滑算法；若发现参数无效登记问题，另行限定修复范围。
