# 圣所回廊：编辑器优先试作与宗教化/环路改造

状态：实施中，首版+多轮反馈修订已完成；2026-10-28 主祭坛圣徽与高坛陈设精修完成，**等待用户验收**。  
不是正式主场景，不接战斗、波次、导航、天气。

## 目标

- 把老圣所从“大草坪 + 远处门 + 单入口”改成紧凑、可编辑、多入口、可绕行的圣所空间。
- 编辑器优先：地图几何是普通节点，可直接在编辑器里移动/改材质；运行时只保留预览角色脚本。
- 先做可步行预览，不接战斗。
- 视觉上从“城堡”转向“宗教圣所”：钟塔、山花、玫瑰窗、十字、双坡屋顶、回廊庭院、暖石；去掉城垛、箭孔、铁闸。
- 解决可达性：两侧大庭院可进入；小礼拜堂之间不必回中庭；入口不只南门。

### 立面构成（从后到前）

- **石环**：整块石料雕出的圆窗外框，内 2.15–2.20 m、外 2.50–2.55 m，前脸有内外倒棱；表面只刻 16 道浅分缝。225° 处留一道较宽的裂缝并加铁锔，读作遭袭后的修补。第一版曾把环切成 24 块深缝楔石，近距离会读成齿轮/轮盘，已弃用；现在浅缝是“整石表面的刻线”，不是深槽。
- **雪花石圆盘**：直径 4.2 m、厚 0.30 m，暖白自发光 0.42。它读作嵌在墙龛里的背光石：雪花石本身透光，墙内藏灯；因此不再需要一盏从殿内打来、没有灯具的射灯。
- **鎏金铜带**：内 2.02 / 外 2.09 m，平嵌在石盘边缘，前凸 1.8 cm；旧版悬空的圆环换成了贴面的带。
- **玄武岩鲸形浮雕**：宽 3.21 m、凸 0.09 m；腹部与眼斑用同一种雪花石嵌片（扩边 0.012 m、凸 0.02 m）补回，正面哑光近黑。这样读法就是参考图的“黑鲸 + 白留白”，而不是把整只鲸涂白。
- **溢光**：石盘前 0.95 m 的 0.5 能量暖色 Omni，只负责把石框、铜带和浮雕侧壁照亮；解释为背光石透出的光，不是独立灯具。
- **撤掉**：旧蓝玻璃玫瑰窗、8 根石辐条、高坛金十字、6.3 m 金环、圣晶背后的金环。最后一项会从正面横切圣徽；金十字与辐条则让新的鲸形标志读不清。
- **分组**：`Sigils` / `WhaleSigil`，节点在 `Hall/WhaleSigil`。

### 高坛陈设

- **亚麻台布**：覆盖 2.70 × 1.95 m 桌面，前垂 10 cm，下缘折边 + 3 条压痕；颜色改为暖奶白，避免与背光圣徽抢白。
- **深红前帷**：2.04 × 0.72 m，挂在祭坛主体正面，金线滚边；颜色与南门/中殿深红幡一致。
- **六支蜡烛**：3+3 分列圣晶两侧，高度 0.44–0.60 m 成拱；黄铜接蜡盘接滴蜡；替代原来的 7 支随机散落蜡烛。
- **圣晶石座**：低矮深色石座（顶半径 0.63 m、外 0.69 m，高约 0.10 m）+ 金箍；晶体插进座内约 0.10 m。旧的外置金环撤掉，晶体不再像悬在金环上。
- **压边**：祭坛基座顶沿加出挑压边；三级台阶前缘各加 4.5 cm 石压边，既有防踩损作用，也让台阶在逆光下读出厚度。
- **清理**：移除高坛后墙脚下的 `HallRubble` 大石块。它挡在圣徽前，读成乱堆；遭袭痕迹保留在东回廊、中殿侧廊与坍塌口。
- **十字架**：不再立在高坛正面；屋顶两端、钟塔尖顶、门楼封印和墓地仍有十字。鲸形圣徽成为寂石圣所自己的标志，这是用户参考图的直接结果，不是把宗教性删掉。

### 每个细节的理由

| 细节 | 为什么存在 |
|---|---|
| 整体石环 + 浅分缝 | 圆窗的承重石框；分缝是整石表面的刻线，方便对位/装饰 |
| 225° 裂缝 + 铁锔 | 遭袭后石框裂开，教团用铁锔夹住；与“据守、修缮”设定一致 |
| 雪花石背光 | 雪花石透光，墙内藏灯；白色是石材本身，不是涂白 |
| 玄武岩浮雕 | 近黑细石适合做浅浮雕，和雪花石形成黑白对照 |
| 鎏金铜带 | 保护石盘边缘、给圣徽一圈金属界限 |
| 亚麻台布 | 祭坛桌面需要可清洗的布；前垂和折边是实际做法 |
| 深红前帷 | 高坛正面的礼仪色布；与圣所其他深红幡统一 |
| 六支对称蜡烛 | 高坛的礼仪对称；黄铜盘接滴蜡，保护台布 |
| 圣晶石座 | 圣物需要插座/固定；金箍是座口收边 |
| 台阶/基座压边 | 石构件边缘的实际防踩损收边 |
| 移除高坛石块 | 教团会把主祭坛周围清理干净；损坏留在别处 |

## 总平面重构（待确认）

用户指出：当前所有东西都在同一圈主墙内，读成一栋主建筑；要的是**主建筑 + 真正独立的附属建筑群**，不是继续在圣所里加房间。

推荐方案 A：**主教堂/内院保留，生活与服务功能外迁**
- **主建筑**：教堂（中殿、门楼、钟塔、高坛、圣晶）+ 现有内院/围墙；内院草庭保留为圣所内部花园/墓地，不再塞修士院。
- **西侧独立回廊院**：四翼围绕一个草庭，各自独立屋顶/墙体；北翼议事厅、西翼宿舍/缮写室、南翼食堂/厨房、东翼病房/圣器室；通过有顶连廊/侧门接主教堂西墙；不再与主墙共用一整条长墙。
- **东侧服务院**：谷仓、马厩、草料棚、工坊、窑/铁匠铺、厨房菜园，围绕一个服务庭院；各自独立体量；通过东侧门/服务门接主院。
- **南门外门村**：香客客房、朝圣客舍、门房/小商铺、马厩或车棚，沿朝圣路分布；现有 hospice/stable 作为种子，但不再贴着主墙。

- **尺度**：向西、东、南扩展台地；主教堂仍最高；附属建筑低一层，屋顶之间留天空/院子/巷道。

- B：所有附属建筑集中在一侧（如西侧），东侧留墓园/果园；更简单，但“建筑群”感弱。
- C：完全开放、无外圈墙的修道村；更像村落，但失去圣所的封闭门槛。

当前场景仍是上一版“主墙内加功能”的状态；确认 A 后，先拆/迁移现在塞在两侧回廊院里的修士院、食堂、客房，再做西回廊、东服务院、南门村。不是继续往现有墙里加东西。
