# 统一天气入口

主场景 `hyrule_field.tscn` 已实例化 `weather_environment.tscn`。展开 **WeatherEnvironment → WeatherSystem** 即可在 Inspector 调整天气。原实验场景 `sanctum_sky3d_experiment.tscn` 保留，仍可独立调参。两处天气配置会在运行首帧生效。雨、独立雾、雪各有开关，可以同时勾选；运行时也可调用 `set_rain_amount()`、`set_fog_amount()`、`set_snow_amount()`，三者均接受 0–1。

主场景保留正常开始菜单及玩家规则，没有迁入实验场景的快速开始与无敌设置。默认雨档跟随实验场景当前保存值：晴朗；独立雾保持开启。主场景与实验场景共用效果实现，但 Inspector 数值分别保存。

## Inspector

- Rain Enabled：雨层开关。Rain Preset 选择晴朗、小雨、中雨、大雨、暴雨；开启 Continuous Rain Enabled 后改用 Continuous Rain Amount 无级雨量。五档参数仍在 Weather Profiles 中独立保存。
- Fog Enabled：独立雾层开关。Fog Amount 控制浓度，Fog Visibility Distance 控制远景没入雾的距离，Fog Color 控制雾色。实验场景默认开启，进入运行模式可直接看见。关闭独立雾不取消大雨和降雪自身的远景能见度变化。
- Snow Enabled：降雪开关。Snow Amount 控制雪花密度与阴天联动；可以与雨、雾叠加。当前是第一版雪花与天空，地面积雪和脚印尚未实现。
- Wind Mode：自然阵风、强制静风、预览持续阵风。实验场景恢复为自然阵风，默认会出现无风时段。

- Cloud Enabled / Type / Coverage / Density：实时更新风格云、转阴云幕、太阳轮廓、直射光、硬阴影、环境光与曝光。
- Cloud Wind Speed / Direction Degrees / Size Multiplier / Deformation Amount：实时更新程序云的推进、大小与可选边缘变形。
- Cloud Shadow Enabled：开启/关闭真实地面云影，编辑器与运行时共用同一设置。
- Fog Enabled / Amount / Visibility Distance / Color：实时更新距离雾与天空大气雾。

编辑器预览刻意与运行时天气逻辑分离。`WeatherSystem` 和 `WeatherRainController` 不改成 `@tool`；由现有 Sky3D 的编辑器工具节点调用独立的 `weather_editor_preview.gd`，只读取序列化参数并投射视觉结果。因此编辑器里不会启动雨粒子、地面雨点池、风状态机、音效、存档或 WeatherDirector。

关闭 **Editor Preview Enabled** 时，预览器会恢复打开场景时捕获的 Sky3D、Environment、太阳和低多边形云基线；再次开启时重新捕获。这个边界也是未来插件化的准备：运行时天气系统保持纯运行时，编辑器适配器可以单独迁入 `addons/`。

编辑器暂不播放雨雪粒子与地表阵风；程序云可以在视口中移动。雨雪仍使用 F6 / Weather Lab 做运行时验证。

## 云层 Cloud Layer

Cloud Layer 当前保留四个 Inspector 参数：

- **Cloud Enabled**：云层总开关。
- **Cloud Type**：目前主要决定照明性格。
  - **Cumulus 多云**：保留更多蓝天天光与直射光。
  - **Stratus 阴天**：覆盖率提高后更积极地削弱直射光、硬阴影与高光。
- **Cloud Coverage**：0–1，表示天空被云占据的面积。
- **Cloud Density**：0–1，表示云层厚度与吸光程度，不承担覆盖面积职责。

### 风格化云与转阴

可见云体由 `WeatherSystem/ProceduralCloudField` 负责，替换旧的整体远景 `BackdropClouds`。`cloud_mesh_library.gd` 首次使用时生成六种基础云形；后续场景与所有实例共享这些网格，不随天气变化重新生成。旧背景云只为未使用统一天气的历史场景保留。

六种云形使用不同的非对称骨架，各云块的大小、中心高度与倾斜均有变化。默认切面版使用带平面倒角的九边体堆积，只在相交处窄幅融合，提取同一张封闭外皮，减少拼接造成的薄片、台阶和锐角剪影；正常切面不做整体平滑。云底保持适度灰色。运行时不透明、`unshaded`，不计算银边与镜面反射，不参加碰撞或导航。云体可参与太阳的真实阴影渲染。

上一轮圆润版完整保留在 `cloud_mesh_library_rounded.gd`，两套网格分别缓存，可通过 Cloud Shape Style 切换。编辑器会同步基础网格引用；修改生成参数时应递增对应库的 Generation Version，或点击实验场 CloudModelGallery 的“刷新基础云形和陈列”。

固定池包含 96 团云：300m 和 415m 两层，每层 48 团、六组 MultiMesh，共 12 个批次。低层高度随机范围约 ±58m，高层约 ±78m；每团内部也有独立高低差。相机附近约 2.4km 的循环区域保留世界位置，远端收缩至零后才回收，避免边界弹出。

从多云转阴时，云团生长、扩展并与天空云幕融合：

- `Coverage < 0.55`：以独立低多边形云团为主，Stratus 云幕基本不出现。
- `Coverage 0.55–0.88`：更多云团出现并横向连片，云底略压平、颜色靠拢云幕；连续天空云幕从背后逐步长出。
- `Coverage > 0.88`：保留实际云团的立体云底，由天空云幕补齐远处与云团之间的缝隙。

这条视觉过渡由内部 `Overcast Blend` 自动推导，不需要作为天气导演的独立参数。`Density` 在整个过程中继续负责薄云到厚云的深浅变化，因此完整阴天可以继续平滑走向暴雨前的深灰云底。

**程序云：移动与形态** 分组新增：

- **Cloud Shape Style**：切面云 / 圆润云（保留），默认切面云。天空与实验场地面陈列一起切换。
- **Cloud Wind Speed**：米/秒，默认 8。低层使用全速，高层使用 0.64 倍速度并略偏转方向；0 停止平移。
- **Cloud Wind Direction Degrees**：默认 225°；0° 沿 +X，90° 沿 +Z。高空风独立于地表阵风。
- **Cloud Size Multiplier**：整体尺寸，默认 1；Coverage 和 Density 继续分别控制横向扩展与厚度。
- **Cloud Deformation Amount**：默认 0。非零时在 GPU 上缓慢改变边缘高度，范围 0–0.15，不重建网格。

生成模型与分布都使用固定种子，因此重开能复现同一构图。切面版六种模型合计约 9660 个三角形，保留的圆润版合计 12624 个；两套均按需生成一次后复用。显示成本还取决于实例数与画面覆盖。

### 地面云影

**程序云：地面云影 → Cloud Shadow Enabled** 默认开启。12 个天空 MultiMesh 批次直接参与现有太阳阴影图，不复制云模型、不增加灯光或阴影贴图，不修改原画质的阴影接收距离/分级。云的移动、缩放、两套形状、GPU 轻微变形以及太阳角度自动反映在投影中，地形、树木、建筑和角色均能接收正常光照阴影。地面模型陈列继续关闭投影。

使用 PCSS 保留与投影距离相关的半影，高空云影比近地树影更柔。**Cloud Shadow Strong Sun Angle** 默认 0.5°，**Cloud Shadow Weak Sun Angle** 默认 1.5°；强日光仍保留非零柔度。阳光强度用当前太阳能量乘以太阳高度分量，除以固定 **Cloud Shadow Reference Energy**（默认 1.5），再平滑插值这两个角径。这是本项目的美术映射，不改变天空显示的太阳圆盘大小。弱日光的阴影对比度也自然随直射能量下降。

投影深度会根据两层最高云体、缩放、厚度和太阳高度自动扩展（600–3000m），让高云保留真实深度，避免默认近景 pancake 把多个高空云面压到同一深度边界后出现点状黑带。扩展的是阳光方向上的深度空间，接收范围仍由原画质控制。方向阴影滤波设为 Soft Medium，以减少宽半影的采样颗粒；画质分级/阴影贴图大小不变。关闭云影或编辑器预览时恢复原太阳角径与投影深度。

两层不透明云在同一阴影图中合并遮光，重合的完整遮光区域不会按层重复变暗。`tests/test_cloud_shadow_rendering.gd` 在真实 GPU 上检查单层、两层完全重合和交错的像素结果。薄云透光仍未实现；以后需要累积透光率而非逐层相加阴影颜色。

当前运行时三档画质的太阳阴影范围为镜头附近 55 / 65 / 75 米。云影也只在这个范围内出现并按原太阳阴影设置淡出；远山不新增云影。太阳光被遮挡时，已有天空环境光与补光仍保留，不会变成全黑。云体仍是不透明网格，Density 改变颜色和厚度，不提供薄云的半透明透光；完整阴天的全局直射光削弱仍由 Cloud Type/天气合成负责。

开发诊断 `tools/probes/cloud_shadow_benchmark.gd` 固定同一镜头和天气，交替比较无云影、硬云影、柔云影，并记录 GPU/CPU 渲染耗时与阴影绘制量，截图和 JSON 输出到工程同级 `visual_captures/cloud_shadows_v1/`；另有单云的强/弱日光、旧深度错误和风推动对照。加 `-- --capture-only` 可仅拍对照。基准冻结游戏模拟，不代表完整战斗性能。后续如需超出太阳阴影范围的大尺度地形云影，可再加入伪阴影投影。

### 实验场地面陈列

`prototypes/environment/weather_lab.tscn` 的 **CloudModelGallery** 在出生点后方（Z=58/75）放置两排、共六种基础云模型，编号 01–06。陈列使用天空同一组网格，缩小到 0.04 倍，架在矮台上便于从侧面和下方观察。Cloud Shape Style 同时切换天空和陈列；Gallery Enabled 可以关闭陈列，Display Scale 可调整显示尺寸。该陈列只在实验场存在，不加入碰撞或导航。

推荐本轮测试：

- `Coverage 0.25 / Density 0.50`：少量风格云，蓝天为主。
- `Coverage 0.45 / Density 0.50`：明显多云，仍不应该出现整片白雾式云幕。
- `Coverage 0.65 / Density 0.50`：开始转阴，程序云和云幕同时可见并开始融合。
- `Coverage 0.80 / Density 0.50`：云团大部分已经与云幕颜色和形态接近。
- `Coverage 1.00 / Density 0.50`：连续阴天云底。
- `Coverage 1.00 / Density 0.80–1.00`：厚阴到未来暴雨前状态。

运行时入口：

- `set_cloud_type(WeatherSystem.CloudType.CUMULUS / STRATUS)`
- `set_cloud_coverage(0.0 到 1.0)`
- `set_cloud_density(0.0 到 1.0)`
- 旧 `set_cloud_amount()` 暂时保留兼容，等价于设置 Coverage。

当前已有近景真实地面云影；远景伪云影、薄云透光、风暴前沿天气地图和闪电尚未实现。

## 其它天气层

- **Rain Enabled**：雨层开关。Rain Preset 选择晴朗、小雨、中雨、大雨、暴雨；开启 Continuous Rain Enabled 后改用 Continuous Rain Amount 无级雨量。五档参数仍在 Weather Profiles 中独立保存。
- **Fog Enabled**：独立雾层开关。Fog Amount 控制浓度，Fog Visibility Distance 控制远景没入雾的距离，Fog Color 控制雾色。
- **Snow Enabled**：降雪开关。Snow Amount 当前控制雪花密度。雪层不再自动把天空切成阴天；积雪覆盖将在后续 Snow Cover 阶段单独实现。
- **Wind Mode**：当前仍使用原有自然阵风、强制静风、预览持续阵风。风场与各天气层的正式叠加放到后续阶段。

统一 `WeatherSystem` 使用独立层逻辑。底层 `WeatherRainController` 为了兼容旧实验，单独实例化时仍保留“雨量自动带来阴雨环境”的旧行为；主游戏使用的 `WeatherSystem` 已关闭这层耦合。

天气合成只写入一次天空、太阳、环境光与距离雾；雨和雪粒子彼此独立，雨滴落点和湿润程度仍归雨层。Sky3D 继续负责昼夜和天空，Sky3DExperimentController 负责低多边形补光以及编辑器天气预览宿主。
