# 统一天气入口

主场景 `hyrule_field.tscn` 已实例化 `weather_environment.tscn`。展开 **WeatherEnvironment → WeatherSystem** 即可在 Inspector 调整天气。原实验场景 `sanctum_sky3d_experiment.tscn` 保留，仍可独立调参。两处天气配置会在运行首帧生效。

天气从这一版开始按“独立环境层”组织：**云、雨、雾、雪互相不代表对方**。可以只开阴天而不下雨，也可以只下雨而保持当前云量；后续天气导演负责决定哪些层在某段时间一起出现。

## 阴天层 Cloud Layer

- **Cloud Enabled**：独立阴天开关。
- **Cloud Amount**：0–1 连续云幕强度。
  - 约 `0.20–0.30`：薄阴，仍然明亮，但硬太阳、高光和硬阴影已经明显减弱。
  - 约 `0.45–0.60`：普通阴天，以漫射天光为主。
  - 约 `0.75–0.85`：厚云，天空、环境光与远景整体转冷转沉。
  - `1.0`：重阴，接近“黑云压城”的低曝光云幕。
- 阴天**不会自动制造雾**。能见度仍由 Fog Layer 单独控制。
- 阴天也**不会自动产生雨雪**。需要时分别开启 Rain / Snow Layer。
- 运行时可调用 `WeatherSystem.set_cloud_amount(0.0 到 1.0)`。

阴天不是单纯把天空乘黑。Cloud Amount 增加时，系统先快速压低太阳圆盘、直射高光和硬阴影，再逐渐降低环境曝光、环境光能量并把色调推向冷灰。这样浅阴可以保持“天街小雨润如酥”的明亮漫射感，重阴才进入“黑云压城”的压迫感。

## 其它天气层

- **Rain Enabled**：雨层开关。Rain Preset 选择晴朗、小雨、中雨、大雨、暴雨；开启 Continuous Rain Enabled 后改用 Continuous Rain Amount 无级雨量。五档参数仍在 Weather Profiles 中独立保存。
- **Fog Enabled**：独立雾层开关。Fog Amount 控制浓度，Fog Visibility Distance 控制远景没入雾的距离，Fog Color 控制雾色。
- **Snow Enabled**：降雪开关。Snow Amount 当前控制雪花密度。雪层不再自动把天空切成阴天；积雪覆盖将在后续 Snow Cover 阶段单独实现。
- **Wind Mode**：当前仍使用原有自然阵风、强制静风、预览持续阵风。风场与各天气层的正式叠加放到后续阶段。

统一 `WeatherSystem` 使用独立层逻辑。底层 `WeatherRainController` 为了兼容旧实验，单独实例化时仍保留“雨量自动带来阴雨环境”的旧行为；主游戏使用的 `WeatherSystem` 已关闭这层耦合。

天气合成只写入一次天空、太阳、环境光与距离雾；雨和雪粒子彼此独立，雨滴落点和湿润程度仍归雨层。Sky3D 继续负责昼夜和天空，Sky3DExperimentController 只保留低多边形补光。

这是两个场景共用的天气实现，但各自保存 Inspector 参数；要抽成通用插件仍需把场景相对路径与项目特有接收组改成可配置接口。
