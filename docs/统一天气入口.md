# 统一天气入口

主场景 `hyrule_field.tscn` 已实例化 `weather_environment.tscn`。展开 **WeatherEnvironment → WeatherSystem** 即可在 Inspector 调整天气。原实验场景 `sanctum_sky3d_experiment.tscn` 保留，仍可独立调参。两处天气配置会在运行首帧生效。雨、独立雾、雪各有开关，可以同时勾选；运行时也可调用 `set_rain_amount()`、`set_fog_amount()`、`set_snow_amount()`，三者均接受 0–1。

主场景保留正常开始菜单及玩家规则，没有迁入实验场景的快速开始与无敌设置。默认雨档跟随实验场景当前保存值：晴朗；独立雾保持开启。主场景与实验场景共用效果实现，但 Inspector 数值分别保存。

## Inspector

- Rain Enabled：雨层开关。Rain Preset 选择晴朗、小雨、中雨、大雨、暴雨；开启 Continuous Rain Enabled 后改用 Continuous Rain Amount 无级雨量。五档参数仍在 Weather Profiles 中独立保存。
- Fog Enabled：独立雾层开关。Fog Amount 控制浓度，Fog Visibility Distance 控制远景没入雾的距离，Fog Color 控制雾色。实验场景默认开启，进入运行模式可直接看见。关闭独立雾不取消大雨和降雪自身的远景能见度变化。
- Snow Enabled：降雪开关。Snow Amount 控制雪花密度与阴天联动；可以与雨、雾叠加。当前是第一版雪花与天空，地面积雪和脚印尚未实现。
- Wind Mode：自然阵风、强制静风、预览持续阵风。实验场景恢复为自然阵风，默认会出现无风时段。

天气合成只写入一次天空、太阳、环境光与距离雾；雨和雪粒子彼此独立，雨滴落点和湿润程度仍归雨层。雾在启动时按 Inspector 当前值出现，运行中调整则按 Fog Build/Clear Seconds 渐变。Sky3D 继续负责昼夜和天空，Sky3DExperimentController 只保留低多边形补光。丁达尔光束及其旧体积雾已从实验场景移除。

这是两个场景共用的天气实现，但各自保存 Inspector 参数；要抽成通用插件仍需把场景相对路径与项目特有接收组改成可配置接口。
