# 统一天气入口

主场景 `hyrule_field.tscn` 已实例化 `weather_environment.tscn`。展开 **WeatherEnvironment → WeatherSystem** 即可在 Inspector 调整天气。天气测试统一使用 `prototypes/environment/weather_lab.tscn`。

天气按“独立环境层”组织：**云、雨、雾、雪互相不代表对方**。可以只开云而不下雨，也可以下雨而保持当前云量；后续 WeatherDirector 只负责让这些连续参数随时间变化。

## 云层 Cloud Layer

Cloud Layer 当前保留四个 Inspector 参数：

- **Cloud Enabled**：云层总开关。
- **Cloud Type**：暂时只区分照明性格。
  - **Cumulus 多云**：保留更多蓝天天光与直射阳光。
  - **Stratus 阴天**：随着覆盖率提高逐渐削弱直射光、硬阴影和高光。
- **Cloud Coverage**：0–1，表示天空被云占据的面积。
- **Cloud Density**：0–1，表示云的厚度、吸光和内部明暗。

### Stylized Cloud Field

从当前版本开始，**Cumulus 与 Stratus 不再使用两套不同风格的云几何**。Sky3D 原生偏写实的体积积云在统一 `WeatherSystem` 中被停用，两种天气都使用同一套低频风格化 Cloud Field：

- Coverage 较低时，云场自然断开成几块大型云团，蓝天从缝隙中露出。
- Coverage 提高后，云块逐渐连接；接近 1.0 时形成连续云底。
- Density 只负责从明亮薄云向厚重深灰云底变化，不再改变天空覆盖面积。
- 云形只保留大尺度轮廓和大块明暗，避免高频噪声与过度真实的烟雾细节。

云材质遵守一个硬规则：**低反光、无太阳高光、无银边**。统一云场不读取 `sun_light_color` 来制造亮边，也不使用真实积云的 Mie 高光。最亮的云仍然是冷灰漫射面，Density 增加时只扩大暗部和降低整体亮度，避免出现天空中漂浮的塑料块。

推荐测试：

- `Cumulus / Coverage 0.30–0.60 / Density 0.35–0.70`：晴间多云到明显多云，蓝天仍占重要部分。
- `Stratus / Coverage 0.45–0.70 / Density 0.35–0.60`：晴转阴阶段，云块开始连片。
- `Stratus / Coverage 0.80–1.0 / Density 0.45–0.65`：普通阴天，太阳轮廓逐渐消失。
- `Stratus / Coverage 1.0 / Density 0.75–1.0`：厚重阴天，作为未来暴雨前状态的视觉起点。

当前 `Cloud Type` 仍保留，是为了不一次改动过多照明逻辑。**云形本身已经统一**，后续 WeatherDirector 连续化时，可以进一步研究是否直接去掉 Type，让 Coverage + Density 自然覆盖晴间多云、转阴、阴天和暴雨前四个阶段。

第一版仍然不实现“某一块云刚好经过太阳时，地面直射光和云影实时变化”。等风格化云形确认后，再做太阳方向局部云密度采样。

运行时入口：

- `set_cloud_type(WeatherSystem.CloudType.CUMULUS / STRATUS)`
- `set_cloud_coverage(0.0 到 1.0)`
- `set_cloud_density(0.0 到 1.0)`
- 旧 `set_cloud_amount()` 暂时保留兼容，等价于设置 Coverage。

云层仍然**不会自动制造雾、雨或雪**。能见度、降雨和降雪继续由各自独立 Layer 控制。

## 其它天气层

- **Rain Enabled**：雨层开关。Rain Preset 选择晴朗、小雨、中雨、大雨、暴雨；开启 Continuous Rain Enabled 后改用 Continuous Rain Amount 无级雨量。五档参数仍在 Weather Profiles 中独立保存。
- **Fog Enabled**：独立雾层开关。Fog Amount 控制浓度，Fog Visibility Distance 控制远景没入雾的距离，Fog Color 控制雾色。
- **Snow Enabled**：降雪开关。Snow Amount 当前控制雪花密度。雪层不再自动把天空切成阴天；积雪覆盖将在后续 Snow Cover 阶段单独实现。
- **Wind Mode**：当前仍使用原有自然阵风、强制静风、预览持续阵风。风场与各天气层的正式叠加放到后续阶段。

统一 `WeatherSystem` 使用独立层逻辑。底层 `WeatherRainController` 为了兼容旧实验，单独实例化时仍保留“雨量自动带来阴雨环境”的旧行为；主游戏使用的 `WeatherSystem` 已关闭这层耦合。

天气合成只写入一次天空、太阳、环境光与距离雾；雨和雪粒子彼此独立，雨滴落点和湿润程度仍归雨层。Sky3D 继续负责昼夜和天空，Sky3DExperimentController 只保留低多边形补光。

这是主场景与 Weather Lab 共用的天气实现，但各自保存 Inspector 参数。要抽成通用插件仍需把场景相对路径与项目特有接收组改成可配置接口。
