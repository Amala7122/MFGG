# 浮游卫士与玩家能量护盾

旧版表现已增量接入正式玩家。F6 运行包含正式玩家的场景即可观察，不限于实验台。使用 **F8** 调整；**F7 仍为近战**，E 手雷 / 空格近战 / Q 脉冲 / C 共鸣 / R 换弹 / F 手电筒不改。

## 浮游卫士

默认两倍模型、深蓝机身与白色装甲、青色透镜和旋转守护光环；普通跟随位置为相机水平坐标系 `(-1.05, 1.85, 0.32)m`，ADS 为 `(-1.35, 2.05, 0.45)m`。瞄准时向外 / 上避让，默认窄视野下可能离开画面；不是保证所有相机姿态都能看见卫士。

普通 / 锁敌 / 超频 / 开火灯光由同一视觉状态组合。开火脉冲回落到当前普通或超频配置，不再由旧 Tween 写回普通亮度。原有伤害9、射速1.35、射程22、盲区65°、弹速42、末只停火阈值1及赐福计算没有改动；继续使用新版 HealthUtil 支持 `get_health()` 类目标。弹体实现未重做。

## 能量护盾

这是受击时短暂显现的视觉球壳，**不是常驻罩子，也不增加防御**。只有真实吸收原始伤害 `absorbed_raw > 0` 时触发；无盾、无敌、翻滚免伤不会伪造吸收。破盾有溢出时仍显示这次已吸收部分，身体白闪、HUD、破盾共鸣充能和当前受伤音效保留。

默认半径1.3米、中心相对玩家根偏移0.05米、显示0.52秒。三向投影蜂巢随受击方向局部高亮和涟漪，世界方向转换到网格局部。按同一秒时钟采样、衰减和隐藏，死亡立即取消。没有搬入旧音频总管或未注册的 `shield_deflect` 音色。

保留旧版的明亮受击核心。正对镜头时核心白光可能覆盖角色；亮度与实战读图尚待用户体验。可在 F8 降低“受击发光 / 总体显现 / 球壳透明度”比较，不据截图自行认定满意。

## F8 调整与复现

打开后暂停战斗，右侧不透明面板不透出小地图，中央保留观察空间。每个参数标出单位 / 范围，修改即时作用于当前正式组件，未保存草稿有明确提示。

- 卫士：尺寸、普通 / ADS 跟随位置、灯光、透镜、能量装饰和光环速度。勾选“预览超频外观”只改变外观，不授予或撤回赐福；关闭面板恢复真实超频状态。
- 护盾：开关、半径、时长、显现、蜂巢密度 / 线宽、边缘光、受击发光和涟漪速度。正面 / 左侧 / 右侧 / 背后 / 上方按相机水平朝向指定，预览吸收量1–100；支持循环和0–100%时间线定位。重播与实战共用实现，不扣血盾、不改共鸣。
- **保存为项目默认**只写 [唯一表现配置](../../data/player_visuals/support.json)；**重读已保存值**撤回草稿。F8 / Esc 关闭，清除预览并恢复暂停 / 鼠标状态。参数没有命名方案库，不把保存默认称为另存方案。

卫士基础颜色仍由现有 [GameConfig](../../data/game_config.json) 的 `wisp.color` 读取（本批更新为旧版青色），重新运行生效；白蓝装甲配方在脚本中。F8 不改战斗段。保存前备份 / SHA256 回执在项目外 `_artifacts/<项目>/editor/<运行编号>/reports/`，失败显示错误；发行模式不写回项目。
