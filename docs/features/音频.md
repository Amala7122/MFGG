# 音频（音色库与文件音源）

## 结论先说

游戏里的音效分两层，**调用方看到的键名完全一样**，75 处调用不需要知道声音是从哪来的：

1. **合成层**：`audio_manager.gd` 用代码合成，不依赖任何音频文件（子弹 / 命中 / 爆炸本质是
   "噪声 + 快速衰减 + 频率下坠"）。
2. **文件层**：`data/game_config.json` 的 `audio.file_bank` 里点名的键改用真实音频文件
   （Ovani Sound《Sound FX Starter Pack Vol. 1》）。

文件层**随时可以整体关掉**，游戏不会因此没声音——没配到的键一律继续用合成音色。

> **当前状态（2026-10-18）**：`audio.file_bank` 是**空表**，所以 **26 个键全部走合成音色**。
> 枪声（`shot` / `sniper`）曾接过录音版，用户判定"过于真实、有拉栓感"且全部派生候选都不如合成版，
> 已撤销文件音源。见 [音效库接入](../tasks/音效库接入.md)。

## 调用方式（没变）

```gdscript
AudioUtil.play("shot")            # 非定位：自己的枪声、UI
AudioUtil.play_at("hit", 位置)     # 3D 定位：命中、爆炸、敌人开火
AudioUtil.duck(1.2, -9.0)          # 特写时压低细碎战场音
AudioUtil.set_low_health_danger(d) # 濒死低通滤波
AudioUtil.reload()                 # 改完配置后立刻重建音色库
```

## 调参入口

| 想改什么 | 改哪里 |
|---|---|
| 某个键用哪个音频文件 | `data/game_config.json` → `audio.file_bank` |
| 某个文件的响度 | 同一条目写成对象并给 `volume_db` |
| 让某个 Loop 素材真的循环 | 同一条目加 `"loop": true` |
| 整体关掉文件层做 A/B | `audio.file_bank_enabled` 改 `false` |
| 合成音色的参数 | `audio.bank`（数值含义见 `_bank_format`） |
| 合成音的变体数（消连发机械感） | `audio.synth_variants`，按键配 N（1~8，1 = 关闭） |
| 新增一个音色键 | 必须同时改 `audio_manager.gd` 的 `BANK_FALLBACK`（**键清单由代码掌握**，配置只提供参数） |

## 合成音的多变体层

同一个键只用一组参数，但用**不同随机种子**生成 N 个波形，装进 `AudioStreamRandomizer`，
播放模式 `PLAYBACK_RANDOM_NO_REPEATS`。**参数一点没动，只有噪声序列不同 → 音色不变**，
目的只是消掉连发时「每秒 7 次同一个波」的机械重复感。

- 变体 0 的种子偏移是 0，波形与改动前逐字节相同；测试用「两次重建结果相同」守住确定性。
- 只给高频重复的键配（`shot`、`casing_clink`、`footstep`、`hit*`、`enemy_shot`、`wisp_shot`）；
  爆炸这类低频键不配。26 个键 + 10 个带变体，构建约 63 ms。

## 调音器（自己调合成音色）

```text
Godot_v4.7.2-stable_win64.exe --path . --script res://tools/probes/audio_synth_tuner.gd
```

按游戏射速循环播放，`1`~`6` 选参数、`←`/`→` 微调、`Tab` 切 7 ↔ 10.5 发/秒、`V` 改变体数、
`R` 复原、`S` 打印可粘贴进 `audio.bank` 的一行、`Q` 退出。**不写项目文件**，调好自己粘贴。


写法示例：

```json
"file_bank": {
  "shot": "res://addons/Sound FX Starter Pack Vol. 1/Hollywood/Titan Handgun.wav",
  "ui": { "path": "res://.../UI & Menus/Select.wav", "volume_db": -4.0 },
  "ambience_wind": { "path": "res://.../Environment/Wind Loop.wav", "loop": true }
}
```

## 三种兜底（配置坏了也有声音）

| 情况 | 行为 |
|---|---|
| 音频文件不存在 | 聚合**一条** `push_warning`，这些键继续用合成音色 |
| 写法非法 / 目标不是音频流 | `push_error` 指明是哪个键，该键回退合成音色 |
| `game_config.json` 整体丢失 | 全部走内置 `BANK_FALLBACK` 合成音色 |

文件不存在只报警告不报错是刻意的：音效库目录被 `.gitignore` 排除（第三方授权要求，见
[问题台账](../issues.md) 的 I-035），干净检出时本来就找不到文件，那不是配置错误。

## 两个必须记住的坑

- **Loop 文件不会自己循环**：音效库里名字带 `Loop` 的文件导入后是 `loop_mode = LOOP_DISABLED`
  （文件里没有 `smpl` 循环块，Godot 的 `Detect From WAV` 自然检测不到，见 I-032）。
  要在配置里显式写 `"loop": true`，运行时才会打开 `LOOP_FORWARD`。
- **3D 用的是立体声素材**：Godot 4 的 `AudioStreamPlayer3D` 支持立体声定位
  （`panning_strength` 就是为此存在），文档没有"3D 必须单声道"的硬性要求。
  若要更聚焦的定位，或想把导入体积再减半，可以对选中的文件开 `Force > Mono`。
