# 敌人统一参数表

本表由当前实际面板语义映射导出，覆盖七种敌人全部 732 个字段。实现及接入合同以 [enemy_parameter_layout.gd](../../scripts/testing/enemy_parameter_layout.gd) 为准；[操作与体型规则](敌人统一参数与攻击观察.md)。原字段仅用于查配置，不要求调参时记忆。所有数值仍在各敌人原 JSON 与命名方案中。

专业编辑归属以[字段归属登记](../../scripts/testing/enemy_parameter_ownership.gd)为准：本表列出完整定义，不表示每台都提供可写控件。视觉220项、个体战斗507项、玩家条件5项；视觉能力分批接入，未支持宿主显示只读，不重复在战斗页开放。
