# 沉积泰坦 Boss 战斗节奏实施方案

**本对话唯一执行入口，2026-10-16 整理。** 此页确定当前状态、下一批和已定规则。后续变化直接更新此页，不再另起平行实施方案；旧研究、任务过程和产物副本用于查证，不能据其中的「下一步」启动工作。

## Boss 攻势与奖励主路线（A4 起实施，效果待验收）

**有限攻势＋可识别的快慢刀＋重招破绽＋输出奖励，仍是主推荐路线。** 用户没有取消它，原研究也没有验证它失效。上次整理将主要奖励触发方式的变更扩大成整条路线被替代，遗漏了攻势组织，本次修正。

| 路线 | 当前判断 |
|---|---|
| 只调整快慢与后摇 | 成本最低，适合拆出时间因素做对照；单独采用仍可能边绕边打、掉血平铺 |
| 有限攻势＋重招破绽＋输出奖励 | **最推荐，效果待验证。** 复用现有招式、泥盾和狂暴，让施压、判断、反击兑现形成段落；快慢刀服务这组攻势 |
| 新姿态条、部位血条、多层外壳系统 | 成本高，暂不采用这类额外系统；用户已指定的泥盾／晶体破解仍保留，不把它们扩成新姿态资源条 |

完整主线：**有限攻势与快慢刀 → 重招承诺 → 无盾重招／后摇输出机会 → 重新施压。** 前半在重招开始前主动卸盾，后摇结束后才重新施盾；狂暴后全程没有泥盾。三雷破盾／三枪倒地另提供更长、更强的奖励，不能也不必成为唯一输出途径。

- 快慢刀与有限攻势负责「Boss 怎样施压、何时把主动权交回来」；慢招靠不同准备姿态和真实节拍可辨认，不靠同姿态随机延迟猜时机。合法选招与场地检查仍保留，不强制执行无落点跃击。
- 前半先卸盾，再进入重招准备／预警；无盾状态覆盖重招前摇、出手与完整后摇。出手期间玩家仍须应对攻击，后摇期间 Boss 不追击、不追加下一招，是明确的常规输出窗口；后摇结束后才重新施盾。
- 狂暴后不再生成泥盾，包括共鸣到来时也不能恢复泥盾。身体全程可正常受伤；重招后摇提供稳定输出时间，三枪倒地另外提供较长的最终 ×2 奖励。晶体 5 秒保护只保护晶体，不是泥盾或全身无敌。
- 主动卸盾与三雷破盾是两件事：卸盾开放常规伤害，不自动兑换跪地、倒地、额外次数或倍伤；三雷／三枪奖励提高主动破解的收益。普通重招窗口不要求先完成破解，也不把三雷／三枪做成通关门票。
- 具体重招后摇时长和招组长度仍待对照；旧 2.5 秒只作研究参考。用户已经明确「招前卸盾、后摇结束后重施」及「狂暴无泥盾」，不能再用笼统的“常驻”盖掉这些规则。

### 设计主线与已明确规则

- 主推荐仍包含有限攻势、快慢刀与重招破绽，具体调参和效果待审阅／验证；不能只剩三雷／三枪计数。
- 手雷统一触敌即爆并造成硬直；旧粘附候选退出当前执行依据。
- 半血前常规施压／追击时维持泥盾；重招前主动卸盾，直到后摇结束才重施。三枚手雷破盾的跪地是额外长奖励，不取消常规重招输出窗口。
- 半血后完全没有泥盾。三次真实狙击晶体可额外争取倒地；前两次各保护晶体 5 秒，第三次倒地，倒地承伤翻倍；身体输出和重招后摇窗口仍存在。
- 跪地有效 4 秒、倒地有效 8 秒、手雷储备／回充、硬直时长及狂暴具体倍率仍是 AI 首版建议，尚未由用户验收为最终数值。
- 战斗时长仅记录，不用它或更高死亡率证明挑战和反馈变好。

## 1. 最新规则与替代关系

- 用户最新要求：**以后所有场景的玩家手雷，接触敌人立即爆炸，并造成硬直。** 不是泰坦专用的起爆方式。
- 原“手雷粘泥盾、等待引信后爆炸”取消作为当前候选。泥盾改为三枚不同手雷分别接触并即时爆炸，第三炸破盾；三枚各爆一次的数量规则保留。
- 前半同时有常规重招卸盾窗口和三雷破盾跪地长奖励；后半无泥盾，常规重招后摇与三枪倒地长奖励并存。前两次晶体命中各保护 5 秒，第三次倒地最终承伤 ×2，不能只靠三雷／三枪才能有效输出。
- “前半泥盾常驻”更新为：在常规施压／追击时维持，不再随机按持续时间消失；主动重招卸盾与玩家破盾是明确例外。重招后摇结束才允许重新施盾；若已进入跪地／倒地，则先兑现奖励，不被旧回调提前加盾。三雷跪地起身后恢复常态带盾，不额外插入 6 秒无盾。
- 狂暴后彻底没有泥盾，普通循环、重招后摇结束与共鸣来临均不重建。晶体保护罩独立保留，只影响晶体破解。
- 触敌起爆和短硬直适用于通用手雷；三枚储备／短投掷间隔仍是泰坦战的资源建议，不能把“所有手雷触敌爆炸”误读为已经要求所有场景同时改成三枚储备。
- 先前研究报告与运行目录中的方案副本保留为历史快照。当前执行依据为本索引及下列分册，不再按粘附或旧 P0–P7 整包实施。

### 最新体验反馈：压迫力不等于挑战质量

用户补充：当前未改造 Boss 已有压迫力，尝试 N 次仍未打过；躲闪本身不难，主要难在战斗时间长、容错低，认为是「伪难度」，挑战机制和战斗反馈并不出色。问题登记 I-108。原话是体验事实；实际时长、死因和机制贡献尚未量化，不将推测写成已测根因。

本方案不以提高失败率、继续加血加伤害或拖长战斗为目标。用户进一步明确：当前战斗时长不作为标准，时长与好的战斗感官和反馈不等价。验收看失误代价、需要做的判断／选择、成功与失败反馈；时长只作为过程坐标和观察截断。三雷／三枪也必须接受同样检查：如果新增的大部分过程只是等待补给或保护罩消退，或者重复同一个已经会做的动作，而没有更好的选择和奖励，就不能因为规则测试通过而称为挑战改善。

5 秒保护与三次命中仍按用户已定规则保留；先验证其间能否有效走位、射击和应对已有招式，不自动加密攻击制造新压力。普通失误不清空破解进度；成功裂盾／破晶／倒地与无效命中要有可区分的反馈。

## 4. 批次边界

- 一次启动一个明确批次；交付该批改动、检查结果和未验证项，后续保持未开始。用户明确授权连续多批时再按授权推进。
- 批准某一批不等于自动授权整张表。当前已授权并推进到 A4.1，A4.2–A6 未开始。
- 某批发现前置条件未满足，先补本批必要条件或登记问题，不顺带开发下一批完整功能。
- A5 的独立验收可在诊断模式下验证晶体和第三击事件；A6 通过前，不把只有计数却没有倒地奖励的半成品作为正式新循环启用。
- 规则快测、短操作回放随相关批次落地。多策略当前基线先做，未来机制策略随新玩法补充；最终综合试玩在 A8，不要求用户每批完整重打一局。
