# 玩家近战（旧版移植首批）

正式玩家共用实现，不局限于实验场。空格短按轻扫、长按蓄力重击；E 仍是现有手雷，Q 震地脉冲、C 共鸣、R 换弹、F 手电筒和直战 F5 重开均不改。玩家主动跳跃暂时关闭，重力、翻滚、踏阶与 Boss 跃击不受影响。

## 使用与调参

- 轻扫默认 60 原始伤害、最多 3 个目标；可缓存下一次点按交替连段。
- 长按 0.15 秒进入蓄力，0.4 秒达到重击，松开释放；按住到 0.85 秒自动释放一次，继续按住不会连发。重击默认 180 原始伤害、单目标、3 秒独立冷却；冷却期间仍可点按轻扫。
- 重击穿透普通护甲减伤的 50%，不是无视 50% 泥盾。Boss 的泥盾、阶段倍伤和破招仍由正式 Boss 自己处理，不套旧占位 Boss 的弱点倍伤或强制破甲 / 打断。
- 翻滚、特写、暂停、失去焦点、死亡会取消未完成动作。蓄力遇破盾或 28 点以上实际生命伤害会打断并进入半冷却；护盾没破不打断。
- 使用现有枪械挥扫与双手 IK、金色挥痕、命中声音 / 镜头反馈；未添加新的骨骼动作资源。

从编辑器运行任意包含正式玩家的场景，按 **F7** 打开近战面板。打开时暂停战斗；各字段标注单位和范围。改值立即应用于本次运行并显示“未保存草稿”，**保存为项目默认**才写回 [唯一数值配置](../../data/player_melee/default.json)。重读撤销草稿；F7 / Esc 返回战斗。保存前旧配置备份在项目外 `_artifacts/<项目>/editor/<运行编号>/reports/`；保存失败会显示错误，不回退到项目根目录。

时长统一为秒，无另一套未接线的帧参数。前摇 / 出手段 / 总时长和蓄力阈值有大小关系校正。保存不等于另存命名方案，本批未提供命名方案库。

## 实现与验证边界

[近战组件](../../scripts/player_melee.gd)负责输入、同一时钟判定与姿势；[形状查询](../../scripts/player_melee_targets.gd)按碰撞表面检查距离 / 朝向 / 遮挡，并按敌人去重，查询预算默认 128。仅出手查询，不每帧扫描全场。轻扫命中前进、重击前进均走碰撞扫掠，不穿墙瞬移。射击在近战动作期间停止，换弹计时仍可推进。

[自动检查](../../tests/test_player_melee.gd)验证正式接线、输入、伤害、中断、面板保存、墙体和大型边界；100 个候选的目标上限检查**不是百体帧率或最终手感验收**。图形模式同一测试保存调参面板图。体验和后续移植批次状态见 [任务记录](../tasks/旧版五项改进移植.md)。
