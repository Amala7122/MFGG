# 手绘画面滤镜

旧版五项移植第三批首版，2026-10-18用户明确“试过了，手绘风感觉不错”，观感已验收；已登记的首次切换停顿不因此视作修复。只处理画面，不改敌人技能、伤害、泥盾、寻路或玩家输入。

## 从编辑器试用

从编辑器运行游戏，在显示设置的“画面风格”选择“手绘彩铅 / 素描”。原五种风格的编号与表现不变；手绘与它们互斥。现有个人设置和默认关闭状态不被强制覆盖。

战斗中按 **F9** 暂停并打开调参。F7近战、F8卫士 / 护盾仍独立；面板互斥，Esc或F9返回。独立实验场需存在可控制的正式玩家才能开F9，不抢占观察台的方括号键。

- “原画对照 / 轻量彩铅 / 旧版复线 / 黑白素描”是本次运行的参考配方，不自动保存。推荐先看轻量彩铅。
- 单字段调整即时预览，未保存会提示；参数标签给出单位，数字框限制范围。线宽为窗口像素，其他范围和步长定义在 [参数字段](../../scripts/sketch_settings.gd)。颜色使用选色器。
- “保存为项目默认”明确写回 [唯一默认配置](../../data/graphics/sketch_default.json)，下次实例化读取；不会替你启用滤镜。开发环境保存会在项目外留旧值、SHA与回退回执；发行包不允许改项目资源。
- “重读默认”放弃本次草稿；返回只恢复打开前的风格，草稿参数仍留在本次运行。
- “本机启用手绘并返回 / 本机关闭滤镜并返回”只保存 `user://display.cfg` 的个人风格选择，不把草稿写成项目默认。内置配方不是用户命名方案库，不存在把“另存方案”暗中当成“设为默认”的操作。

临时切换效果建议先开F9：首次实际绘制观察到约81ms切换停顿（I-180），后续切换约2ms；未确认冷启动根因，未声称已消除首次进入游戏卡顿。

## 实现与边界

[PostProcess](../../scripts/post_process.gd)复用统一入口。手绘独立在CanvasLayer -1、HUD默认层之前处理世界，显式复制最新世界画面；不会把文字、准星、血条、地图或调参面板描边。原五种效果仍在90层。关闭、切到其他风格或混合为0时，手绘画面与屏幕复制都不绘制。

[Shader](../../shaders/pencil_sketch.gdshader)保留旧版轮廓、纸张、排线、彩铅与素描；采用正向smoothstep表达，采样不生成未使用的mipmap。空间噪声无TIME驱动，固定机位可重复观察。[参考配方](../../data/graphics/sketch_legacy.json)核对的是旧版实际运行配置，不是原场景更强的默认值；“旧版复线”也使用适配后的同一Shader，不是对旧工程帧率的直接测量。

轻量配方只取消0.05复线，避免其额外8次屏幕采样；不宣称整体GPU时间减半。所有Shader参数均接入配置与F9，不再存在导出属性、场景数值与部分配置读取互相覆盖。

红色信号保色和亮部特效保护均为颜色 / 亮度启发式，**不是技能语义遮罩**：可能保留红色环境材质；透明填充在不同背景上的颜色仍会变。已核对完整外圈和逐渐填充，不改变原危险范围、倒计时或碰撞。环境遮挡不会由滤镜消除。黑白是可选对照，不将其当作默认战斗可读性已验收。

## 验证入口

自动：`python -B tools/run_acceptance.py --tests test_sketch_filter --graphics --task sketch_check`。覆盖真实F9、开关互斥、全部参数落材质、显式保存 / 回读、未编辑值精度、个人风格与项目参数分离、退出场景清理、HUD像素、四方向外沿、黑白土路与取消保色反例。

实景：`python -B tools/run_probe.py tools/probes/sketch_comparison.gd --graphics --task sketch_live`。固定正式圣所、1920×1080、100%渲染、1个稳定可见泰坦、固定机位，晴天 / 暴雨各轮换3次原画 / 旧配方 / 轻量，截图读回在测量段外。AI与天气时钟暂停，所以**不是100敌人战斗性能**。100个静态盒体的专项截图同样不代表百体AI。

本批实景GPU轮次中位数的中位值（RTX 5060 Ti / Godot 4.7.2 / D3D12 Forward+）：晴天原画2.200ms、旧配方2.462ms、轻量2.400ms；暴雨2.179 / 2.441 / 2.373ms。只是该固定画面，首轮温度 / 缓存扰动保留在原报告，不外推其他硬件或战斗压力。

最终截图与自动证据见 [持续任务](../tasks/旧版五项改进移植.md)。全核心回归另暴露一条已有Boss旧断言（I-181），还原移植前显示接线仍失败；用户确认重招允许泥盾。本批未改Boss实现，曾尝试的测试预期调整也已撤回，不把回归报告写成全通过。
