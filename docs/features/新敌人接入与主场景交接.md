- 调参后重新开始一局读取。每局解析一次参数快照，个体差异再由同一个 `EnemyCrowd` 生成；选点按照方案体型和最大随机放大值验证。体型不会重复缩放。

## 生存压力编排

当前已按数量不足反馈提高密度，参数都保存在同一[独立编排](../../data/encounters/sanctum_creatures.json)，重新开始一局读取。

| 字段 | 当前值与作用 |
|---|---|
| wave.base_enemies / growth_per_wave | 30 / 15：三波30、45、60只，共135只 |
| spawn.max_alive | 30：同时在场小怪的硬上限 |
| spawn.target_alive / refill_interval | 24 / 0.10秒：还有本波预算且少于24只时加快补怪；尾段预算耗尽后正常排空 |
| spawn.squad_member_interval / spawn_interval | 0.12 / 0.35秒：小队成员及小队之间的节拍 |
| spawn.ranged_ratio | 0.30：首六只覆盖后，补充池70%近战/30%远程 |

这些参数改变数量和加入战斗的节奏，单体生命、伤害、移动、前后摇、体型与个体差异仍读取各敌人的已保存方案。没有额外覆盖泰坦的实战台方案。此版为加强生存压力的试玩值，实际难度与长局性能仍由用户体验确认。

## 公共接入约定

1. 战斗宿主应是带真实碰撞、生命、`take_damage` 和目标获取的实体；纯 `Node3D` 外形不能直接当成小怪。通过公共导航/地面或空中运动执行位移，通过实际命中系统造成伤害。
2. 在 [creature_catalog.gd](../../scripts/enemies/creature_catalog.gd) 注册 `species`、场景和调参配置 ID。宿主提供静态 `get_body_dimensions(values)`；选点与碰撞使用同一份尺寸定义。注册表直接查询脚本，不为测尺寸构造尚未进树的敌人。
3. 在编排 `entries` 填入 `species`、角色/掉落分类、方案、权重、解锁等级和投放距离。新编排漏写或写错物种会明确报错并停止，不会默默回退成旧机器人。后续添加物种可以继续复用同一生成与波次链路。
4. [EnemySpawner](../../scripts/enemy_spawner.gd) 在进树前注入调参快照和正式敌人标记；进树后绑定玩家、按照真实体型/悬停高度摆位，安装 [EnemyLifecycle](../../scripts/enemies/enemy_lifecycle.gd)。普通敌人仍是碰撞层 4、遮罩 3，不做敌人之间的实体碰撞，保留软分离、绕行和错峰。
5. 致死伤害通过 `Lifecycle.credit_player` 给击杀奖励；先进入死亡状态，再调用 `Lifecycle.begin_death`。宿主声明 `died(enemy)` 信号，由公共流程恰好发一次；正式模式才调用公共掉落表。没有 AI 目标时也能归属玩家击杀，不重复发奖励。飞行敌人的掉落采样地面后放置。
6. 死亡表现独立于活体根节点继续。真实演出节点加入 `enemy_death_effect`，向 `Lifecycle.register_effect` 登记取景对象；结束时移出组或随演出计时器回收。保留静态尸体的宿主应在死亡动画结束时移出等待组，并另行安排尸体回收。纯展示死亡不会因此产生正式掉落。
7. 波次的电影镜头结束后还要等待当前场景所有活动死亡演出；等待期间不启动下一波。完成后才发选卡/通关事件。暂停保持等待，玩家死亡、退出或重开取消旧请求。泰坦旋转死亡核心也登记进此组，不能只等身体碎片。
8. 公共附属节点按编排的巡检间隔检查坠界/越界，恢复合法出生点，不误算击杀或额外掉落。普通导航局部卡住仍交由既有导航恢复逻辑处理；这不代表全图寻路问题已经全部解决。

## 六种小怪的受击反馈

六种均使用[共享闪红组件](../../scripts/enemies/enemy_hit_flash.gd)，真实受伤立即叠红，连续命中刷新，暂停冻结，结束恢复原材质。每只缓存网格并复用一份叠层材质，不在每次命中创建新材质或改变共享基础材质。各自面板新增「受击反馈」组：`hit_flash_duration`（秒，默认0.14）、`hit_flash_strength`（比例，默认0.8），保存和生效时机同其他参数。

战斗实验场「敌人不死」对六种小怪均有效：照常结算伤害和受击反馈，生命下限1，不提前结束回合。该标记只用于实验场，主场景不启用。Esc和Q既有显示/输入流程保持。

## 矮墙、岩石与晶兽接战修复

- 三种新宿主完整推进共用空间规划器，并提供实际攻击条件及远程站位圈。远程站位由自身撤退退出距离和攻击范围派生，避免套用近战1–3米站位后找不到合法射击位置；进入撤退触发区立即交回自身撤退行为。
- 寻路先尝试短通道，完整身体通不过时，在转角外侧做有限净空修正；去除共线门户提示点，避免大体型脚印在岩石/墙角被误抬到障碍顶部。每段仍检查真实碰撞、支撑及跌落安全；不能通过才尝试另一条路线，没有穿墙或瞬移兜底。
- 爬兽选站位与实际投囊共用抛物线路径检查，不再只根据发射口一条视线反复往岩石上投囊。蜘蛛使用晶眼实际视线，兜虫起冲前检查完整身体通道，遇墙停止流程保留；处于顶撞范围外、冲锋下限内时继续接近，不原地反复空顶。
- 晶兽选招与预警统一使用世界尺寸，消除随机体型重复缩放；实际无法落脚的飞扑不再被导航当作“已经能攻击”。近于扑击下限时启用原近身跳咬，避免导航带到玩家身旁后无法攻击。跳咬高度计入玩家真实身体半高，选招只检查实际挥击窗口能到达的高度，避免视觉相交但只拿中心点判空。
- 晶兽起招前补查当前危险预警，撤离的反应等待期不会被新近身跳咬抢占；远处正常移动仍保留。

晶兽的飞扑距离/速度/范围、近身攻击距离/高度/起跳速度仍使用原可保存字段，本轮没有改写用户已保存数值。原盾卫、Boss等共享空间系统经过回归；没有借此重做Boss设计。

## 投出的毒弹与持续黏液

爆囊爬兽的攻击毒弹命中后，保留原一次爆炸伤害，并生成独立毒池；投掷者死亡不会删除已落地的毒池。死亡动画自爆与毒液仍仅为表现。毒池半径4米（直径8米）、持续8秒，落地后每1秒结算一次6点毒伤；离开即停，没有额外减速，顿帧不会补发积压伤害。暂停冻结时长，到期回收，不占死亡等待组。

战斗面板同一爬兽方案新增「毒弹落地黏液」：poison_radius / poison_duration / poison_damage / poison_tick_interval / poison_hit_height；poison_duration=0关闭毒池。原impact_fx_lifetime改为末尾消退表现时长。保存命名方案、选默认、重新生成/开局后生效；用户旧方案通过schema继承新增默认值。毒伤沿用个体伤害差异。

[毒池实现](../../scripts/enemies/poison_puddle.gd)复用公共可达地表网格，墙/台阶/坡面裁剪与显示/命中共用覆盖，另查目标真实高度与遮挡。网格只在生成及环境几何变化时重建，伤害按周期检查玩家，不增加刚体、持续碰撞形状或逐帧射线矩阵。使用一份[黏液材质](../../shaders/poison_slime.gdshader)显示绿色膜边/流动斑纹。测试台清空与场景重开会回收动态毒池。

泰坦出土时由公共生成器立即绑定玩家。原场景边坡追击复现中，前探切平面可能钻入弯曲坡地，现允许逐小步验证连续支撑；空间攻击门控和实际选招共用高处判断；开场跃击无落点也可在同轮选择其他合法技能。Boss配置/命名方案保持与直战台相同；六物种保留，三波预算按最新生存压力反馈调整为30/45/60。
