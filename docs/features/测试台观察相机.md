# 测试台观察相机

各独立观察模块使用同一控制器 [observation_camera.gd](../../scripts/testing/observation_camera.gd)，固定视角与手动观察并存。正式玩家的移动／瞄准仍使用原输入。

| 操作 | 作用 |
|---|---|
| 按住右键拖动 | 围绕当前观察中心旋转；俯视也可转成斜视／侧视 |
| 滚轮向上／向下 | 拉近／拉远；透视改变镜距，正交改变视野跨度 |
| 按住中键拖动 | 在画面平面内平移观察中心，画面跟随拖动方向 |
| 固定机位／复位 | 清除手动构图，恢复该模块的预设位置 |

无需捕获鼠标；暂停／慢放不会缩放鼠标灵敏度。拖动在画面空白处开始，在界面上松开仍会结束；失去窗口焦点时也会清掉拖动状态。在控件上开始的拖动与滚轮由控件处理，不穿透到观察相机。滚轮围绕当前观察中心缩放。

战斗原型台启动时不预选任何敌人；选中敌人后才可开战。战斗空间台原有默认编组保留。

## 接入约定

1. 创建共用控制器并 `bind(camera, focus)`；宿主只把 `_unhandled_input` 中的事件交给 `handle_event()`，消费后标记已处理。
2. 固定机位使用 `set_view()`，或在设置原机架后重新 `bind()`；不再自行实现滚轮／右键／中键逻辑。
3. 控制器处理跨界面拖动和松键；窗口失焦取消拖动。相机不再是当前机位或模块退出时不得继续响应。条件观察模式应明确切换 `active`。
4. 跟随目标只调用 `translate_focus()` 平移相机和中心，保留用户构图；切固定机位则显式复位。
5. [观察相机合同](../../tests/test_observation_camera.gd)覆盖透视／正交手势、俯视边界、暂停、真实草稿按钮、GUI阻断／跨GUI松键与重播；已纳入默认验收。图形取证沿用[攻击观察探针](../../tools/probes/enemy_attack_observation_capture.gd)。

鼠标手感与不同观察对象的构图效果仍需用户试用确认。
