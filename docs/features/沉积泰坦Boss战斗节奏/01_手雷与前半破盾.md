# 手雷与前半破盾

本页是[唯一执行索引](../沉积泰坦Boss战斗节奏实施方案.md)中 A2／A3／A4 的按需细节，不另立计划；启动某一批后再读该批。

A4 分两次交付：A4.1 恢复原研究推荐的有限攻势、快慢刀和重招破绽；A4.2 再接三雷破盾的长奖励。后者细化奖励来源，不替代前者的攻势组织。

2026-10-16：A2、A3 首版与定向验证完成；用户已复测并授权 A4.1，首版完成、自动验证通过、待体验验收；A4.2 未开始。批次、确定程度与公共参数以 [方案索引](../沉积泰坦Boss战斗节奏实施方案.md)为入口。本分册负责 A2／A3／A4，每次只启动指定一批。

## 1. 最新规则

用户明确以后手雷统一接触敌人即爆炸并造成硬直，适用于所有正式场景和活跃战斗敌人。旧粘附方案取消，不再等待粘附引信，不再开发粘雷跟随、粘雷脱落或残留粘雷跨盾周期。

半血前泥盾仍需三枚不同手雷，各爆炸一次；现在每次是接触泥盾即爆炸。第一炸裂纹，第二炸剥落，第三炸崩盾、跪地。附近落地爆炸不冒充直接触盾破坏，但仍可按原范围规则伤敌和造成短硬直。

用户最新明确：前半每次重招准备前主动卸盾，前摇／出手／后摇期间无盾，后摇结束才重施；狂暴后彻底没有泥盾。三雷提供额外长跪地，不能成为常规无盾输出的唯一钥匙。

## 2. A2：通用触敌爆炸与真实短硬直

已落地入口：`scripts/grenade.gd` 的身体接触与球体扫掠共用一次爆炸锁；`combat_fx.gd` 统一结算，直接接触对象不受根节点偏移漏判，其余对象保留衰减／墙体遮挡。普通近战／远程、泥土傀儡、晶兽和蜂接入真实受击状态；正式 Boss 使用短动作暂停，泰坦空中命中延至安全阶段兑现，原攻击进度和方向保留，预警计时一起暂停。普通推力／Q 不使用新增手雷时长。

调参：`data/game_config.json → abilities.grenade.stagger_seconds` 普通敌人最短硬直 0.6 秒，范围 0.05–2；`boss_stagger_seconds` 正式 Boss 短硬直 0.25 秒，范围 0.05–0.8。编辑器保存配置并重新运行后生效，每枚生成时快照（仅 F5 重跑不会重新加载 GameConfig）；敌人原有更长反应保留，重复命中刷新而不累加。伤害／半径／推力／引信／库存与冷却沿用现值。秒数为首版起点，未验收手感。

### 本批只做

- 敌人身体或其有效护盾命中体接触手雷后，当次物理处理触发一次爆炸；接触玩家、投掷者、地形不是触敌。敌人命中体需解析回唯一伤害接收者，不能将每块子碰撞体都当成独立敌人。
- 当前 1.7 秒引信建议保留为未触敌的兜底，碰墙／地面维持原弹跳行为。接触起爆不重开引信、不延时等待；同帧接触和引信到期共用一次起爆门闩。
- 接触检测＋前后位置的高速穿越检测共用起爆入口。先处理世界遮挡／实际接触先后，不能隔墙提前命中敌人。
- 爆炸对有效受击敌人造成伤害和短硬直；沿用原范围、衰减、视线与友军规则，不顺带新增自伤或全局伤害调整。直接接触目标要纳入唯一受击集合，不能因大体型根节点离爆点远或自己的命中壳而漏伤；同一敌人不得再被范围枚举伤害一次。
- 硬直是实际运动／攻击受限，不是仅闪白、击退位移或镜头停顿。首版建议普通敌人 0.6 秒、Boss 0.25 秒，均需可调；只改变手雷来源，不让 Q、普通枪或其他爆炸自动获得同样的新硬直。

### 真实代码入口与兼容

当前 grenade.gd 仅按引信爆炸；CombatFX.apply_radial_damage() 结算伤害后调用 apply_push()。普通近／远战的 apply_push() 会进入硬直或取消蓄力，但泰坦的 apply_push() 只累加小幅推力，迅捷晶兽也会按参数决定是否打断。因此“已有击退”不能充当统一硬直已实现的证据。

计划入口：scripts/grenade.gd、scripts/combat_fx.gd 的手雷专用可选处理，以及真正参与战斗的敌人受击适配；普通近战、远程、旧 Boss、泥土傀儡、迅捷晶兽、晶刺蜂、沉积泰坦均列入覆盖。仅外形预览的三个新模型不当作现成战斗实体。

提供明确的爆炸硬直接收入口／兼容适配，不用对所有来源统一改 take_damage()，也不将 Boss 的 parry() 无条件当作普通手雷硬直。位移、硬直时长和招式打断语义分开，避免重复 apply_push() 与新反应各结算一次。

普通敌人可取消当前普通攻击后进入短硬直。Boss 首版建议短暂停止动作和攻击计时，结束后恢复已公布的攻击方向与进度，不重新选一招或偷偷追踪玩家；预警进度同步暂停。该补全为 AI 建议，供审阅，不是用户已确定的时长／打断规则。

跃击中的 Boss 不在空中悬停或瞬移，登记受击并在安全接地后兑现短硬直；飞行兵沿用其安全飞行受击方式，不套地面跪地。晶体 5 秒保护仍按战斗时间推进，不能通过投雷短硬直延长晶体保护。

重复命中可刷新至本次短硬直时长，不累加排队；已经跪地／倒地时只结算有效伤害，不替换、延长或缩短既有奖励。第三炸破盾的长跪地优先于该枚手雷的短硬直。死亡不再硬直。

### 本批验收与停止点

真实发射手雷命中近战、远程和 Boss；验证接触当次物理步爆炸、尚未到引信也起爆、只伤一次、硬直期间实际不能正常攻击／自主移动；测同帧引信、多个命中体、墙后敌人、高速目标、空中命中、死亡。普通场景也必须通过，不只在 Boss 台特殊开启。

已新增 `test_grenade_enemy_contact` 与 `test_grenade_hit_stagger` 并接核心验收，复跑相关战斗反馈／反应、环境破坏与场景依赖。交付 A2 后停止，不顺带改三枚储备或开发泥盾计数。

## 3. A3：只接泰坦战的手雷储备

已落地：正式生成器投放的泰坦与晚生成的玩家均自动接入同一 `scripts/grenade_reserve.gd` 资源实现；主场景、直战和陪练共用。初始3枚，1.2秒投掷间隔，逐枚6秒回充。后续投掷不重置正在进行的回充，满库存停表，暂停不计时。普通模式沿用原冷却。

进战保留玩家已有使用冷却；每次战内投掷也保留普通模式6秒冷却的剩余时间，退出时交接，不能进出立即再投。同一泰坦实例重复接入／狂暴／离开再进均不补满；战外该库存暂停回充，投掷间隔仍正常消退。新挑战实例初始化一次。Boss退出时恢复普通模式；死亡不继续走玩家计时。

HUD：标题显示「手雷2/3」，下行左侧「投1.2s／可投／空」，右侧「补6.0s／已满」，细条表示下一枚回充。陪练保存逐帧公开资源、输入前后库存与拒绝原因；新快照重放还比较库存、模式、容量和两个计时，旧记录缺该项不补造核对证据。

调参入口：编辑器运行敌人视觉观察台，选沉积泰坦，使用「正式泰坦战 · 玩家手雷储备」组。载入正式命名方案后修改，单独「保存命名方案」；「所选设为默认」是另一动作。**正式关底仍按 `data/game_config.json → bosses.sediment_titan.preset` 指定的「圣所关底 Boss」读取，不因观察台默认改变而切换。** 若另存新方案，要显式将该配置指向新名称并重新运行；当前局资源不会重发。文件是 `data/enemies/procedural_sediment_titan.json` schema与 `data/enemy_presets/PrototypeSedimentTitan.json` 命名值。五个字段均登记了玩家资源作用范围，不将其错误高亮为Boss身体。

参数：`grenade_reserve_enabled` 开关（原型默认false、正式方案true）；`grenade_reserve_capacity` 1–6枚；`grenade_reserve_start` 0–容量；`grenade_throw_interval` 0.4–6秒；`grenade_recharge_seconds` 2–30秒/枚。保存并重新运行后，新战斗实例快照；不改正在运行的库存。3／1.2／6仍是首版手感起点。

本批采用容量／初始 3 枚、最短投掷间隔 1.2 秒、逐枚 6 秒回充，体验尚未验收。首次进入正式泰坦战初始化一次；重开盾或跨半血不补满；退出时交接资源，防止反复进出刷额度。普通场景继续使用原单枚冷却资源模式，但起爆和硬直已统一使用 A2 新规则。

入口为 scripts/player.gd、scripts/ability_bar.gd、scripts/player_hud.gd、泰坦 schema／正式方案的战斗资源覆盖。共用同一个手雷和配置读取，不能只给直战台偷偷塞三枚。

HUD 同时区分剩余枚数、短投掷间隔、下一枚回充。E 空库存不扣成负数；充满停止计时，暂停不回充。保存命名方案和项目默认分开；资源变化可用固定 E 操作短段复现。

本批独立验收库存、回充、普通场景与 Boss 战切换、暂停和 HUD；不要求破盾／跪地已经实现。A3 已交付；用户随后复测并授权 A4.1，后续状态见下节。

## 4. A4.1：有限攻势、快慢刀与重招破绽

当前首版（2026-10-16，定向与图形验证通过，效果待用户体验验收）：正式「圣所关底 Boss」显式开启 `offense_enabled`，旧原型方案默认关闭；不修改原型 active。新增参数与旧招式时长都从观察台参数面板命名保存，下次生成实例生效；正式绑定仍由 GameConfig 的 preset 名决定。

| 可调入口 | 首版 | 范围／作用 |
|---|---:|---|
| offense_front_limit／offense_rage_limit | 2／3 招 | 1–4／1–5 整数；组开始锁定，半血不临时追加 |
| offense_link_timeout | 2 秒 | 0.3–6；收招后等不到合法后续则结束本组 |
| offense_failed_rest | 0.8 秒 | 0.3–3；衔接失败停止追击，保留常态盾，不兑换长奖励 |
| sweep_windup／sweep_swing／sweep_recovery | 0.42／0.32／0.2 秒 | 沿用既有合法范围；左臂拉开后横扫为快招 |
| slam_windup／slam_swing | 1.15／0.1 秒 | 右臂举高、身体扭转后定向砸地，准备阶段已卸盾 |
| slam_sink_time＋slam_hold＋slam_recovery | 0.2＋1.4＋0.8 秒 | 最后伤害后完整约2.4秒无盾收势 |
| leap_windup／leap_landing_hold＋leap_recovery | 1／1.6＋0.8 秒 | 屈膝双臂蓄力，合法落点接地后约2.4秒收势 |

选招仍先验证范围、通道、完整落点；快横扫优先，砸地或跃击可提前收尾，不强制固定连招。达到招组上限前一招后只接合法重招；无后续则超时短收势。每个成功开始的普通跳跃攻击也占一招；导航破障不占玩家攻势、不兑换重招窗口。短硬直冻结当前动作与计时，不重置招组。前半常态盾已随本步同步改为不定时消失，否则无法验证“主动卸盾至后摇结束”；三雷计数／跪地与关闭旧Q解盾仍留 A4.2。

狂暴全程无泥盾，包括共鸣强制入口；本批不改旧狂暴伤害／范围倍率、生命或武器数值。当前后半可能仍很凶，倍率收敛仍在 A5。常规卸盾只开放正常身体伤害，没有跪地、倒地或新增倍伤。

本步先验证「施压 → 读招 → 重招收势 → 实际反击／推进破解 → 再次施压」，不把仅改前摇快慢或仅加三次计数当作完整节奏方案。

- 复用横扫、砸地和跃击，用有上限的招组安排施压。可先对照前半「快 → 慢重招」、后半「快 → 快 → 慢重招」；这是待审阅候选，不是已定的固定连招。距离／通道／落点不合法就合理结束或换合法动作，不能无限补招拖长这一组。
- 快招先保留现有可避性；慢招以不同准备姿态、定势和明确落招形成预判，不以同一姿态随机等时惩罚玩家。旧慢招 0.9–1.2 秒仅作对照参考，命中方向和范围公布后仍须遵守。
- 收尾重招完成后保证一段可读、可实际利用的收势：不追击、不立即起下一招。记录从攻击判定结束到再次施压的实际可行动时间；时间由调参验证，不能只把动画拉长却继续攻击。
- 前半先卸盾再进入重招准备／预警，无盾贯穿前摇、出手和完整后摇；后摇结束才允许重施。重招仍有攻击风险，后摇则是明确的常规无盾输出时间。盾视觉与真实减伤同步，不能只藏模型或仍留80%减伤。
- 后半全程没有泥盾，共鸣也不能再开泥盾；重招后摇仍不追击或追加攻击。身体正常可伤，晶体5秒保护只护晶体，不挡身体；三枪倒地另外提供长窗口和最终×2，不能作为唯一有效输出手段。
- 主动卸盾不等于三雷破盾，不自动给予跪地、倍伤或破解次数。边界建议：主动卸盾保留已积累的裂盾进度；无盾时手雷照常伤害／硬直，但不冒充命中泥盾；重新施盾显示已有裂纹。若真实三雷已触发跪地，重招旧回调不得提前施盾。该进度处理是实施建议，与用户明确的卸盾时间分开。
- 招组计数、收势和半血切换需区分；普通短硬直不能把招组无限重置或不断追加招式。导航破障不自动兑换同等长奖励；所有状态遵守死亡／安全接地／已挣得奖励的优先级。

本步独立验收：重招准备开始时已经无盾，出手与后摇最后一帧仍无盾，后摇结束后才重施；每组结束真实交还主动权；实际普通射击能得到常态无盾伤害，不要求先三雷／三枪。狂暴与共鸣均不得恢复泥盾。对照先保持血量、伤害、配装及长奖励不变，只验证本步后交付，A4.2 继续未开始。

## 5. A4.2：三炸破泥盾与前半跪地

正式泰坦新方案在出土结束后开启泥盾，保留开场跃击。普通子弹仍按现有泥盾 80% 减伤结算；新盾不按旧 6 秒自行消失。命中有效盾的三枚手雷各计一次即时爆炸：爆炸／盾周期标识共同去重，落地范围爆炸、普通枪和同一爆炸的多部位回调不增加次数。

第三炸先按命中时状态结算该枚爆炸，再移除盾、取消后续技能伤害，转入跪地：跪下 0.6 秒 → **有效输出 4 秒** → 起身 0.8 秒，均为 AI 首版建议。有效时间从姿态稳定、能够射击时开始；不额外给倒地 ×2，保持无盾正常承伤。第三炸不能同时重入短硬直和长跪地。

空中破盾取消该技能后续伤害并安全接地，再开始完整奖励，不悬停或瞬移。已有预警、横扫与落地效应不能残留伤人。长跪地起身后若仍在前半，则恢复常态泥盾并清零该盾周期计数；如果已进入狂暴则不再施盾。不在奖励期重建，也不额外插6秒等待；后续重招仍按A4.1主动卸盾。

输出跨过 50% 先记待切换，完成已经挣得的跪地奖励后进入狂暴；若直接击杀正常死亡。正式新方案建议关闭 Q 解除泥盾，保留 Q 自救；原型旧方案不自动修改。共鸣奖励期例外沿用索引，须明确验收，不能因临时开泥盾吞掉窗口。

本批入口：procedural_sediment_titan.gd、titan_combat_brain.gd 的奖励门控、schema、正式命名方案、visual_param_parts.gd。参数作用部位与阶段逐项登记，保留观察台 play 能力声明。

本批验收：0／1／2 炸不破盾、第三炸只触发一次；真实 E 三投可以完成，无粘附等待；短硬直不掩盖进度；地面／空中、半血、死亡、暂停、盾再生、投失与资源不足均可重复观察。只交付前半循环，不提前写晶体和后半倒地。

体验另记：三投准备的实际操作／资源等待各占多久，第一次和第二次的破坏反馈是否清楚，投失是否只是损失一次机会而非抹掉前功，跪地是否能换来有感收益。不能把「再多扔两枚，所以打得更久」当作新挑战；若只是固定次数门票，记录为设计未证明，不以三炸计数测试代替体验验收。

## 6. 参数入口与生效约定

通用起爆／硬直已在 data/game_config.json 的 abilities.grenade 落地；泰坦战储备也已落地，字段见A3本节。以下三雷／跪地仍是待实现契约，常态盾与重招卸盾已在 A4.1 接入，在泰坦 schema 与「圣所关底 Boss」命名方案，未知参数不得借旧 active 方案传播。

| 参数概念 | 首版、单位 | 可调范围与生效 |
|---|---|---|
| 普通敌人／Boss 爆炸硬直（已实现） | 0.6／0.25 秒 | 0.05–2／0.05–0.8 秒；保存配置并重启运行，生成新手雷时快照 |
| 未触敌兜底引信 | 现有 1.7 秒 | 继续现有合法范围；投出时快照，不能延迟已触敌起爆 |
| 战斗储备上限／初始值（已实现） | 3／3 枚 | 上限1–6，初始0–上限；新战斗实例 |
| 两投最短间隔（已实现） | 1.2 秒 | 0.4–6 秒；新战斗实例快照 |
| 逐枚回充（已实现） | 6 秒／枚 | 2–30；新战斗实例快照 |
| 泥盾有效爆炸次数 | 3 次 | 诊断可调 1–8；下层盾，正式默认仍按用户 3 次 |
| 跪下／有效跪地／起身 | 0.6／4／0.8 秒 | 0.1–3／1–12／0.1–3；下次状态 |
| 泥盾重生 | 前半重招后摇结束或长跪地起身结束后 | 不早于窗口结束；狂暴后禁止重生，不额外插6秒等待 |

接触起爆属于已确定通用规则，不能因旧原型默认或敌人抗击退而静默退回引信等待／免硬直。改变正在运行状态的参数只影响下一次快照，已公布攻击的预警与硬直暂停同步。新增参数登记作用部位和阶段，给最小重播入口；保存并重新运行后，再用 F5 重跑同一条件。A8 再综合检查跨批保存。
