# 敌人统一参数与攻击观察

编辑器 F6 运行 [战斗原型测试台](../../prototypes/combat_lab/combat_lab.tscn)，敌人行点“调参”。七种可战斗敌人共用下面的布局与技能参数语义，原方案的存储键、基础数值及当前默认选择保留。完整映射见[统一参数表](敌人统一参数表.md)。

## 固定布局

| 顺序 | 分页 | 内容 |
|---|---|---|
| 1 | 基础属性 | 最大生命、基础体型、护甲、排列占位 |
| 2 | 移动与距离 | 移动、转向、加速度、重力、绕行、撤退、悬停 |
| 3 | 攻击技能 | 每招一个小节；范围→伤害→前摇／生效／停留／后摇→冷却→攻击移动与弹体 |
| 4 | 受击反馈 | 打断、击退、硬直、闪白 |
| 5 | 个体差异 | 开关、移动／伤害／体型／时序／步频浮动与初始相位 |
| 6 | 群体运动 | 感知、避让、路径散开、速度节奏与同时攻击比例 |
| 7 | 外形与表现 | 共用步态、呼吸、颜色、姿态比例、死亡与碎片表现 |
| 8 | 专属参数 | 物种外形、独有动作、特殊机制／阶段与策略；保留分节 |

没有使用的公共分页仍保留位置并说明不适用，不伪造一个可调但没有效果的参数。同一技能内按行从左到右读取。搜索同时覆盖分页、技能名、统一名称与原字段。

### 必须区分的语义

- **施放距离**决定能否起手，**命中尺寸**决定打到哪里；投囊的施放距离与爆炸半径、兜虫的起步距离与冲锋长度分别调。
- **起手冷却**从开始攻击计时，**出手冷却**从发射弹体计时，**结束冷却**从动作结束计时。晶蜂的射击／俯冲属于结束冷却，棱眼蛛属于出手冷却。
- 泥土傀儡与晶兽使用扇形**半角**，泰坦横扫使用**全角**，单位均标明“度”。泥土傀儡基础距离还会加上命中延伸距离。
- **转向角速度**是弧度／秒；晶兽、晶蜂使用的**转向响应率**是 1／秒，二者不能当作相同数值互换。
- 旧步态使用角频率，界面换算为统一的 **Hz**，输入时换回原存储单位；不会直接重写旧方案。
- 投射物的“弹体显示半径”控制模型大小。当前晶束、晶针和爆囊的飞行碰撞沿中心线逐段射线检测，不能将显示半径当作扫掠球碰撞半径。
- 爆囊的前摇是转身时间；原 `windup` 在真实倒放流程中是最终转回身体的时长，统一显示为“最终回位时长”。

## 体型联动

框内保存体型 1 的基础值；实际体型＝基础体型倍率×本个体随机体型。带 **↗** 的字段随体型联动，悬停显示具体换算规则。

- 模型与本体碰撞由根节点缩放一次；局部模型尺寸不能再乘一遍。
- 近战命中尺寸、世界施放／撤退／绕行距离、远程航程／落地爆炸／黏液区域、冲锋长度与接触距离、群体占位／感知等按实际体型缩放。
- 为使攻击移动在原时长内覆盖放大后的路线，飞扑水平速度倍率、俯冲／冲锋速度、泰坦跃击旅行速度及晶束速度同步换算。投囊按原飞行时间重算初速，弹道重力随体型换算。
- 最大生命、伤害、护甲、通常移动速度、技能时序、冷却、角度、比例与瞄准玩家身体的高度偏移独立控制。它们不会因为体型放大自动加倍。
- 晶兽飞扑的垂直起跳速度、重力和最长飞行时间继续共同决定纵向弧线与可达性；水平航程和命中尺寸随体型。地形／落脚检查仍可拒绝起手，范围变大不代表一定可施放。

换算发生在实例生成时；保存的仍是基础数值。输入边界验证也只针对基础值，运行中的世界距离超过编辑框上限不属于非法输入。

## 攻击观察

在调参页点 **“观察本草稿”**，会以未保存草稿重建单体与真实玩家目标，关闭个体浮动／群体运动、指定个体种子。目标不操作、双方不死亡；只执行所选技能，使用真实伤害／弹道／地形检查入口。

1. 选择技能，调整“距离”（米），点“重播”。重播重新生成同条件实例；改距离不会悄悄保存方案。
2. “暂停／继续”冻结世界；冻结后点“单帧”只推进一个物理帧；速度支持 1／0.5／0.25／0.1 倍。
3. “交战区域／完整范围”调整构图，另有斜视、俯视、侧视与镜距倍率。长冲锋可以切“完整范围”，近看动作可调低镜距。
4. “攻击范围”“轨迹”分别开关；留痕 0.5–30 秒，默认 8 秒，可清除。
5. “返回调参”回到同一草稿；返回敌人配置后正常生成一局，才进入真人试玩。

| 颜色 | 读什么 | 限制 |
|---|---|---|
| 青蓝 | 理论范围、同公式预计路线 | 尚未替代地形／遮挡／落脚证明；完整范围可能超出场地 |
| 橙红 | 本次攻击的准备／锁向快照及实际黏液区域 | 最终命中仍检查高度、可达地表与遮挡；原游戏预警继续显示实际地表 |
| 绿色 | 拳头、横扫端点、口器／角部、身体与已发射弹体的实际逐帧运动 | 原地出拳也有轨迹；弹体包含最后碰撞点；到期清除，不存磁盘 |

普通战斗默认也显示当前敌人／技能的范围观察条，**V** 开关；暂停后可选敌人和技能。暂停与逐帧按钮只在单体观察显示。观察线为方便分析穿透遮挡显示，不代表可以穿墙伤害。

黏液观察由真实投囊落地生成，不凭空创建另一份伤害区。护盾属于增益技能，没有对外伤害范围。泰坦跃击在起跳后读取锁定落点与弧高绘制预计路线，落点橙圈读取真实攻击区。

## 接入与验证

- [共享语义、顺序及体型规则](../../scripts/testing/enemy_parameter_layout.gd)：`COMMON`／`SLOTS`／`SKILLS`／`WORLD_KEYS`。专属字段自动归入最后一页，新增共性语义必须登记并复用。
- [实际技能观察适配](../../scripts/testing/enemy_attack_inspection.gd)：复用战斗 spec 和弹道函数；新增可战斗敌人需登记所有技能观察入口。
- [合同测试](../../tests/test_enemy_parameter_contract.gd)：七种敌人完整字段覆盖、固定分页、技能绑定、真实实例 1／2 倍体型、独立属性、单招启动与暂停／单帧、显示单位往返。已加入默认验收列表。
- [隔离截图探针](../../tools/probes/enemy_attack_observation_capture.gd)：实际面板和六种典型攻击图形取证。

本功能是草稿重建／重播观察，尚没有冻结姿态后拖动参数即时变形或任意时间轴定位。视觉测试台的三种纯外形仍使用同一语义和分节顺序，外形预览沿用原即时生效能力。
