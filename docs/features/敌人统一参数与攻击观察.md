# 敌人统一参数与攻击观察

编辑器 F6 运行 [战斗原型测试台](../../prototypes/combat_lab/combat_lab.tscn)，敌人行点“调参”。七种可战斗敌人共用下面的布局与技能参数语义，原方案的存储键、基础数值及当前默认选择保留。完整映射见[统一参数表](敌人统一参数表.md)。

T02后以下八类仍是完整定义与只读参考的共同语义。战斗页只编辑个体战斗参数，外形通过“外形 ↗”进入视觉台；视觉页通过“技能 ↗”返回专业战斗页。统一左上角返回保留草稿与原文；[具体入口、支持对象与保存边界](测试台参数草稿与保存.md)。

## 固定布局

| 顺序 | 分页 | 内容 |
|---|---|---|
| 1 | 基础属性 | 最大生命、基础体型、护甲、排列占位 |
| 2 | 移动与距离 | 移动、转向、加速度、重力、绕行、撤退、悬停 |
| 3 | 攻击技能 | 每招一个小节；范围→伤害→前摇／生效／停留／后摇→冷却→攻击移动与弹体 |
| 4 | 受击反馈 | 打断、击退、硬直、闪白 |
| 5 | 个体差异 | 开关、移动／伤害／体型／时序／步频浮动与初始相位 |
| 6 | 群体运动 | 感知、避让、路径散开、速度节奏与同时攻击比例 |
| 7 | 外形与表现 | 共用步态、呼吸、颜色、姿态比例、死亡与碎片表现 |
| 8 | 专属参数 | 物种外形、独有动作、特殊机制／阶段与策略；保留分节 |

没有使用的公共分页仍保留位置并说明不适用，不伪造一个可调但没有效果的参数。同一技能内按行从左到右读取。搜索同时覆盖分页、技能名、统一名称与原字段。

### 必须区分的语义

- **施放距离**决定能否起手，**命中尺寸**决定打到哪里；投囊的施放距离与爆炸半径、兜虫的起步距离与冲锋长度分别调。
- **起手冷却**从开始攻击计时，**出手冷却**从发射弹体计时，**结束冷却**从动作结束计时。晶蜂的射击／俯冲属于结束冷却，棱眼蛛属于出手冷却。
- 泥土傀儡与晶兽使用扇形**半角**，泰坦横扫使用**全角**，单位均标明“度”。泥土傀儡基础距离还会加上命中延伸距离。
- **转向角速度**是弧度／秒；晶兽、晶蜂使用的**转向响应率**是 1／秒，二者不能当作相同数值互换。
- 旧步态使用角频率，界面换算为统一的 **Hz**，输入时换回原存储单位；不会直接重写旧方案。
- 投射物的“弹体显示半径”控制模型大小。当前晶束、晶针和爆囊的飞行碰撞沿中心线逐段射线检测，不能将显示半径当作扫掠球碰撞半径。
- 爆囊的前摇是转身时间；原 `windup` 在真实倒放流程中是最终转回身体的时长，统一显示为“最终回位时长”。

## 体型联动

框内保存体型 1 的基础值；实际体型＝基础体型倍率×本个体随机体型。带 **↗** 的字段随体型联动，悬停显示具体换算规则。

- 模型与本体碰撞由根节点缩放一次；局部模型尺寸不能再乘一遍。
- 近战命中尺寸、世界施放／撤退／绕行距离、远程航程／落地爆炸／黏液区域、冲锋长度与接触距离、群体占位／感知等按实际体型缩放。
- 为使攻击移动在原时长内覆盖放大后的路线，飞扑水平速度倍率、俯冲／冲锋速度、泰坦跃击旅行速度及晶束速度同步换算。投囊按原飞行时间重算初速，弹道重力随体型换算。
- 最大生命、伤害、护甲、通常移动速度、技能时序、冷却、角度、比例与瞄准玩家身体的高度偏移独立控制。它们不会因为体型放大自动加倍。
- 晶兽飞扑的垂直起跳速度、重力和最长飞行时间继续共同决定纵向弧线与可达性；水平航程和命中尺寸随体型。地形／落脚检查仍可拒绝起手，范围变大不代表一定可施放。

换算发生在实例生成时；保存的仍是基础数值。输入边界验证也只针对基础值，运行中的世界距离超过编辑框上限不属于非法输入。

## 实验范围与错误恢复

所有七种敌人的数值框、共享草稿、命名保存和真实观察使用[同一范围策略](../../scripts/testing/enemy_parameter_limits.gd)。原schema的min／max保留为“原建议”，不再把玩法调优区间直接当作实验上限；基础值、现有命名方案和active不被改写。范围仍是有限的支持预算，不是引擎绝对极限，也不代表每种极端组合都能通过地形与技能条件。

| 参数类别 | 当前实验边界 |
|---|---|
| 移动／冲锋／弹体速度 | 0–1000米／秒；兜虫攻击移动速度可直接输入50、300、500 |
| 距离／长度 | 上限1000米；保留非负或正几何下限 |
| 时长 | 通常上限300秒；逐帧预计算的晶针／弹道／飞扑最长时间上限30秒，避免无限取样；分母相关时长保留正下限 |
| 频率 | 通常上限100Hz或100次／秒；旧角频率仍按TAU换算 |
| 生命／伤害 | 上限10亿点；不改变基础值 |
| 倍率／权重、体型 | 通常上限100倍；基础体型支持上限20倍 |
| 比例／颜色／阶段 | 颜色、透明度、减伤、群体占比0–1；阶段占比0.001–0.999，随机浮动上限±0.99以保留正倍率；会相减的囊体收缩保留已支持几何范围 |
| 计数／命中角 | 计数须整数，逻辑计数实验上限100；晶蜂仍对应0–3个固定晶针槽；扇形半角≤180度、全角≤360度 |

以每项悬停显示的实际允许边界、原建议和约束原因为准；已有合法范围不会被缩小。成对距离／随机区间／容量等还须满足字段关系，报错会同时列出涉及的参数。

- 错误持续显示对象、分页／模块、参数、输入内容、允许范围或关系原因；数字框标色。草稿刷新不会抹掉报错，也不把超限原文悄悄改成边界数值。
- “观察本草稿”或“保存候选”失败时，战斗面板解除搜索并定位到出错分页／字段；非法输入不会冒充旧值预览或保存。视觉面板解除搜索并滚到相关字段。
- “返回敌人配置”始终可用：合法输入提交到草稿；非法原文留在本进程同一对象／方案的输入缓存。回来后可继续改，返回后也可打开其他对象。
- “撤回输入”只撤回尚未提交的文字，保留已经进入共享草稿的修改；已提交但关系不合法时仍需修正、撤销或还原草稿。结束进程不会保留未保存草稿／文字。
- 保存目录不可写、文件占用、同名冲突、外部修改、未保存就设默认等失败保留草稿并显示原因；磁盘写入问题附目标与恢复建议。另存候选与设为默认继续分开。

## 攻击观察

在调参页点 **“观察本草稿”**，会以未保存草稿重建单体与真实玩家目标，关闭个体浮动／群体运动、指定个体种子。目标不操作、双方不死亡；只执行所选技能，使用真实伤害／弹道／地形检查入口。

1. 选择技能，调整“距离”（米），点“重播”。重播重新生成同条件实例；改距离不会悄悄保存方案。
2. “暂停／继续”冻结世界；冻结后点“单帧”只推进一个物理帧；速度支持 1／0.5／0.25／0.1 倍。
3. “交战区域／完整范围”调整构图，另有斜视、俯视、侧视与镜距倍率。也可按住右键旋转、滚轮缩放、按住中键平移；冻结时可用，重播保留手动构图，选择固定视角可复位。各观察台共用[同一操作规则](测试台观察相机.md)。长冲锋可以切“完整范围”，近看动作可调低镜距。
4. “攻击范围”“轨迹”分别开关；留痕 0.5–30 秒，默认 8 秒，可清除。
5. 左上角统一“←返回”回到同一参数草稿。普通观察仍可回配置生成一局；三线重击定格面板另有同草稿“真人试打”。

### 三线重击定格编辑（T03首批）

入口：战斗原型测试台F6 → 沉积泰坦行“调参” → “观察本草稿” → 技能下拉选“三线重击” → “定格编辑”。战斗空间台继承此入口。其他技能目前保持原有重播／暂停观察，定格编辑按钮禁用并提供能力提示。

- 进入后重建静止样本，固定目标距离、朝向及个体种子20261020，暂停物理；右侧用原参数页的同一输入控制器和草稿，无第二份配置。项目默认未启用狂暴编排时先明确勾选“启用”；开关也影响真实狂暴选招，仅修改草稿。
- 命中长度／宽度以米、相邻重击夹角以度调整；前摇／后摇以秒调整。合法输入可在尚未离开数字框时即时预览，回车／离开输入框提交。单次伤害和结束冷却也能调整，但需要真实重播／试打验证，不把几何预览当作伤害已执行。
- “几何时间”以秒固定绝对时刻，改变时长不自动挪动时刻；滑条只采几何和技能阶段，不倒放肢体、Tween或物理世界。青蓝为完整理论边界，橙色为该时刻尚未命中的锁定预警；后摇／结束阶段不再显示有效预警。定格期间暂停／单帧／倍速按钮禁用，退出定格后沿用原观察能力。
- “播放单次”用当前完整合法草稿重建，调用真实技能入口，完整收势后自动冻结；可重播。“真人试打”同样重建，开启真实选招AI和玩家控制，玩家无敌／敌人不死沿用配置区；当前被锁定的旧攻击不会被输入偷偷改写。
- “收起编辑”只收起工具并保持冻结；若运行样本仍为旧修订会提示“待重播／试打”。左上角返回保留草稿、精确原文与错误，完整参数页继续编辑或“保存候选”；候选与设默认仍分开。准备过程中立即返回会取消尚未完成的观察交接。
- 非法输入持续标红并显示字段、原文、范围与恢复建议，悬停可看完整说明；暂停更新预览并显示已提交合法草稿。“撤回输入”只撤回未提交文字，保留有效修改；非法输入不能播放／试打，但可返回。

[共享三线定义](../../scripts/prototypes/titan_triple_slam_definition.gd)供实际狂暴施放和定格采样共同读取尺寸、朝向、时序及固定4.1米高度。实际命中继续使用EnemyAttackArea的地表／高度／遮挡检查，三道交叠只结算一次；本批未改变正式数值和默认方案。测试与证据见[同一任务T03记录](../tasks/实验与调试体系摸底.md#t03执行三线重击试点2026-10-21)。

| 颜色 | 读什么 | 限制 |
|---|---|---|
| 青蓝 | 理论范围、同公式预计路线 | 尚未替代地形／遮挡／落脚证明；完整范围可能超出场地 |
| 橙红 | 本次攻击的准备／锁向快照及实际黏液区域 | 最终命中仍检查高度、可达地表与遮挡；原游戏预警继续显示实际地表 |
| 绿色 | 拳头、横扫端点、口器／角部、身体与已发射弹体的实际逐帧运动 | 原地出拳也有轨迹；弹体包含最后碰撞点；到期清除，不存磁盘 |

普通战斗默认也显示当前敌人／技能的范围观察条，**V** 开关；暂停后可选敌人和技能。暂停与逐帧按钮只在单体观察显示。观察线为方便分析穿透遮挡显示，不代表可以穿墙伤害。

敌人死亡、散架或回收后停止读取其攻击部位与当前技能范围，已录实际轨迹仍按留痕时间显示；面板说明当前对象已死亡／回收。重播或重新投放后恢复新样本观察，不追踪死亡碎片。

黏液观察由真实投囊落地生成，不凭空创建另一份伤害区。护盾属于增益技能，没有对外伤害范围。泰坦跃击在起跳后读取锁定落点与弧高绘制预计路线，落点橙圈读取真实攻击区。
