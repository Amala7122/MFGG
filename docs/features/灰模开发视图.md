# 灰模开发视图

旧版五项改进移植的最后一项。只用于观察体量、道路、障碍和攻击范围，不改碰撞、寻路、伤害、敌人动作或泥盾规则。针对用户反馈I-188 / I-189已接入道路网格和效果分类适配，观感仍待用户复看；手绘风的认可不代表本灰模已验收。

## 入口与保存

- 从编辑器运行，按 **F4** 切换灰模 / 原画；显示设置也有“灰模开发视图”按钮。本次运行跨场景保持，重新启动默认关闭，不把开发视图写进个人显示偏好或项目默认开关。
- 游戏或独立实验场运行且未暂停时按 **F10** 打开调参。它会暂停战斗并临时预览灰模，Esc / F10返回。打开前灰模已开启，关闭面板后继续灰模；打开前未开启，关闭面板后恢复原画。
- 调整即时生效，未保存草稿有明确提示。“保存为项目默认”只保存参数，不改变下次启动的开关；“重读默认”放弃当前草稿。没有用户命名方案库，不把保存方案与设默认混为同一操作。
- F7近战、F8卫士 / 护盾不变，和F10互斥。灰模期间F9手绘面板不打开：先F4退出灰模，再调手绘，避免调整时看不到效果。

唯一参数文件：[greybox.json](../../data/graphics/greybox.json)。运行窗口F10提供：细格间距0.25–4米、每粗格2–10个细格、细线宽0.005–0.1米、粗线宽0.01–0.2米、棋盘明暗0–1、主光0–3、环境光0.1–2、接触阴影开关、中性灰扬尘0关 / 1开，以及地面 / 障碍 / 敌人 / 背景颜色。默认细格1米、粗格5米、扬尘关闭；道路和地形同步使用同一网格尺度。保存使用共用项目外备份与SHA回执；发行包不允许改项目资源。

## 显示与恢复

地面 / 掩体 / 道路使用同源世界空间三向网格，道路底色稍深，格线原点与尺度连续。道路本来就是贴地Mesh；本次不加厚、不新增碰撞或绘制叠层。玩家以浅色分层，敌人以橙色分层。普通Mesh与MultiMesh均支持，后生成的敌人或部件延后到初始化完成再接入。不改共享Mesh或原材质资源；关闭时恢复原引用。如果外部明确换了某节点材质，不拿旧快照覆盖它。

仅隐藏确定的纯装饰：Grass脚本层、Flowers、GroundPebbles、DistantPines、缓存MeadowColonies / MeadowShrubs。不隐藏整个WorldDecor，带碰撞的BoulderBatch、外围BankBoulders、树干和实体掩体继续显示。实例数量、变换和碰撞不变。

真实AttackArea的完整外沿 / 逐渐填充、Telegraph / GroundWarning、能量护盾、火花 / 共鸣等继续保留原材质。弱点HeadCrystal与晶体火焰不涂成橙色；实体泥盾不是透明能量罩，不按名字中所有shield一概替换透明材质。HUD和运行面板不改。

敌方弹幕使用不发光的浅灰弹芯、深色细外缘和克制短尾，关闭它的局部投光，不隐藏弹体或改轨迹 / 数值。卫士机体、光环 / 透镜和CPU尾焰使用中性灰材质副本；索敌 / 超频仍可改变中性明度，动画照常。卫士与独立钉弹均关闭局部投光，即使挂在玩家下面也不漏过。效果按正式脚本身份分类，钉弹识别实际内嵌类，不靠默认节点名猜测。

脚步 / 落地同源扬尘默认只隐藏粒子显示，脚步声音、发射参数、强度差异和寿命清理不变。F10把“中性灰扬尘”改为1可即时预览低透明度版本；只创建独立灰色色带，保留原Quad软边纹理与透明渐隐。退出恢复原色带和原可见性，不改变正式扬尘参数。

动态新生、敌弹池化复用与离树恢复共用同一接管逻辑。卫士原材质仍由业务脚本更新，灰模只同步少量共享副本，不回写原材质或把灯能量设为0；退出时恢复原引用 / 灯可见性，期间最新的锁敌 / 超频 / 发射颜色和灯能量不会退回旧快照。F8正式表现配置未改。

灰模使用独立相机Environment与中性灯，不写原Sky3D环境、光源能量、天气配置。天空 / 天气显示控制器暂时冻结自动推进，雨雪云和SkyDome独立雾幕暂时隐藏；退出恢复原处理模式、可见性、相机Environment引用。不是调用Graphics套一遍默认，也不复制旧时刻资源覆盖当前状态。

原天气预报脚本仍运行，**F1敌人冻结调试仍走原入口**；它不是灰模管理器的新机制。F2 / F3原调试入口也未替换：若主动手动改时间 / 天气参数，退出后继续使用这些新选择，灰模不会回滚用户的明确操作。自动天空时间在灰模期间不推进。

手绘和其他全屏风格只临时绕过，选择与参数不丢；灰模期间从显示设置改了风格，退出后使用最新选择。场景退出清理旧引用，下一场景接入灰模，不遗留F10暂停。

[显示总管](../../scripts/greybox_director.gd)、[配色与效果适配](../../scripts/greybox_palette.gd)、[度量网格Shader](../../shaders/prototype_grid.gdshader)、[弹体细外缘Shader](../../shaders/greybox_projectile_rim.gdshader)、[参数校验](../../scripts/greybox_settings.gd)、[F10面板](../../scripts/greybox_panel.gd)、[专项验收](../../tests/test_greybox.gd)。只在开启时维护当前相机、已接管灯 / 可见性和少量卫士共享材质；有变化才同步副本参数，不每帧全树扫描。默认关闭停止自身逐帧处理。

运行 `python -B tools/run_acceptance.py --tests test_greybox --graphics --task greybox_check`。检查原引用恢复、隐藏值、共享资源、批量实例、100个受控角色材质与位置 / 速度、动态部件、离树与待执行队列、相机更换、F10草稿 / 显式保存 / 回读、真实F4 / Esc、手绘绕过、正式地图天气持续运行、F1保留、缓存草丛 / 雾幕、预警与弱点、跨场景清理。新增真实道路材质 / 几何保持、卫士 / 钉弹动态接入、敌弹实际回池 / 再发射、状态更新不返彩、扬尘隐藏 / 中性预览 / 寿命清理，以及正式玩家行走 / 冲刺入口。图片写入项目外本次运行 `screenshots/greybox/`，含`fx_`开头的效果前后对照。

这不是100个真实敌人AI的帧率测试，也未验证所有外形、死亡特效、天气组合、分辨率、长期切换或发行包。材质名称启发式存在边界，新增效果需要相应保护登记。既有I-181旧Boss断言仍另行保留，本批没有为了让全套回归变绿而调整它。真实证据、源SHA和回退入口见[持续任务](../tasks/旧版五项改进移植.md)。
