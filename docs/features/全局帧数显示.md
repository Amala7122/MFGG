# 全局帧数显示

## 行为

- 任意场景（主游戏、战斗测试台、原型、独立 lab）自动在右下角显示 `FPS + 单帧毫秒 + peak`。
- `peak` 是最近 1 秒内最差单帧的毫秒数，用来暴露“平均 60 但会顿一下”的帧生成问题。
- 帧率用**真实墙钟**（`Time.get_ticks_usec`）计算，不用 `delta`：`--fixed-fps`、时间缩放、暂停都不会伪造帧率。
- 鼠标穿透，不接管点击、不参与游戏逻辑；暂停时仍然刷新。
- `F12` 切换显示。
- 主游戏 HUD 自己打开 `ui.show_fps` 时，全局显示让位给 HUD，避免同一屏两处数字。

## 自动化运行

`RUIN_STAR_AUTOMATION=1` 的验收/探针默认**不创建**该节点，避免影响像素对照和节点计数。
需要自动化截图也带帧数时：

- 命令行：`godot ... -- --fps-overlay`
- 或环境变量：`RUIN_STAR_FPS_OVERLAY=1`

## 入口与守卫

- 实现：`scripts/fps_overlay.gd`，autoload 名 `FpsOverlay`。
- 位置：右下角 248×28 逻辑像素，13 号字，半透明底，避免遮挡底部中央血条与右下技能栏。
- 守卫：`tests/test_fps_overlay.gd`（面板存在、右下角、鼠标穿透、FPS/帧耗/peak 文本、墙钟采样值）。
- 新测试场景不需要任何接入代码；只要 autoload 存在就会显示。

## 验证

```powershell
python -B tools/run_acceptance.py --tests test_fps_overlay --task fps-overlay
```

手动：F6 运行任意测试场景，右下角应出现帧数；`F12` 应能隐藏/恢复。
