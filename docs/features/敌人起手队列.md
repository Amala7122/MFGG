# 敌人起手队列

正式圣所的六种小怪及沉积泰坦共用战斗编排队列。队列约束整组技能何时可以开始，以及在场危险组的数量；获准之后继续使用原技能的前摇、锁定、碰撞与伤害实现。

## 调整入口

从编辑器启动主场景，按ESC暂停，选择“敌人起手队列”。专业测试台也可从“全局调节→敌人起手队列”进入。

- **应用本次运行**：只修改本进程后续起手，不写项目文件。
- **保存为默认并应用**：保存到[data/combat/attack_queue.json](../../data/combat/attack_queue.json)，下次启动可读。导出版本资源只读，保存到`user://attack_queue.json`。
- **恢复已保存值**：撤回当前草稿，恢复最近保存的默认值。
- **关闭／返回**：保留草稿和输入原文，恢复进入面板前的暂停状态；继续战斗仍从原入口操作。

非法输入不截断、不取整，面板会标出字段、原因与恢复方式。全局组数范围1–64、每渲染帧起手数1–8、间隔0–10秒、等待绕行速度倍率0–4；每兵种／每技能范围0–64，0表示禁止这类新起手。上限不是推荐把64个攻击同时打开，允许范围用于连续实验；实际限制取所有层级的交集。

## 参数含义

| 项 | 单位／范围 | 含义 |
|---|---|---|
| 总危险技能组上限 | 组，全场 | 起手、攻击动作、收势及尚存弹体／残留所占的组数 |
| 地面危险技能组上限 | 组，全场 | 有地面预警、投囊落点或毒池的技能组；属于总组数的一部分 |
| 每渲染帧起手上限 | 组/帧，全场 | 多物理步追赶也共享同一渲染帧名额 |
| 同一玩家的起手最小间隔 | 秒，游戏时间 | 新组起手的最小间隔，暂停时不推进 |
| 等待绕行速度倍率 | 倍，0–4 | 0为守势等待，调高可恢复绕行；再乘各兵种原有等待速度系数 |
| 此兵种危险技能组上限 | 组/玩家 | 同时针对该玩家的同兵种组数 |
| 每个技能并发上限 | 组/玩家 | 该兵种、该技能同时在场的组数 |

初始默认是总3组、地面2组、每渲染帧1组、起手间隔0.35秒，兵种2组、技能1组、等待绕行速度倍率0。自动候选比较后选取中间档，兼顾危险重叠、许可吞吐和帧耗；它是可调的工程初始值，难度与可躲性仍待试玩。测量口径及结果见[主场景帧耗排查](../tasks/主场景帧耗排查.md)。

限额调低时，已经开始的动作照常兑现；在场存量暂时高于新上限时，等其自然结束才准新起手，不突然删除玩家已经看见的攻击。关闭限制用于无约束对照，仍跟踪在场危险，重新启用时不会漏计存量。

## 排队与生命周期

每个敌人最多一张等待票。具备攻击条件却没有名额时，主要地面宿主默认守势等待；可用等待速度倍率调整绕行。重力、身体碰撞、受击、击退和正在执行的跨坎仍逐物理步处理；目标离开有效位置后恢复原有追击／撤退。候场不提前消耗这次攻击的冷却。

稳定候场者最多每0.1秒完整复核一次昂贵规划；自身位移超过0.4米、目标位移超过0.2米、地形版本改变或轮到自己获准时立即复核。等待查询只节省计算，不自行授予技能，真正起手始终回宿主检查当前条件。该路径不用于已经开始的攻击。

按先到先服务选取第一个能够容纳的有效请求。某个技能或兵种满额，不堵住其他可行请求；同一敌人根据新距离换招，保留仍有效的等待年龄。停止申请超过0.25秒的请求自动过期，死亡、目标失效或明确取消也会清理。队列不会发出异步强制施放回调，宿主获得名额后才按最新条件进入完整技能。

独立单体原型不强行接入正式群体编排；`formal_enemy`或`formal_boss`实例使用队列。正式群体的攻击限制独立于“启用群体运动”开关，原邻近同族攻击比例不再叠加限制正式队列。

队列随战斗现场保存。跨专业台暂时离树不会清空它，返回后恢复同一时钟和占位；新场景获得新队列。

## 弹体、毒池与Boss

敌人收招或死亡时，已经出手的弹体继续占位。爆囊在投出前为落地黏液预留名额，落地后由毒池接力，直到毒池退出才回收。毒池阶段不占已经结束的“转身投囊”技能限额，但仍占黏液、兵种、总组和地面组限额。

把黏液限额设为0会阻止**会产生毒池的投囊**起手；如果只想保留爆炸投射物，需要在敌人技能配置里将毒池持续时间或半径设为0。仅把伤害改为0仍会产生可见池，仍需预留。没有毒池的投囊不会申请黏液预留。

泰坦三线重击是一组内部有三条预警的完整招式，队列不拆散原本的出手顺序。跃击接震拳提前预留后续震拳额度，两段共用一组，不在落地时重新排队；后续震拳额度为0时，这种连招不会起手。关闭敌人配置中的跃击追击可保留独立跃击。泥浆护盾为防御动作，不消耗攻击配额。

## 验证与边界

`tests/test_enemy_attack_queue.gd`守住公平性、换招、限额、同帧追赶、过期／死亡、弹体毒池接力、连招、暂停和现场离树保留。`tests/test_enemy_attack_queue_panel.gd`覆盖真实按钮点击、非法原文、运行应用、保存及返回。

`tools/probes/attack_queue_calibration.py`比较真实混合波次的候选配置；运行副本、种子、帧耗、许可数量、等待时间和危险组峰值均记录到独立产物目录。许可数不等于命中数或招式完成数：获准后仍可能被玩家打断或因目标离开而取消。

晶体三怪的纯装饰腿在同一渲染帧只提交最后一次物理采样姿态；身体、眼睛、囊体、角与伤害相关部位仍逐物理步更新。观察台的公开`sample_pose`仍立即采样全部节点，逐节点等价回归覆盖普通／战斗／死亡姿态。

队列能限制夹击密度，不能保证任意站位都有可躲路线。不同前摇／飞行时长仍可能接近同时命中，毒池和场地也会压缩空间；实际可躲性与难度需要试玩验收。单个预警构建、导航内部长任务和首次管线编译也仍有独立成本，起手错峰不是对所有长帧的承诺。
