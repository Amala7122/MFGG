# 小型战斗空间测试场

入口：`res://prototypes/combat/spatial/combat_spatial_lab.tscn`。Godot 打开后按 **F6** 运行。

场地约 **44 × 41 米**，固定包含平地、约 18° 坡道、1 米台阶、2 米平台（右侧另有绕行坡道）、L 形掩体角、净宽 3.4 米窄路、落差 5 米的悬崖（右侧有桥），以及 **1.5 米高、1.2 × 1.2 米的小台面**。另有可破坏石块、残柱、小树和矮墙，共九个可选玩家起点。

两处坡道保留厚 0.3 米的薄板及坡脚挡边。地面敌人用完整身体检测跨越不超过 0.3 米的低坎，检查头顶与落脚空间；高挡边、低顶和悬崖不能硬跨。导航从实际静态碰撞烘焙，步高与角色跨坎上限一致，按泰坦体型留出通行宽度。

`spatial_layout.tscn` 是可整体实例化的空间预设；几何、碰撞和标记都由同目录脚本生成。编辑器可直接预览。将它放在其他实验场的 NavigationRegion3D 下后，按实际碰撞重新烘焙导航。

## 投放敌人

- 默认 **混合组 6 只**：泥偶 2、晶兽 2、蜂 2。
- **近战组 4 只**：泥偶 2、晶兽 2。
- **泰坦组 3 只**：泰坦 1、泥偶 1、晶兽 1。
- **单晶兽 1 只**：便于逐项观察飞扑与高度差。
- **单泰坦 · 掩体破坏**：搭配「可破坏石块 / 残柱旁」起点观察各攻击的破坏。
- **泰坦反应组 7 只**：泰坦 1、泥偶 / 晶兽 / 蜂各 2，观察跃击前撤离与友军受击。

选择玩家起点和整组预设，点击 **投放这组**，倒数三秒后开始。也可以继续使用下方图鉴自选敌人、数量、等级和参数，点击原来的生成按钮。最多 12 只，且按实际体型限制 36 米投放线容量。

默认玩家无敌，可关闭。沿用 Combat Lab 的统计、参数方案、A/B 循环补兵；Esc / Tab 暂停与继续，**F5 按当前选择重开**。起点在下一轮生成时应用。跌下悬崖后也可按 F5 重开。

无敌时仍记录模拟承压：独立护盾按正常倍率消耗、破盾溢出和回复，受击及翻滚免伤仍排除；破盾后的生命承伤持续累计，真实血盾不会扣除。统计合计包含实际与模拟，并分别列出两者。重新开启无敌时，模拟护盾从真实剩余护盾开始。

技能预警像笔刷一样从起点沿可达地表铺开；显示、命中和攻击后的笔迹共用同一份覆盖。坡面连续铺开，掩体背面、无法到达的高台、断层与无地面位置不画，横扫笔迹只覆盖手臂已经扫过的部分。飞扑按实际身体轨迹和障碍截断覆盖，不能在被墙挡住后继续画到墙后。

地面效果性能：整个范围只有同一块平坦地板时直接生成轮廓，保留碰撞、站立高度及飞扑轨迹检查；遇到坡板、掩体、台阶等仍使用细分刷面。复杂地表从 1m 格子开始，只在地形 / 遮挡边缘细分两层（标准范围约 25cm），细小边缘保守留白，仍不跨层连面。追踪重建按全场共用的 3ms 目标预算分帧执行，完成前保留原网格；小于 5cm 的视觉变化等锁定时准确刷新。初次出现和最终锁定仍完整生成范围。横扫笔迹只裁剪一次，之后由材质进度显示已经扫过的部分。

成本探针位于 `tools/probes/profile_attack_surface.gd`；实际六个预警加三个横扫的帧率对照位于 `tools/probes/attack_effect_frame_benchmark.gd`，应带图形运行，关闭 VSync 并设 `--max-fps 60`。这些是性能观察工具，自动通过 / 失败检查仍放在 `tests/`。

晶兽与泰坦先检查跃击落点是否能容纳完整身体，以及高度与路径是否允许。小台面无法落脚时，接近后改用 **跳起来的普通攻击**：原地跳起、挥击一次、落回原地，不需要站上台面，也不创建地面预警或裂痕。命中仍检查实际跳跃高度、距离和遮挡；台面过高或头顶被挡时不能攻击。泥偶及正式近战的普通攻击同样不画地面效果。

## 可赋予的环境破坏

选择「单泰坦 · 掩体破坏」和「可破坏石块 / 残柱旁」，点击投放。区域包含暖色石块、分节残柱、小树与矮墙；砸地按矩形命中范围破坏，横扫按实际挥击进度逐段破坏，跳跃普攻在空中挥击时破坏。蓄力跃击下落接触时碎裂，完整碰撞当帧移除，Boss 继续落到下面的地面；落地冲击可以震碎范围内的其他可破坏物。普通墙后、范围外和强度不足的物件保留；蓄力、取消不提前清场。上升阶段不能穿柱子，普通墙、平台、边界不参与破坏。

落点、完整脚印与下落通道按可破坏物消失后的地板预测；预警使用同一预测范围，落地先处理环境破坏，再按实际剩余碰撞刷新覆盖并结算一次伤害。不能为了破坏而跳进无地板的悬崖。

跃击在显示预警前确认落脚、飞行通道和最终计划；预警一出现就锁定落点与这一击的范围 / 伤害。蓄力期间不再追踪玩家，起跳不再次选点；玩家接近、远离、移到小台面、死亡或目标丢失都不能让 AI 撤回已公布的跃击，Boss 会在原位置完成冲击，玩家可以离开范围躲开。普通推力不改变这次蓄力的起跳位置。转入狂暴时也完成已公布的砸地 / 横扫 / 跃击，新的攻击倍率从下一击生效；Boss 死亡、清空及重开仍清理旧动作和危险，实际飞行仍尊重实体墙体碰撞。

碎块带短暂飞散、地面 / 墙体反弹、尘土与声音；只有表现，不产生伤害或阻挡移动。每组可配置 1–32 块、全场最多 8 组，默认 4 秒清理，低矮残骸保留到本轮结束。暂停冻结碎块；F5 重开或清空恢复完整物件，并清理动态效果。碰撞改变后同帧请求合并，后台重烘焙导航，通路随破坏 / 恢复更新。

能力位于 `scripts/destructible_component.gd`，共享材质位于 `data/destruction/`，攻击接口位于 `scripts/environment_destruction.gd`。给任意模型添加同一组件即可复用；小树、矮墙没有专用破坏代码。设置步骤见 [破坏能力说明](../../../data/destruction/README.md)。泰坦参数页的「环境破坏」分别控制四种攻击的强度，默认 1，设为 0 关闭。当前服务原型场景；环境血条、实时网格切割尚未实现。

## 跃击周围的小怪

选择「泰坦反应组 · 7 只」。泥偶保持原动作，硬吃伤害但不被击退；晶兽与蜂会感知落地区域、撤到安全边缘，冲击 / 取消后恢复围攻。晶兽躲不开时受伤并击退；蜂躲不开时被砸落，碰到实际地板后短暂停顿，存活则重新起飞，死亡则进入原死亡解体流程。普通墙后和高度窗口外仍受保护。

这些是独立资源赋予的反应，根节点的 `Combat Reaction Profile` 可更换；策略与命中反应可自由组合，不按敌人 ID 分支。操作和参数见 [可赋予战斗反应](../../../data/combat_reactions/README.md)。尚未接入正式敌人；当前只有蓄力跃击触发友军危险和伤害。

## 建议固定检查

T03 已接入可赋予的空间策略：行走 / 跳越 / 破障组合路线、真实接战姿态、下坑前出口证明、返程冷却预留，以及受阻时按实际枪口 / 相机遮挡转移。薄板坡仍保留挡脚边。资源与角色接口见 [空间能力说明](../../../data/combat_spatial/README.md)，实现范围与原始审核见 [T03 记录](T03_AUDIT.md)。

通用能力演示入口：`res://prototypes/combat/spatial/capability_lab.tscn`，F6 运行五组实际移动角色：跳越矮墙、1m 浅坑返程、5m 深坑拒绝、真实破障、爬墙转到天花板接战。**E** 让浅坑目标出坑 / 回坑，**R** 重开，滚轮缩放。真实敌人、玩家射击与小台面普攻仍在主 Spatial Lab 投放。墙顶使用通用场景连接；潜地仍需真实介质与出土执行器。

1. 平地：贴脸、1/3/5/10 米首发和连射；左右横移，再对比狙击。
2. 掩体角：相机能看到敌人、枪口被挡时应打在掩体上；枪口进入墙体也不能穿墙伤人。
3. 台阶 / 平台：从高处观察敌人的追击、挥空、绕坡与飞扑，记录无效循环。
4. 坡面 / 窄路 / 悬崖：观察落地、卡住、绕行和技能落点。
5. 小台面：投放单晶兽或泰坦组，观察追到台边后的跳跃普攻；与宽平台上可落脚的跃击对照。
6. 可破坏掩体：站在石块旁或跳到石块顶，观察砸碎时机、继续落地及残柱碎裂；F5 检查完整物件恢复。
7. 泰坦反应组：观察泥偶留在范围内继续攻击、晶兽 / 蜂撤离；引导已经飞扑 / 俯冲的敌人撞上落地冲击，检查击退、坠地与存活恢复。
8. 凹陷地：主场 5m 坑中，不能脱困的小怪围住坑沿、退少许遮住身体，默认 15% 概率短暂探头；蜂缩小盘旋圈追到坑上方射击 / 俯冲；泰坦使用实际 6m 高差跳跃下坑攻击，玩家出坑后预留原冷却并实际跳出，贴坑壁时先退到起跳点。玩家站住原入口时改用同层附近出口。冷却等待超预算、跳高不足都不算出口；更换物种与能力资源时不新增专属策略。
9. 能力导航：演示检查真实跳越、命中前保持物件碰撞、破障后的接战，以及墙顶转角 / 倒挂攻击。未来复杂间隙、动态出口与潜地仍按 T03 扩展矩阵继续覆盖。

T01 已修正：腰射散布半角为「基础 + 连射 bloom + 速度比例 × 独立移动角度」。基准跑速增加 1°，疾跑最多增加 1.6°，连射 bloom 上限仍为 6.5°；疾跑满 bloom 的水平半角从约 27.35° 降至 8.65°，首发保持约 2.15°。准星四条线段的内沿显示实际水平 / 垂直投影边界，随 FOV、画面比例和 UI 缩放变化；右键零散布狙击用中心标记，不继承腰射 bloom。

`tests/test_player_spread.gd` 以 1 米宽、2 米高的胶囊目标和玩家身后 4.5 米的相机作固定对照，始终重瞄身体中心，以正常射速疾跑环绕，重复 20 个 30 发弹匣。L12 在 3 米的命中率为旧 31.0% → 新 77.0%，5 米为旧 20.8% → 新 69.2%；这是补偿瞄准后的受控散布对照，不包含实战跟枪误差。另检查连射 / 移动独立性、停步回复、狙击、162 组相机 / 控件条件与 3072 发实际弹道；带图形运行时检查 1080p、85–130% UI 缩放的真实准星像素，加 `--capture-spread` 可保存截图到项目同级 `visual_captures/t01_spread/`。

自动验证：`tests/test_combat_reactions.gd` 检查真实跃击的撤离成功 / 失败、硬吃 / 击退 / 坠地、存活起飞 / 死亡、跨物种赋予、遮挡 / 悬崖、取消 / 暂停 / 清理和击杀归属；带图形运行加 `--capture-reactions` 保存实际画面。`tests/test_environment_destruction.gd` 检查真实砸地、横扫、跃击及跳跃普攻的破坏时机，小树 / 长矮墙边缘、多子碰撞赋予、300 件密集破坏、强度 0 关闭、实墙遮挡、取消 / 暂停 / 寿命 / 数量上限、重开恢复与导航更新；带图形运行加 `--capture-destruction` 保存前后画面。`tests/test_combat_spatial_lab.gd` 检查碰撞、导航、整组生成、九个起点和 B 补兵；`test_combat_spatial_navigation.gd` 检查三种地面敌人的薄板坡上下行及跨坎限制；`test_combat_spatial_attacks.gd` 检查从远处接近后的小台面跳跃普攻、大平台跃击，以及过高 / 低顶拒绝；`test_combat_feedback.gd` 检查刷面与命中一致；`test_player_hitscan.gd` 检查 T02 命中与阻挡规则。
