# T03：能力导航、高台与凹陷地接战

2026-10-07：已实施共享空间能力、接战姿态、组合路线、下坑准入 / 返程预留和射击威胁转移。现有原型的运动参数与技能冷却直接绑定到能力资源，策略不读取敌人种类；正式近战 / 射手接入公共行走策略。新增角色赋予资源并适配真实攻击 / 冷却接口，不复制导航脚本。

## 实施结果与边界

| 范围 | 当前实现 |
| --- | --- |
| 接战判断 | 按实际姿态、攻击形状、跳跃空间和表面可达性判断；没有合法攻击时继续找路。同层无遮挡时保留角色原有绕行与选招。 |
| 地面支撑 | 目标脚下真实支撑，不从头顶向下找楼层；薄板端面补探，完整身体跨低坎；大体型坡顶按有限板面求接触，不把身体高度当地面高度。 |
| 组合能力 | 有限成本搜索组合行走、真实跳越、具体物件破障及通用表面连接；未完成的查询保持安全等待。 |
| 凹坑 | 下降前验证返回路线 / 真实跳高 / 表面连接，入口消耗计入冷却等待预算；坑内预留返程，玩家实际离坑后优先执行。 |
| 无出口 | 不主动进入，利用坑沿遮住身体，只沿边或小幅后退；固定锚点、防止连续远退，允许可配置概率的短暂探头。 |
| 飞行 | 相对目标与真实地板求高度，按身体和发射口的净空 / 遮挡收缩盘旋圈，追到凹坑上空持续接战；不使用世界零高度。 |
| 墙顶 | 通用连接与执行器真实移动、旋转身体，检查接触、材质、转角与净空；到达后必须能在此姿态攻击，附着面消失则下落。 |
| 更新与成本 | 几何 / 导航版本、目标改变、实际碰撞失败使路线失效；搜索分帧共享 2.2ms 目标预算，不为候选生成地面效果。 |

真实敌人入口仍为 `combat_spatial_lab.tscn`；新增 `capability_lab.tscn` 以五组通用载体验证能力复用（E 切换浅坑目标出坑 / 回坑）。接入说明见 [空间能力资源](../../../data/combat_spatial/README.md)。

范围限制：墙顶路线目前由通用场景连接提供，尚未自动生成整关墙顶导航；持续飞行使用局部空域策略，复杂三维迷宫仍需完整路线搜索。潜地尚无真实介质和出土执行器，泰坦出生出土不算脱困手段。当前返程证明支持完整行走、带起跳前行走的实际跳跃或带前后行走的单条表面连接；复杂多段出口仍保守拒绝。下面的完整扩展矩阵保留作为后续验证要求，不能理解为每个动态、潜地或资源条件都已自动覆盖。

## 2026-10-05 原始审核与设计依据

当时已有绕坡、落脚检查与跳跃普攻，但默认 AI 在另外一些可达地形上会停步或重复挥空。下文保存当时观察与完整设计原则；接口和已实施范围以上面的结果及资源说明为准。

设计原则：主动下坑前必须证明能够脱困；没有脱困能力时在坑外转移到能规避玩家射击的位置。路线由行走、跳越、破障、攀附、潜地、飞行等实际能力组合，不限定沿地面接近玩家。高台、下坑、脱困和撤离使用可赋予的空间能力与共用策略，禁止按敌人 ID、名称或 Boss 标签编写决策分支。

## 已确认的缺口

| 问题 | 复现与原因 | 修复方向 |
| --- | --- | --- |
| 距离近就停，实际攻击却够不到 | 5m 平台有完整导航路径，泥偶可上台并命中；晶兽与泰坦站在台边 25 秒，0 次命中、脚底仍在地面。两者按高处目标的水平普攻距离停步，没有要求跳跃普攻真正可执行。 | 只有真实攻击成立或已经进入有效蓄力时才允许停步；否则继续沿可达路线接近。 |
| 导航终点吞掉局部绕行 / 后退 | 同层平地、后退方向身体无遮挡、无需绕路，期望后退速度 `(0, 0, -5.2)`，公共导航返回零。导航到达目标 0.7m 内，就让 `ground_velocity()` 丢弃了晶兽自己的局部移动。 | 区分“到达真实目标附近”和“部分路径终点”；前者允许经过身体碰撞与地面支撑检查的局部移动，后者保持不可达保护。 |
| 玩家靠边被误当成整个平台站不下 | 同一块 6×5m、2m 高的平台，泰坦面对玩家靠前边时返回 `landing_too_small`；玩家移到平台中央，跃击规划成功。现在只检查玩家正下方的一处落点。 | 在同一支撑面上寻找附近安全落点，保留完整脚印、头部、身体轨迹检查；没有合适起跳位置时先移动到起跳位置或绕坡。 |
| 找地面会选中上方顶板 | 晶兽可以落脚的 0.5m 高、6×5m 平台，上方顶板底面为 3.2m，飞扑整个身体最高约 2.27m，空间足够；加入顶板后 `_pounce_landing_ok()` 却从 true 变 false。头顶向下射线先命中顶板上表面，误把它当落脚地板。 | 从目标真实脚下查支撑面，而非从头顶任意高度向下找首个表面；角色离地时另保留最近合法支撑面。 |
| 到了附近仍会反复选择无法命中的技能 | 绕过过早停步后，泰坦到达高坡顶部，连续七次近战锁定都无法命中静止玩家；完成的攻击记录为 miss，命中仍为零。选招只检查距离、中心高度与直线可见，实际刷面 / 命中范围已经排除了目标。 | 候选使用实际形状与可达性；失败后调整接战位置，避免在原地重复同一无效选择。 |

对应位置：

- `scripts/prototypes/procedural_fast_beast.gd` 的 `_process_circle_flank()`、`_pounce_landing_ok()`。
- `scripts/prototypes/procedural_sediment_titan.gd` 的 `ordinary_range`、`_select_attack()`、`_plan_leap()`。
- `scripts/nav_steering.gd` 的 `ground_velocity()`、`needs_route()`、`has_path()`。

另一个需要一起纠正的代码边界：泰坦只有在跃击冷却可用时才计算落点；因此“没有跃击计划”也可能只是技能没准备好。几何能力与技能冷却应分别判断，不能把冷却未好当成台面无法落脚。

## 共用能力与策略边界

沿用现有 `CombatReactionProfile` 可跨物种赋予的组合原则，新建独立的空间策略资源与控制器，不把追击 / 下坑规则塞进受击反应资源。以下为拟定职责，名称不是现有实现接口：

| 层 | 职责 | 新增敌人时的处理 |
| --- | --- | --- |
| `CombatSpatialProfile` | 配置接战、进入风险区域、脱困、射击威胁撤离策略，以及重试 / 等待预算、路线成本偏好；引用可用的通行能力。 | 赋予或组合已有资源，调参数。 |
| 共用空间查询 | 读取角色实际支撑 / 附着面、表面法向、身体尺寸、导航层 / 有向通路、落点、可破坏物、遮挡和射击威胁；返回事实及明确失败原因。 | 复用查询，禁止重新写一套判定。 |
| 通行能力规划器 | 行走、跳越、破障、攀附、潜地、飞行等能力各自提供通用规划 / 执行契约；用同一能力参数规划接近与脱困。 | 复用已有能力；全新通行方式才新增一个可跨物种复用的规划器。 |
| 共用路线规划器 | 组合能力提供的有向通行段，比较完整接战路线及出口，输出带动作、消耗和环境前提的计划。 | 复用搜索与成本策略，不按物种选择寻路算法。 |
| `CombatSpatialController` | 用共用事实执行接战、路线动作、下坑准入、坑内追击、脱困、坑外转移及受阻策略；决定移动目标或合法动作候选。 | 接入共用控制器，不复制决策脚本。 |
| 角色执行适配 | 提供实际身体、运动参数、攻击可达性、技能冷却 / 消耗和动作执行接口；保留模型动画及攻击风格。 | 绑定接口和资源，已有攻击的表现可以保留。 |

能力不能只提供 `can_jump` / `can_burrow` / `can_climb` 布尔值。规划结果至少包含起点与姿态、移动模式、支撑 / 附着面及法向、落脚 / 附着区域、路径 / 轨迹、时间、消耗、冷却条件、要破坏的具体物件及导航 / 碰撞版本；失败分别返回几何不可达、未就绪、资源不足、查询未完成等原因。控制器只接受可验证的计划，执行器执行同一份计划，不能另选落点或省略通行动作。

普通攻击、跳跃普攻、攻击技能与纯移动 / 脱困动作分别声明用途。能在空中挥击不代表能跃上平台；出土动画、沉地表现也不自动提供穿行能力。攻击预警与地面笔迹只由实际攻击技能申请，纯跳跃普攻和纯脱困不自动生成攻击地面效果。

停步、局部绕行和选招失败反馈也进入公共策略；当前晶兽 / 泰坦等脚本中的对应位置是迁移入口。所有适用敌人共享规则，原有物种名称只用于描述复现与配置示例。

## 能力导航：障碍能否通行由能力决定

当前 `NavSteering.direction_to()` 把路径方向的 Y 分量置零，`ground_velocity()` 处理地面跟随；现有 `EnvironmentDestruction` 提供公共破坏查询 / 执行接口，但尚未接入跨障碍路线选择。下一轮保留地面导航作为行走能力的路线来源，在其上增加共用的能力路线规划，不能把“地面网格没有路径”直接作为所有敌人的不可达结论。

行走数据与连接净空也要按实际体型查询；目前为泰坦体型保留的公共网格不能成为所有小体型角色的通行上限。可以按通行尺寸等级共享导航数据，在局部补充经过完整身体验证的连接，不能为解决网格过于保守就退回无约束直线移动。

### 路线表示与选择

路线节点表示可停留或可继续运动的区域 / 姿态，包括地面、墙面、天花板与空中状态；连接表示带条件的真实动作。搜索状态同时包含移动模式、资源 / 冷却与该路线计划造成的必要环境变化。可以组合“走到起跳点 → 跳过矮墙 → 走到可破坏物前 → 破障 → 穿过开口”，也可以组合“贴墙 → 爬墙 → 转入天花板 → 到合法攻击姿态”。不为某个敌人单独写整条路线。

| 能力 | 可生成的通行段 | 成立条件 |
| --- | --- | --- |
| 行走 / 跨坎 | 已连通的地面路线与实际可通过的局部段 | 实际体型、坡度、步高、地板和头顶空间合格。 |
| 跳越 / 跃上 / 受控下落 | 跨过障碍、跨越间隙、改变支撑层 | 起跳点、全身体轨迹、落点与后续出口合格；能力就绪，消耗后仍能完成计划。 |
| 破障 | 接近障碍 → 执行合法破坏动作 → 通过真实开口 | 该动作能触及物件、破坏强度足够、冷却 / 资源满足；破坏后有足够宽高与支撑。 |
| 攀附 | 地面与墙面接驳、沿墙 / 顶面移动、转角、脱离附着 | 表面允许附着，连续接触与身体空间合格；角度转换、附着消耗和退出动作可执行。 |
| 潜地 / 飞行 | 经过允许的介质或空域，连接合法出土 / 降落 / 附着位置 | 穿行条件、完整身体空间、续航 / 消耗及终点动作满足该能力契约。 |

跳越和破坏对于具备能力的角色是有动作成本的通路，不是无限成本的封堵，也不是零成本的空地。完整路线比较移动时间、起跳 / 蓄力 / 破坏时间、技能等待、资源占用、暴露风险与战斗风格；安全边界和脱困条件先约束，再比较成本。允许绕行、跳越、破障和爬墙竞争，不采用“有地面路就一定走地面”的固定优先级。同一能力组合可以因参数不同选择不同路线。

路线终点是一组能够建立真实接战的姿态，不强制投影到玩家脚底附近。墙面 / 顶面敌人可以在合法姿态攻击；倒挂但实际攻击够不到时，还要继续移动或执行合法脱离 / 落地 / 扑击。仅仅到达玩家上方不能算接战成功，地面攻击也不能直接在倒挂姿态释放。

### 跳越与破障执行

跳越沿用实际身体与落点检查，途中实体碰撞正常生效；能够越过矮墙不等于能够穿过墙。地面路径断开时仍需查询已赋予的跨越能力，但没有该能力的角色保持原有通行限制。上层落脚点、跳回能力与凹坑返程由同一套规划器验证。

攻击型跃击若声明也可用于通行，就按通行落点与出口验证，不要求这一段同时命中玩家；仍完整执行真实预警、消耗、碰撞与落地伤害。没有声明通行用途的跳跃普攻不能自动作为跨障碍移动，也不能为了导航把攻击型跃击的危险和施放承诺删掉。

破障连接绑定具体物件与具体破坏动作，复用 `DestructibleComponent.can_break()` 和公共破坏接口。规划时只预测该动作确实会破坏的物件，不能全局排除所有可破坏碰撞，也不能隔着不可破坏墙预测砸掉后面的东西。若以后存在多次击破的物件，按真实累计伤害、次数与成本规划；当前组件按单次强度判定，不虚构累计破坏能力。

先到能执行该动作的站位，正常蓄力 / 命中，在真实破坏结算后检查开口，再通行。物件的碰撞在命中前继续阻挡角色；预警、伤害、取消与施放承诺沿用真实动作。动作目的区分“攻击玩家”与“为路线破障”：合法破障可以以物件为目标，不能因为这次打不到玩家就被普通接战的挥空过滤剔除，也不能假装打玩家而无限砸不可破坏墙。

按破坏后的环境检查后续路线与出口：开口后仍有第二堵墙、宽度不足、脚下成为深坑，或会拆掉自己的附着面 / 唯一出口时，该段不能无条件通过。若破坏需要的技能占用已预留的脱困资源，则等待或选其他路线。破坏完成后立即使相关连接失效并合并请求导航更新；重烘焙完成前仅走重新验证的局部通行段，不用旧网格或直线兜底穿越未知区域。

### 墙面与天花板攀附

攀附能力以实际接触面的法向和切平面计算方向，支撑信息保存接触点、法向、有效接触区域、材质 / 附着许可、所属物件及变换 / 碰撞版本。不能将墙面路径压成 XZ 水平速度，也不能继续使用“角色中心减固定半高就是脚底”的假设。现有地面落脚检查作为行走 / 落地能力的检查器保留，附着使用适合该接触方式的检查器。

地面到墙面、墙到顶面、内外转角和跨小缝都是需验证的模式转换：检查身体转动与运动扫过的空间、接触连续性、允许转角 / 间隙及能力消耗。几何上相邻的面不自动连通；不能在墙角穿模、隔着厚墙吸到背面，或把不可附着材质算成通路。运动执行器需要实际切换附着方向、身体姿态与重力处理，而不是只转动模型。附着面被破坏或离开接触时，转入该能力真实支持的重新附着、下落 / 落地或受困处理。

因此未来蜘蛛只需组合已有的行走、攀附、攻击 / 脱离能力与路线偏好，便可沿墙和天花板接近玩家；其他角色赋予同样能力也获得同样的通行方式。首次加入攀附时新增的是通用的表面规划 / 执行能力，不是蜘蛛专属 AI。未完成真实攀附执行器前，该能力保持不可用，不能只用配置标记宣称墙顶可达。

### 共用执行与更新

路线执行逐段经过准备、承诺、执行与到达验证；局部卡墙处理只能在当前合法模式和支撑区域内调整，不可以覆盖已承诺跳跃 / 破障，或把墙顶角色拉回地面导航。攻击移动、危险撤离和追击向同一个动作调度接口提交计划，避免几个控制器同时写速度 / 消耗资源。目标改变后重选后续路线，已公布动作仍按原承诺处理。

路线缓存按体型、能力与模式、接触区域、目标姿态、必要环境状态、导航 / 碰撞版本区分；资源可用性单独更新。每段提交前复核，外界破坏、附着面移动、技能变化或真实运动失败后使相关计划失效并有限重试，不能在多个模式间无限切换。候选表面、跳跃连接和破障分支按区域分层并限制搜索预算；先查少量完整候选，再局部扩展，预算耗尽返回待查询，不误报永久不可达。通用关卡标记可以帮助生成连接，角色能力与实际碰撞仍是准入依据。

地面 / 附着表面与候选连接在场地加载、烘焙或几何变化时构建共享区域数据，角色再按自身能力与体型过滤和复核。避免每只敌人每帧扫描全部墙顶、重新烘焙导航或枚举全部可破坏物组合；动态变化只更新受影响区域，并与现有地面效果预算分别受全场总成本约束。

## 建议的接战规则

每种敌人保留原本的战斗风格，共用空间事实：自己 / 目标实际支撑或附着面、完整能力路线是否通往合法接战姿态、安全落点与动作起点、当前攻击是否能命中、技能是否准备好。任何方案涉及主动进入可能无法返回的区域时，先通过下节的准入检查。

1. **当前能打到**：进入普通攻击或合法技能，按真实攻击范围停步。
2. **能到达接战位置**：行走、跳越、破障、攀附、潜地或飞行组成合法路线，按路线成本与风险选择并执行；技能冷却期间继续执行可用的通行段或在安全处等待，不强制优先走地面。
3. **站不上，但能在空中打到**：接近可攻击的位置，跳起来普通攻击，再落回原地。这次仍无技能地面效果。
4. **当前打不到，但有路**：执行能力路线追到有效接战姿态，不能因水平距离近、地面导航到达或站在玩家正上方而停。
5. **已赋予能力都无法建立路线或有效攻击**：进入明确的受阻行为，寻找可达的掩体、脱离实际射程的位置或其他风险较低的接战位置，避免站在台边 / 坑边持续挨打；低频复查，目标变得可达或地形变化后恢复追击。仅地面路径失败不能触发这一结论。

只有行走能力时，有坡就绕坡，没有通路时保留能力限制。拥有跳跃普攻能力时，小台面继续使用真实高度和遮挡判定。已经公布并锁定的攻击按原计划完成，新的接战判断用于下一次选择。

## 凹陷地：先证明能出，再允许进入

当前 `NavSteering` 的卡住处理是横向侧移与改路，不能证明垂直脱困。`has_path()` 又只表示导航能到达已投影的目标点；目标点落在另一层、部分路径终点或坑边时，都不能据此承诺下坑后能够返回。需要增加有方向的区域转换与脱困计划。

### 识别与下坑准入

凹陷地按实际支撑 / 附着面和通路识别：即将从当前区域进入较低区域，且不能确认该角色能从预计落点回到坑外的合法支撑、附着或持续运动区域。不能按世界 Y 小于零、节点名称、固定坑深或关卡坐标识别。连续坡道有完整返回路线时就是正常上下行；跨在坑顶的桥面不等于坑底有出口。

1. **检查进去是否安全。** 预测实际运动的落点，检查下落承受能力、完整身体轨迹、落脚支撑及落地空间；有环境破坏的动作按破坏后的地板与出口规划，不能把即将被自己拆掉的支撑 / 坡道算作保障。无底深渊不属于可进入的凹坑。
2. **从进去后的落点检查如何出来。** 查找能返回坑外的完整行走路线，或由已赋予能力规划跳跃、破障、攀附、潜地、飞行等出口；同一能力路线规划器处理追击与返程。上层到坑底可达不表示反方向可达。出口要接到可继续追击 / 转移的合法状态，不能只停在另一块仍被困住的台面。攀附者可以沿坑壁爬出，但须证明附着连续、出口转换和消耗合格。
3. **检查脱困手段现在是否可用。** 默认要求出口计划所需的技能 / 资源就绪并预留。下坑动作扣除消耗后仍要满足脱困条件；若同一次跳跃会用掉唯一脱困次数，则改走安全下降路线、等待或留在坑外，不能先跳下去再假定会刷新。几何可行但冷却未好属于等待，不能伪装成没有能力。
4. **越过边缘前复核。** 在实际跨边、起跳及攻击技能公布预警前复核入口与出口计划；导航未就绪、重烘焙中或查询仍未完成时，保守留在安全处等待，不退回朝玩家直走的默认方向。

该准入约束覆盖普通追击、绕行、后退、横向卡墙脱困、换路、主动闪避与所有能力路线段；所有主动运动都经过同一约束，不能从局部移动接口绕过。飞行 / 攀附角色使用自己的运动、续航 / 附着与返程条件评估，不套用地面角色的跳高。

若某套策略允许短暂等待冷却后返程，必须显式配置等待预算，并证明落地后有稳定等待位置、技能会在预算内恢复、恢复条件不会被计划中的其他动作破坏。把等待时间纳入出口计划；玩家出坑时转入准备脱困，条件满足即执行。默认不把尚未定义的资源恢复或无限等待当作出口，也不临时豁免 Boss 的冷却。

### 坑内追击与脱困

准入后进入坑内追击，维护已验证的出口与必要资源。攻击选择不能占用预留的脱困次数 / 资源；共用的冷却与资源接口必须提供实际占用机制，不能只在空间控制器里记一个标记。角色可以攻击，也可以使用其他剩余能力，但不能把自己打成没有出口的状态。

成功离坑、取消尚未承诺的入坑计划、死亡或场景清空时释放预留，避免回到正常地形后仍被限制使用能力；更换出口时先落实新预留，再释放旧预留。已承诺动作所需的资源按其正常执行 / 清理流程结算。

玩家真正离开凹坑并有合法坑外支撑 / 落脚预期时，结束当前动作后优先按出口计划上去继续追击。上升到空中但仍将落回坑里时不立即来回切换；采用支撑面、预计落点与短暂状态滞后来避免反复进出。已公布的攻击保持施放承诺，准入与资源检查必须发生在承诺之前，不能借“玩家出坑”撤回已显示的攻击。

跳跃出口使用实际跳高、水平距离、起跳位置、完整脚印、顶板和全身体轨迹检查；玩家所在小台面站不下时，寻找其他合法坑沿落点，之后再选择跳跃普攻或绕路。潜地能力检查允许穿行的介质 / 区域、深度与距离、出口支撑、出土身体空间和资源，禁止仅凭能力名称穿越所有实体墙。当前泰坦的出土表现不能算作已拥有潜地脱困技能。

出口被破坏、堵塞或导航版本改变后重新规划，必要时换出口。运动被实体碰撞阻止时记录原因并限制重试，不重复朝同一堵墙起跳。若已经没有出口，进入明确的受困状态，选择实际可用的防御 / 掩体 / 移动，暴露失败原因供测试观察；不通过瞬移、无碰撞或偷偷刷新技能补救。

Boss 与普通敌人使用相同契约：拥有且能执行出口能力才允许下坑。现有场地的 5m 深坑也要按实际能力验证；若跳高不足且其他已赋予能力也没有合法出口，Boss 同样留在坑外。后续赋予满足条件的跳跃、潜地或其他出口能力，就能复用“下坑追击 → 玩家离坑 → 脱困续追”的整条策略。

### 没有脱困手段时的坑外转移

不能证明出口的敌人拒绝主动进入，切换到坑外转移策略。依据已感知的玩家威胁，在自身可达、可安全停留的位置中寻找能阻挡实际射击的掩体或实际射程外的位置，同时避免退进另一处凹坑 / 悬崖。不把“离坑边几米”直接算作安全，也不只让敌人原地守在坑沿。

射击威胁查询与武器命中规则共用射程、射击起点、遮挡和穿透条件；掩体会被破坏时重新评估，不能只检查玩家脚底到敌人脚底的射线。当前枪械默认射程 120m，测试场约 44 × 41m，往往无法在场内走出射程，所以优先利用真正能遮挡攻击的地形 / 掩体。没有安全位置时选择暴露风险最低的可达位置并持续调整，报告仍然暴露；AI 不因此获得免伤，也不保证在任何布局里都能躲掉子弹。

若真实远程攻击或从坑外的攻击可以命中，接战策略可在合法站位短暂反击，再按风险转移；没有可执行攻击的近战不能在坑边循环挥空。玩家走出坑、转移到可达地形或出口条件改变时，重新评估追击。

被击退、碰撞挤落或脚下支撑破坏而强制掉坑的情况属于另一入口：立即查当前实际可用的脱困计划，有出口则离坑，没有出口则明确受困并做有限尝试。不能靠拒绝下坑规则免除真实物理后果；出生在坑里的角色也使用相同处理，测试投放优先避免把无出口能力的角色生成在孤立坑底。

## 实施顺序

**第一步：统一契约与接战入口。** 建立可赋予的空间策略资源、共用控制器、路线与能力接口；把现有停步、绕行和攻击可达性接入公共决策，让可执行攻击取代仅看水平距离。地面导航作为行走规划器区分完整路径、部分路径终点与受阻，并保留通过身体、支撑及风险检查的同层局部移动。先让“有坡高台”的默认 AI 通关，不新增物种专属策略。

**第二步：支撑 / 附着信息与落点。** 共用支持移动模式的接触面查询，移除玩家中心减固定 1m 的高差假设；对同一台面取少量落点候选，检查完整脚印、头顶、起跳位置与全身体轨迹。地面落点复用现有 `JumpLanding`；提取公共身体轨迹验证，并为附着面保留法向 / 姿态及独立接触验证，避免以后再次改写所有角色。

**第三步：组合路线与能力执行。** 实现带动作与成本的区域连接，先接入行走、真实跳越和现有破坏接口；处理具体物件的破障、环境变化、资源占用与逐段执行。让绕行 / 跳越 / 破障按完整路线竞争；后续墙面与天花板能力接入同一接口与模式调度，不新增蜘蛛专属分支。只有具有真实执行器并完成验证的能力才开放配置。

**第四步：选招与失败反馈。** 候选阶段按实际姿态与动作目的做轻量形状 / 可达性检查，选中后复用完整范围复核；几何不可达与技能未就绪分别处理。攻击玩家的无效候选转为调整接战位置，合法的路线破障候选按物件目标验证；连续失败不能只轮换砸地 / 横扫后继续原地挥空。

**第五步：有方向的下坑准入与返程。** 从预计落点规划坑外出口，接入入口安全、技能 / 资源预留与所有主动位移的准入约束；实现坑内追击、玩家离坑后的脱困、强制落坑及出口失效后的处理。准入检查随路线执行一起启用，不能在前几步未具备出口判断时开放危险下降连接。潜地等新能力遵守相同契约，有实际实现和验证后才允许赋予。

**第六步：威胁撤离与混合回归。** 为无出口或其他受阻状态选择真正可达的掩体 / 射程外站位，处理无安全点的持续转移；以跨物种赋予和混合组验证策略复用，再接入正式敌人。

空间判断按自己 / 目标支撑、相对位置、身体尺寸与能力参数、导航 / 碰撞版本变化刷新，稳定失败结果短时缓存。几何出口结果与冷却 / 资源可用性分开缓存；技能变化只更新可用性，不每帧重新搜索整个凹坑。候选区域与出口数量有上限，昂贵查询使用全场共享帧预算，未知结果先等待；地图可提供通用出口标记加速，实际安全仍由同一检查验证。越过危险边界时使用当前版本的有效计划，不继续执行过期缓存。

不要为每个攻击 / 出口候选每帧重建地面效果；初次选中和锁定时准确复核，沿用现有刷面预算。策略日志记录选择的能力、出口、失败原因及撤离结果，便于辨认“没有路”“冷却中”“无法脱困”“仍暴露”，避免用横向卡住计时替代这些状态。

## 扩展验收矩阵（完整清单未全部自动化）

- 默认参数、正常攻击决策下，2m / 5m 有坡平台从正面、侧面都能建立接战；玩家靠近台边也不能让敌人在台下停死。
- 宽台中心与边缘都能找到合法上台方案；小台完整身体站不下时使用跳跃普攻，超出真实跳跃 / 攻击高度时保持限制。
- 同层晶兽可正常后退、绕行和重新建立飞扑距离；身体被挡、无地板、部分路径终点不能盲目退回直线移动。
- 头顶有足够空间的顶板不改变脚下支撑面；真实低顶、墙体和悬崖仍拒绝跳跃。
- 不可命中的技能候选促使调整位置；玩家主动躲出已锁范围时，攻击按承诺完成，允许合理挥空。
- 玩家上台 / 下台 / 跳起 / 离开，以及环境破坏 / 导航重烘焙后能切换接战方式；混合组也要验证。
- 地面效果仍只服务技能；跳跃普攻无地面预警与笔迹。现有空间攻击、导航、刷面性能和泰坦施放承诺回归继续通过。

凹坑验收需新增默认 AI 的明确断言，不能只验证导航网格存在。场景与变体继续放在 `prototypes/combat/spatial/`，复用整体空间预设，测试脚本放在 `tests/`，观察工具放在 `tools/probes/`：

| 条件 | 必须观察到的行为 |
| --- | --- |
| 坑底有该角色能通行的返回坡道 | 可进入追击，玩家离坑后沿完整返回路线继续追击；薄板挡脚边仍按实际跨坎限制验证。 |
| 无坡闭合坑、单向下落、上层桥跨过坑顶 | 无脱困能力者不主动下去；不能把桥或导航投影误当成坑底出口，不能停在坑边持续白挨打。 |
| 坑深在跳跃能力内 / 外，坑沿宽 / 窄，头顶空旷 / 低顶 | 逐项验证出口身体与轨迹；合格才进入，不合格则换出口或留在坑外。当前 5m 坑对能力不足者也必须拒绝。 |
| 跳跃能下去，但消耗后没有脱困次数；技能冷却 / 资源不足 | 默认进入前等待或改选保留出口能力的路线；显式允许冷却等待时验证恢复时间 / 条件与等待位置，超过预算拒绝进入。坑内攻击不消耗预留的逃出资源。 |
| 玩家在坑内、跳起落回、真正出坑、到狭小坑沿 | 不因短暂腾空反复进出；真正出坑后使用合法出口续追，狭小玩家台面不是唯一出口候选。 |
| 潜地出口材质不允许、距离超限、出土点身体被挡 | 拒绝该出口；具备合法潜地方案时可追下去并从坑外重新建立追击。 |
| 无脱困能力，坑外有掩体 / 有射程外位置 / 没有安全位置 | 分别选择有效掩体、真实射程外站位、最低暴露的持续转移；不能按固定撤退距离宣称安全。 |
| 撤离路线被墙、另一处坑或悬崖隔断；掩体可破坏 | 不直线穿越危险；掩体破坏后重新择位，保留真实受伤与物理规则。 |
| 强制击落或生成在坑内，出口被堵 / 破坏，入坑攻击会破坏原出口，导航未就绪 / 重烘焙 | 能脱困则脱困，无出口则明确受困并有限尝试；进入前按预计破坏后的环境判断，不无限起跳、不瞬移、不使用失效出口或未知导航贸然下坑。 |
| 攻击预警前入口 / 出口失效；公布后玩家离坑 | 公布前拒绝无效技能，公布后完成承诺，结束后重新规划脱困；跳跃普攻和纯脱困不产生攻击地面效果。 |
| 给不同物种赋予同一策略 / 能力资源，或改变敌人 ID | 在相同体型与能力条件下做出相同空间决策；体型差异只通过几何检查产生差异，不要求新增策略脚本。 |
| 多敌人反复进出坑，攻击预警同时出现 | 查询预算、缓存失效、暂停 / 重开 / 死亡清理和资源预留释放均正常；不重复造成地面效果的性能下降。 |

能力导航验收同样放在上述目录，墙顶场景在通用攀附执行器完成后启用，不能用测试替身瞬移替代真实动作：

| 条件 | 必须观察到的行为 |
| --- | --- |
| 地面路线断开，但矮墙 / 沟可跳越；超高墙 / 低顶 / 无落点对照 | 具备能力者执行真实跳越并继续接战；不具备能力或轨迹不合格者不穿越。 |
| 同一窄通路，小体型能通过、大体型身体被挡 | 按实际净空决定行走连接，小体型不因公共大体型网格被误判无路，大体型不能强穿。 |
| 绕行、跳越、破障同时可行 | 改变路线时间、技能消耗与风险偏好可改变选择；不会永远优先地面，也不把能力动作当零成本。 |
| 攻击型跃击有合法通行落点但打不到玩家 | 具备通行用途时可执行并继续路线，真实预警与落地伤害保留；仅有原地跳跃普攻时不能获得跨越能力。 |
| 玩家只在破障后可接近，攻击可打到物件但当前打不到玩家 | 以物件为合法目的执行破障并继续路线，不被攻击玩家的挥空过滤误拒绝；命中前碰撞仍有效。 |
| 不可破坏 / 强度不足物件、第二堵墙、开口过窄、破坏后无地板或出口消失 | 拒绝无效破障段或选择其他完整路线，不全局忽略可破坏碰撞、不隔墙破坏、不拆掉唯一返程。 |
| 墙面、天花板、内外转角、墙顶接驳；不允许附着材质 / 断缝 / 旋转时身体被挡 | 合格连接按真实附着与姿态转换通过，不合格连接拒绝；不穿墙、不只转模型，不把顶面当地面落脚。 |
| 玩家在攀附者下方但攻击够不到，或只有地面技能可用 | 继续到能命中的姿态或合法脱离 / 落地，不在玩家正上方停死、不倒挂释放不支持的地面技能。 |
| 坑壁可附着 / 不可附着，攀附出口转换合法 / 不合法 | 同一出口规划器决定是否下坑并支持沿墙脱困；不能仅检查地面路，也不凭标签宣称能出坑。 |
| 外界抢先破坏物件、附着面移走 / 被毁、预警后目标改变、资源被占用 | 按当前环境更新未承诺路线，保留已承诺动作与真实碰撞；消耗 / 预留互斥，失败有限重试。 |
| 同一通行能力赋予不同敌人；修改名称 / ID；移除某项能力 | 能力相同时复用路线与动作，移除后不再选择对应连接；新增兼容敌人无需复制导航或策略脚本。 |
| 多敌人同时组合路线并破坏 / 攀附，暂停 / 重开 / 死亡 | 搜索、碰撞验证与导航更新遵守共享预算；动作、资源、附着状态和缓存正确清理，不产生新的帧率骤降。 |
