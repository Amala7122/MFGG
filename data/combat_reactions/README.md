# 可赋予的战斗反应

反应资源不包含敌人 ID。当前三个默认场景分别赋予：

| 资源 | 危险出现时 | 冲击命中后 | 默认赋予 |
|---|---|---|---|
| `hold_anchored.tres` | 继续原动作 | 扣血，不产生冲击位移 | 泥偶 |
| `evade_knockback.tres` | 撤离危险范围 | 扣血、击退、恢复原 AI | 晶兽 |
| `evade_knockdown.tres` | 撤离危险范围 | 扣血、坠地；飞行角色存活后重新起飞 | 蜂 |

在 Godot 打开 `prototypes/combat/enemies/` 中的敌人场景，选根节点，修改 **Combat Reaction Profile** 即可更换赋予。可把现有资源赋给其他兼容敌人，也可以新建 `CombatReactionProfile` 资源自由组合。编辑共享资源会影响所有使用它的实例；要单独调整，先复制资源或在检查器中选择“设为唯一”。

**Warning Response** 和 **Impact Response** 独立：例如可以配置“主动躲避但命中后不位移”，或“不躲避但被命中后击退”。硬吃仍受正常护甲 / 生命结算，生命归零照常死亡，不是免伤。

感知距离、反应延迟、撤离速度倍率和安全余量控制撤离；击退速度、受击时长、阻力、重力、坠落速度、贴地停顿和起飞速度控制命中表现。时间单位为秒，距离为米，速度为米 / 秒。参数是该能力的配置，不写进某个敌人的数值 JSON，也不修改玩家 Q 的原有推力数值。

当前只由泰坦蓄力跃击发布友军危险并造成友军伤害。跃击在预警出现前确认并锁定落点，之后不因目标移动或丢失由 AI 取消；危险与伤害共用地表范围、实墙遮挡和独立的友军高度窗口（默认 6 米，玩家仍使用原 3 米窗口）。小怪可看到“破坏后”的危险地面，落地仍先破坏、刷新实际范围，再结算一次伤害。成功撤离后守在安全边缘，直到冲击 / 外部清理后再恢复追击，避免不断冲回预警。Boss 死亡或重开仍立即撤销危险。

撤离会扫掠完整身体并检查沿途支撑；地面角色再交给原有寻路 / 跨坎逻辑。处于已经离地的飞扑、跳跃普攻或俯冲时不能突然改成地面撤离；来不及、无出口或正在执行这些动作时仍可能被命中。玩家受击可以打断撤离，撤离不赋予额外霸体。

坠地采用真实碰撞和重力；贴地停顿后，飞行角色连续回升到命中前的悬停高度，受低顶阻挡则在实际可飞高度交回飞行 AI。地面角色即使赋予坠地，也只贴地恢复，不凭空获得飞行能力。恢复期间普通受击继续扣血，但不会抢占坠地流程；死亡优先，不再起飞。

公共控制器位于 `scripts/combat_reactions.gd`，资源定义位于 `scripts/combat_reaction_profile.gd`。兼容角色在物理帧调用 `step`，并提供中断 / 恢复 / 姿态接口；地面角色提供寻路接口，飞行角色提供恢复高度。控制器根据移动方式决定是否重新起飞，不检查物种。生成前也可通过 `combat_reaction_profile` 元数据覆盖本次赋予；资源不会被运行时改写。

Boss 造成的伤害和击杀不计入玩家的武器伤害、DPS、命中和击杀；测试场把这些死亡列入“未归属死亡”。这些能力目前服务原型战斗场，正式敌人没有接入反应控制器。
